# N.O.V.A. 2026 대화형 의료 진단 AI 에이전트 개발 경진대회 신청 폼
> [!summary] 핵심 요약
> 분당서울대학교병원 의료인공지능센터와 엘리스(elice)가 여는 **N.O.V.A. 2026 "Doctor Agent" 개발 경진대회**의 Tally 참가 신청서다. 접수 마감은 2026-10-03이며 폼은 제출하지 않았다.
>
> 신청서는 총 7페이지로, 개요 → 약관 동의 → 팀·대표자 → 구성원 → 소개·동기 → 최종 확인 → 접수 완료 순서다.
>
> 예선은 고정 LLM(gpt-oss-20b) 위에서 파이프라인을 설계해 코드를 제출하는 방식이며, 총상금은 500만원이다.

## 무엇인가
Tally로 만든 참가 신청서다. 폼을 열어 안내문·질문 항목·동의 문구를 읽기만 했고 어떤 값도 입력하거나 제출하지 않았다.

렌더링된 화면에는 1페이지(개요)만 보이지만, Tally가 페이지 HTML에 내장한 폼 정의(블록 목록)를 읽어 모든 페이지의 안내문과 질문 항목을 확인했다(필드 제목·placeholder·필수 여부만 읽고 입력은 하지 않음).

폼 안내문이 가리키는 대회 공식 사이트 `nova.snubhai.org`도 열어 개요·일정을 보강했다.

대회 풀네임은 N.O.V.A. = Navigating Optimal clinical decisions via Virtual-patient Agents. 실제 의료 현장의 임상 추론 과정을 모사한 대화형 환경에서, 환자 문진·신체진찰·검사 선택을 거쳐 진단에 도달하는 "Doctor Agent"를 개발하는 대회다.

## 핵심 내용

### 1. 대회 개요 (신청서 1페이지 + 공식 사이트)
- 주최·주관: 분당서울대학교병원 의료인공지능센터, 엘리스(elice). 후원(공식 사이트 표기): 경기도경제과학진흥원, 정보통신기획평가원, 한국보건산업진흥원.
- 참가 자격: 의료 AI 및 대화형 AI 에이전트 기술에 관심 있는 누구나. 공식 사이트는 의료인, 연구자, 개발자, 데이터 사이언티스트, 학생 등 전공 제한 없음이라고 명시.
- 팀 구성: 팀당 최대 4명(공식 사이트는 "개인 또는 최대 4인 팀"). 목표 모집 규모 100팀.
- 접수 마감: 2026년 10월 3일. 신청서 목적은 참가팀 선발 심사, 중복 참가 확인, 참가자 본인 확인, 대회 운영 연락망 구축.
- 대회 방식(공식 사이트): 참가자는 가상 환자를 진료하는 Doctor Agent를 개발한다. 제한된 초기 정보에서 출발해 어떤 질문을 할지, 어떤 검사가 필요한지, 언제 진단을 내릴지 스스로 결정한다. 행동은 세 가지다 — ASK(문진: 환자에게 질문해 병력·증상 확인), EXAM/TEST(진찰과 검사 선택), DIAGNOSE(수집한 근거로 최종 진단 제출).

  한 증례당 최대 60턴의 상호작용을 허용하며, 제출 코드는 대회 서버에서 실행되어 비공개 증례로 평가된다.

  질환명 예측 정확도뿐 아니라 진단에 이르는 과정까지 평가한다고 밝혀 두었다(세부 배점은 미공개).
- 대회 배경 서술: 실제 진료에서는 모든 환자 정보가 처음부터 주어지지 않으며 문진, 진찰, 검사를 통해 단서를 모으고 진단 가능성을 좁혀 간다. 이를 모사해 "정확하고 안전한 진단"에 도달하는 능력을 평가한다.

개회식은 10.06 10:00-12:00 온라인. 예선은 "Doctor Agent 개발 및 코드 제출" 기간, 본선은 본선 진출팀 대상 평가. 제출 마감 시각, 본선 진출 발표일, 시상식 장소는 추후 공지(참가자 가이드).

### 2-1. 공식 사이트 하위 페이지 (`/evaluation/`, `/rules/`, `/prizes/`, `/faq/`, `/schedule/`)
처음에는 메인 페이지만 읽고 하위 페이지를 놓쳤으나, 링크를 따라가 아래 내용을 확인했다.

**진행·평가 (`/evaluation/`).** 환자의 전체 정보는 공개되지 않고 허용된 인터페이스로만 획득한다. 행동은 ASK(문진), EXAM(신체진찰 선택·소견 확인), TEST(검사·영상검사 선택), DIAGNOSE(최종 진단 제출)이며 증례당 최대 60턴, 문진·진찰·검사는 반복 가능.

예선은 대회 서버의 자동 채점 점수만으로 평가한다. 점수에는 세 기준이 반영된다.

- **Accuracy**: 최종 진단이 얼마나 정확한가
- **Efficiency**: 필요한 정보를 효율적으로 얻었는가
- **Safety**: 적절한 질문과 검사를 선택했는가

세부 지표·가중치와 본선 평가 방식은 예선 시작 전에 공개.

개발 단계에서는 공개 샘플 증례로 실험하고 채점 단계에서는 제출 코드를 서버에서 실행해 비공개 증례로 평가.

실행·제출 조건은 다음과 같다.

- **예선 모델**: 서버에 준비된 고정 LLM `openai/gpt-oss-20b`를 사용한다. 모델 파일은 제출하지 않는다.
- **본선 모델**: VRAM 20GB 이하 모델을 자유롭게 제출한다.
- **제출 파일**: `run.py`와 `requirements.txt`가 든 ZIP이며 최대 50MB다.
- **비공개 범위**: 채점 증례 원문과 실행 산출물은 참가자에게 제공하지 않는다.

**참가 규칙 (`/rules/`).**
- 예선: 고정 LLM(`openai/gpt-oss-20b`, 특정 리비전 해시로 고정)을 그대로 쓰고 그 앞뒤 파이프라인(프롬프트 구성, 문진·검사 선택 전략, 검색, 후처리)을 설계하는 경쟁. 고정 LLM 파인튜닝(LoRA·QLoRA 포함)과 가중치·어댑터 제출은 금지.

  서버 GPU는 고정 LLM 전용이고 보조 임베딩 모델은 제공하지 않으므로 RAG 인덱스나 소형 임베딩 모델은 서버의 CPU·RAM에서 제한 시간 안에 동작해야 한다.

  모든 증례마다 고정 LLM을 최소 1회 이상 정상 호출해야 하고(증례 정보를 담은 프롬프트), 호출이 없거나 증례와 무관하면 무효 가능.

  출력 후처리·규칙 기반 보정은 자유. 로컬 개발 환경 제한 없음.
- 개발용 API 크레딧: 5만원 상당. gpt-oss-20b와 채점용 GPT 모델 호출 가능. 대회 준비 목적에만 사용, 호출 로그는 운영진이 모니터링하며 용도 외 사용 시 사전 통보 없이 회수.
- 외부 자료: 대회 제공 자료 외 외부 데이터와 외부 LLM API도 개발과 제출물 제작에 활용 가능하나 모든 데이터·모델·도구는 논문 등 연구 출판에 쓸 수 있는 라이선스여야 하고 출처 명시 필수.

  허용: 샘플 증례의 학습·검증·검색·후처리 활용, 자가 라벨링(생성 방법 제한 없음), 라벨 생성 시 외부 LLM(상용 API 포함), 연구 출판 가능 라이선스의 공개 데이터셋·의학 자료, requirements.txt 설치 오픈소스.

  금지: 라이선스 불분명·연구 출판 제한 데이터·모델·도구, 제공 증례의 비식별화 정보를 외부 자료와 대조해 복원하려는 행위, **제출한 추론 코드에서 외부 LLM·외부 API를 호출하는 행위**, 비공개 평가 증례나 채점 정보 취득·유출 시도. (즉 외부 LLM은 개발·라벨링 단계에서만 쓰고, 제출 코드는 고정 LLM 하나로만 추론해야 한다.)
- 재현성: 수상팀 결과물은 대회 제공 자료와 제출 자료만으로 재현 가능해야 하며 불가하면 수상 취소 가능.

  자가 라벨링 코드·프롬프트·절차도 재현 대상.

  외부 LLM 라벨은 생성 코드·프롬프트·모델(버전) 기록과 생성된 라벨 데이터 제출로 재현을 대신하고 상용 API 비결정성은 문제 삼지 않음.
- 비공개 평가 데이터: 비공개 증례를 이용한 추가 학습·튜닝·pseudo-labeling 금지. 각 증례는 독립적으로 진료·예측해야 하며 다른 증례의 정보·예측값·통계를 활용해 보정하면 안 된다.
- 본선: 고정 LLM 제한 해제, 파인튜닝 모델 포함 자유 제출(VRAM 20GB 이하에서 로드·실행). 모델·코드와 함께 접근법과 결과를 정리한 발표 자료(PPT) 제출. 데이터·재현성 규칙은 본선에도 동일.
- 검증 자료 제출: 예선 종료 후 본선 대상팀은 점수 재현 코드와 실행 방법, 사용 요소의 출처·라이선스 명세, 팀 구성원 정보(성명·생년월일·성별·현재 소속)를 기한 내 운영 메일로 제출.

  예선 종료 시점 점수는 최종 순위가 아니며 검증 후 본선 진출팀과 수상팀이 확정된다.
- 유의: 1일 최대 제출 1회, 사용 언어 Python, 제출 파일·텍스트 출력 UTF-8. 코드 제출 기능을 악용한 평가 데이터 유출 시도는 즉시 실격. 다른 팀 계정·코드·API 토큰 접근이나 비공개 증례 반출은 실격·수상 취소.

**시상 및 혜택 (`/prizes/`).** 총상금 500만원: 대상 1팀 250만원, 우수상 1팀 150만원, 장려상 2팀 각 50만원. 참가 혜택으로 분당서울대학교병원 연구진과의 논문화 기회, 의료인공지능센터 인턴십 연계 지원(대상·조건은 별도 안내, 논문 게재나 인턴 선발을 보장하지 않음).

**FAQ (`/faq/`).** 의료 비전공자 참가 가능, 개인 참가 가능(한 사람은 한 팀에만), 신청은 사이트 버튼으로 연결되는 Tally 폼, 예선은 서버의 격리된 환경에서 코드 실행 후 자동 채점, 개발 가이드·예제·공개 샘플 증례·제출 방법은 참가자 가이드로 예선 전 신청서 이메일로 안내.

### 3. 신청서 구성 (모든 페이지, 제출 안 함)
**페이지 1: 개요.** 위 대회 개요 안내문. 입력 항목 없음.

**페이지 2: 약관 및 규정 동의.** 필수 체크박스 6개.
1. 개인정보 수집·이용 동의: 수집 항목은 성명, 소속, 이메일, 연락처 및 신청 과정에서 제출한 정보. 이용 목적은 참가자 확인, 중복 참가 확인, 팀 선발, 대회 운영, 공지, 수상자 확인과 시상 절차. 보유 기간은 대회 종료 후 1년이 원칙(법령상 보존 필요 시 연장). 동의 거부 권리는 있으나 거부 시 참가가 제한될 수 있다.
2. 대회 참가 규정·공정한 참여 서약: 1인 1팀 원칙, 타인 명의·계정 사용 및 중복·허위 참가 금지, 입력 정보의 사실 일치, 대리 참가·결과 조작 등 공정성 훼손 금지, 운영기관 연락망 유지 의무, 위반 시 심사 제외·실격·수상 취소·상금 환수 가능.
3. 비공개 증례 및 평가 환경 보호·보안 서약: 평가 중 접근하는 비공개 증례·테스트 데이터·평가 환경 정보는 대회 목적 범위에서만 사용. 금지 행위는 제3자에게 공유·전송·복제·배포, 허가 없이 개인 클라우드·공개 저장소·GitHub에 업로드, 허가되지 않은 외부 AI 서비스·API·외부 시스템에 입력·전송, 스크린샷·녹화·촬영·복사 등으로 외부 반출, 대회 종료 후 허용되지 않은 정보 별도 저장·계속 이용. 유출·무단 접근 가능성을 인지하면 즉시 보고해야 한다.
4. 제출물의 권리 및 제3자 권리 침해 금지: 제출물(코드·모델·문서)의 적법한 사용·제출 권한 보유, 제3자 권리 침해 금지, 오픈소스·공개 데이터·사전학습 모델 사용 시 라이선스 준수. 별도 규정이 없으면 기존 권리는 참가자에게 귀속되나 운영기관에 대회 운영·연구·논문·학술발표·교육·홍보 목적의 무상 비독점적 이용권을 부여. 평가 과정에서 생성되는 대화 기록, 모델 입출력, 도구 호출 기록, 실행 로그, 평가 결과, 판정 근거가 운영·검증·학술연구를 위해 수집·분석될 수 있고, 연구 결과는 참가자·팀이 식별되지 않게 처리해 논문·발표에 쓰일 수 있다. 수상작은 팀명과 산출물 일부가 공개될 수 있다.
5. 평가 방식 및 수상 절차 동의: 제출 형식·기한·필수 요건 미충족 시 평가 제외, 규정 위반·정보 유출·부정행위·표절 시 실격, 수상 후보자는 코드·모델·실행환경·기술문서 제출 요청 가능, 수상 후 중대한 위반이 확인되면 수상 취소와 상금 반환 요구 가능, 수상자는 제출물에 대한 라이선스 부여 권리를 보유해야 하며 자격 확인서·라이선스 등 서류를 제출해야 한다.
6. 최종 확인 체크박스: 위 전체를 확인했고 대회 중 별도 공지되는 운영·보안 지침이 규정의 일부로 적용될 수 있음에 동의.

**페이지 3: 참가팀 및 대표자 정보.** 참가팀명(필수), 팀장 성명(필수), 팀장 이메일(필수, 선발 결과·계정 정보·Discord 초대가 전달됨), 팀장 연락처(필수), 부팀장 성명·이메일(팀장과 다른 주소)·연락처(모두 선택).

**페이지 4: 팀 구성원 정보.** 팀 구성원 수 선택(1~4명, 필수) 후 조건부 로직으로 팀원 입력란이 나타난다. 팀장 소속(필수, 대학·기업·기관명), 팀원 2~4 각각 성명·소속·이메일·연락처(선택). 안내: 중복 참가 확인을 위해 실제 사용하는 이메일을 정확히 입력할 것.

**페이지 5: 팀 소개 및 참가 동기.** 목표 모집 규모를 초과하면 선발 심사 자료로 쓰인다고 명시. 항목: "팀 소개 및 참가 동기"(필수 서술, 권장 약 500자: 팀의 주요 기술 역량, LLM·AI Agent·의료 AI 경험, 참가 동기, Doctor Agent 개발 아이디어/접근 전략), "관련 경험 또는 프로젝트"(선택: LLM, RAG, AI Agent, 의료 AI, ML, 소프트웨어 개발 프로젝트·연구·대회), "참고 링크"(선택: GitHub, 논문, 프로젝트 페이지, 포트폴리오), "대회를 알게 된 경로"(복수 선택 체크: 학교·학과 공지, 카카오톡 오픈채팅, 공모전 사이트, 대회 홈페이지·포스터, SNS, 개발자·AI 커뮤니티, 학회 공지·뉴스, 지인·교수 추천, 기타).

**페이지 6: 최종 확인.** 입력 정보가 사실과 일치하며 제출 내용을 최종 확인했다는 필수 체크. 접수 마감 후에는 팀 구성 변경이 제한될 수 있다고 안내.

**완료 화면.** 접수·선발 결과는 팀장 이메일로 안내. 선발 팀에는 대회 계정, API 이용 안내, Discord 초대 링크가 별도 발송되며 공지는 공식 홈페이지(`nova.snubhai.org`)에서 확인.

## 구체 사실·수치
- 마감 2026-10-03, 모집 100팀, 팀당 최대 4명, 증례당 최대 60턴, 개인정보 보유 대회 종료 후 1년.
- 선발 방식: 신청이 100팀을 넘으면 "팀 소개 및 참가 동기" 서술(약 500자)을 심사 자료로 쓴다 → 사실상 서류 선발이 있을 수 있다.
- 평가 환경: 예선은 서버의 고정 LLM(gpt-oss-20b) 하나로만 추론, 제출 코드의 외부 API 호출 금지, 제출은 하루 1회·Python·ZIP 50MB 이하, 총상금 500만원(대상 250만원), 개발용 API 크레딧 5만원 상당.

## 비판적 평가
- 설계가 현실적이다: 문진·검사 선택·진단 시점 판단 같은 정보 수집 정책 자체를 평가해 정답 맞히기보다 임상 추론 과정에 가깝다. 최대 60턴 제한은 무한 질문 전략을 막는 장치이자 비용 통제 장치다. 다만 "과정 평가" 배점이 공개되어 있지 않아 어떤 질문이 좋은 질문으로 채점되는지 알 수 없다.
- 데이터 윤리·보안 조항이 강하다. 신청서 동의문은 "비공개 증례를 허가되지 않은 외부 AI 서비스·API에 입력 금지"라고만 하지만, 공식 사이트 규칙이 구체화한다: 외부 LLM은 개발·라벨링 단계(공개 샘플 증례 대상)에서는 허용되나 제출 코드에서의 호출은 금지다. 샘플 증례를 외부 상용 API에 보내는 것이 "비공개 정보 입력"에 해당하는지는 경계가 모호하므로 참가자 가이드나 운영 메일로 확인해야 실격 위험을 피한다.
- 상금 규모가 작다(총 500만원). 대신 논문화 기회와 인턴십 연계라는 비금전 혜택이 본체다(보장은 아님). 앞의 [[ai-top-100]](총상금 1억 2,500만원)과 성격이 다르다.
- 예선이 "고정 20B 모델 + 파이프라인 설계" 경쟁이라 모델 성능 격차가 아니라 프롬프트·검색·정책 설계 역량을 가른다. 이는 공정하지만 gpt-oss-20b 특성(추론 형식, 도구 호출 방식)에 대한 사전 이해가 필요하다. 세부 채점 가중치는 예선 직전에야 공개되므로 개발 방향이 늦게 확정되는 위험이 있다.
- 권리 조항: 권리는 참가자 귀속이지만 무상 비독점 이용권, 평가 로그의 학술 연구 활용, 수상작 공개가 붙는다. 상업화 계획이 있다면 영향이 크다.
- 개인정보: 신청서에 성명, 소속, 이메일, 연락처가 필수이고 팀원 정보를 대표가 대신 입력하는 구조라 팀원 동의 확보 책임이 팀장에게 있다.
- 마감(10/3)이 이 노트 작성일(10/1)에서 이틀 뒤다. 폼 자체는 500자 서술이 필요한 수준이라 준비 시간이 매우 짧다. 본선 진출 시 생년월일·성별 등 추가 개인정보를 검증 자료로 요구하므로 제공 범위를 사전에 판단해야 한다.
- 폼 정의를 읽은 방법: 렌더링 화면이 아닌 페이지에 내장된 폼 정의로 확인했으므로 조건부 로직의 세부 분기나 마감 이후 폼 상태는 확인하지 못했다.
