# 사람 대화로 기억 경로만 학습한 실험 — 2026-09-28

## 결론

언어모델을 완전히 고정하고 실제 사람 대화로 순환 기억 부분만 학습하면, 과거가 **없는** 조건보다 미래 발화를 잘 예측하는 경향은 얻는다. 하지만 과거를 **다른 사람 것**으로 바꾸면 거의 같은 예측을 한다. 개인별 장기 기억의 합격 기준에는 미달했고 어떤 체크포인트도 채택하지 않았다.

같은 모델에서 대화 짝짓기로 만든 자기지도 대조 손실을 추가해도 test의 `타인−자기` 이득은 −0.0022에서 +0.0033 nats/target-token으로 작게 바뀔 뿐이다. 95% bootstrap 구간은 0 위지만, 사전 기준인 최소 유용 효과 +0.02보다 훨씬 작고 valid에서는 구간이 0을 포함한다. 대조 손실을 해결책으로 판정하지 않는다.

## 실험

- 학습기 (`train_stream_memory_human.py`; 원 저장소의 파일 참조): MSC train의 사람-사람 페르소나 역할극 512개 대화를 사용. 과거 세션 최근 12발화/1,800자/384토큰을 순서대로 8 × 576 잠재 상태에 입력하고, 마지막 세션의 두 발화 뒤 세 번째 발화만 next-token CE로 학습한다. 추가 실험은 같은 CE에 `max(0, 0.02 + 자기 NLL − 타인 NLL) × 2`를 더한다. 대화 짝짓기는 원시 대화 ID에서 자동으로 구성하며 사실 위치·저장 여부·정답 기억 텍스트 라벨은 없다.
- SmolLM2-135M-Instruct의 모든 가중치와 출력 헤드는 고정. RMT 변형의 rank는 0이라 기존 Q/V adapter가 없다. 학습 가능 파라미터 338,113개는 기억 bridge, gate, 공유 write query뿐이다. 빈 기억 상태에서는 원래 언어모델 예측과 일치하는 테스트를 통과했다. 대화별 상태는 여전히 18 KiB(float32)이고 외부 key/value 기록은 없다.
- Apple MPS/float32에서 600스텝, batch 1, lr 0.0003, 256토큰 구간, 100스텝마다 MSC valid 96개를 평가한다. 선택 점수는 `min(빈−자기, 타인−자기)`이며 초기 가중치도 후보에 포함한다. 선택된 가중치 하나만 MSC test 96개에서 평가했다. CE 단독과 대조 손실은 같은 seed·기본 512개 대화·예산을 쓴다. 대조 손실은 여기에 MSC train의 별도 donor 과거를 추가로 입력하므로 학습 입력량까지 완전히 같지는 않다.
- 별도 80스텝/256개 대화 파일럿은 선택 test에서 `빈−자기` −0.0567, `타인−자기` −0.0041이었다. 따라서 짧은 학습만으로 결론을 내리지 않고 600스텝으로 확장했다.

## 결과

동일 test 96개, 정답 발화 2,889토큰. 수치는 대화별 평균 NLL의 동일 가중치 평균이다. `빈−자기`와 `타인−자기`가 양수일수록 자기 과거가 유리하다. 과거 원문 직접 읽기는 정보 존재 대조로, 순환 모델과 입력 경로가 다르다.

| 경로 | 자기 NLL | 빈 NLL | 빈−자기 [95% 구간] | 타인−자기 [95% 구간] |
| --- | ---: | ---: | ---: | ---: |
| 고정 LM, 과거 원문 직접 읽기 | 2.966 | 3.068 | +0.102 [0.070, 0.136] | +0.078 [0.044, 0.112] |
| 고정 LM + 순환 기억, CE만 학습 | 3.031 | 3.068 | +0.037 [0.019, 0.056] | −0.002 [−0.015, 0.009] |
| 고정 LM + 순환 기억, CE+대조 손실 | 3.032 | 3.068 | +0.037 [0.022, 0.051] | +0.003 [0.001, 0.006] |

CE 단독은 valid 200스텝, 대조 손실은 valid 500스텝 가중치가 선택됐다. 둘의 test 대화 ID·donor·정답 토큰 해시가 정확히 같다. 각 test 사례의 `타인−자기` 차이를 짝지어 보면 대조 손실은 평균 +0.00547 바뀌었고, 54개가 개선·42개가 악화됐다. 이 비교에 대한 별도 신뢰구간은 계산하지 않았다.

선택된 두 모델의 과거 상태는 서로 다른 대화임에도 코사인 유사도가 평균 0.951(CE), 0.963(CE+대조)이다. 이는 큰 공통 성분이 있다는 관찰이지 그 자체만으로 원인을 확정하지 않는다. 최종적으로 타인 상태에 대한 예측 차이가 거의 없다는 개입 결과가 더 직접적인 실패 근거다.

## 경계와 결정

train/valid/test의 대화 ID는 겹치지 않는다. 다만 MSC valid/test는 프로젝트 이전 실험에서 이미 반복 관찰했고, 이번에도 모든 대화의 일부 과거 이력이 길이 제한으로 잘렸다. 결과는 탐색적이다. 첫 정답 토큰 이후는 teacher forcing이며, 이 모델에는 기억 텍스트/`NO_MEMORY` 출력 또는 자동 반환 시점 결정이 아직 없다. 그래서 완전한 메모리 반환 E2E 성능을 주장하지 않는다.

**결정: 두 가중치 모두 개인별 기억 모델로 채택하지 않는다.** 언어모델 고정은 이전 합성 학습에서 발생한 일반 대화 성능 저하를 피했지만, 개인별 상태를 읽는 문제를 해결하지 못했다. 같은 목적함수의 스텝 수만 늘리는 작업은 여기서 멈추고, 다음 설계에서는 개인별 차이를 상태에 보존하고 읽기에 반영하는 통로를 별도로 검증해야 한다.

재현 결과: `local-data/stream-rmt-human-frozen-600-seed29.json`, `local-data/stream-rmt-human-frozen-contrastive-600-seed29.json`; 사례별 점수와 상태 진단: `local-data/stream-rmt-human-frozen-600-test-audit.json`, `local-data/stream-rmt-human-frozen-contrastive-600-test-audit.json`. 두 체크포인트는 별도의 `.pt`로 보존했고 기존 체크포인트를 수정하지 않았다. 전체 Python 테스트 **721개 통과**(기존 경고 1개)를 최종 확인한다.
