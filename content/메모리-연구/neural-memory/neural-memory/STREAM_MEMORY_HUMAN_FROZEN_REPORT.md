# 사람 대화로 기억 경로만 학습한 실험 — 2026-09-28

## 결론

이 실험은 언어모델의 일반 대화 능력을 건드리지 않고 기억 부분만 배우게 하면, 개인별 과거를 활용할 수 있는지 묻는다. 언어모델의 가중치는 완전히 고정하고, 실제 사람 대화를 읽으며 다음 구간으로 넘기는 순환 기억만 학습했다.

그 결과 과거가 **없는** 조건보다는 미래 발화를 잘 예측했다. 하지만 기억을 **다른 사람의 과거**로 바꿔도 예측은 거의 같았다. 무엇이든 기억 상태가 있으면 도움이 되는 효과와, 해당 사람의 내용을 기억하는 효과는 다르다. 이번 모델은 후자의 합격 기준을 넘지 못해 어떤 체크포인트도 채택하지 않았다.

자기 대화에서 만든 기억이 타인의 기억보다 유리하도록 대조 손실도 추가했다. 대화끼리 짝지어 비교하는 자기지도 방식이다. test의 `타인−자기` 이득은 −0.0022에서 +0.0033 nats/target-token으로 바뀌었다. 이 단위는 정답 토큰당 예측 손실의 차이를 뜻한다.

95% bootstrap 구간은 0보다 높았지만, 미리 정한 최소 유용 효과 +0.02에 비하면 변화가 훨씬 작다. valid에서는 구간이 0도 포함했다. 따라서 대조 손실을 추가하는 것만으로 해결됐다고 판단하지 않는다.

## 실험

- **대화와 학습 정답:** 학습기 (`train_stream_memory_human.py`; 원 저장소의 파일 참조)는 MSC train의 사람-사람 페르소나 역할극 대화 512개를 사용한다. 과거 세션의 최근 12발화/1,800자/384토큰을 시간순으로 8 × 576 잠재 상태에 넣는다. 마지막 세션의 첫 두 발화를 본 뒤 세 번째 발화를 예측하게 하며, 그 발화의 다음 토큰 CE만 학습한다. CE는 실제 다음 토큰에 높은 확률을 주도록 하는 손실이다.
- **비교할 손실:** 추가 실험에서는 같은 CE에 `max(0, 0.02 + 자기 NLL − 타인 NLL) × 2`를 더한다. 자기 기억으로 예측한 손실이 타인 기억보다 충분히 낮지 않으면 비용을 주는 식이다. 대화 쌍은 원시 대화 ID로 자동 구성한다. 사실 위치, 저장 여부, 정답 기억 텍스트 라벨은 없다.
- **고정할 부분과 배울 부분:** SmolLM2-135M-Instruct의 모든 가중치와 출력 헤드는 고정한다. RMT 변형의 rank는 0이어서 기존 Q/V adapter도 없다. 학습하는 338,113개 파라미터는 기억 bridge, gate, 공유 write query뿐이다. 빈 기억에서는 원래 언어모델과 예측이 같은지 검사해 통과했다. 대화별 상태는 여전히 18 KiB(float32)이고 외부 key/value 기록은 없다.
- **실행과 선택:** Apple MPS/float32에서 600스텝, batch 1, lr 0.0003, 256토큰 구간으로 학습한다. 100스텝마다 MSC valid 96개를 평가하고 `min(빈−자기, 타인−자기)`로 선택한다. 두 비교 중 약한 쪽까지 좋아야 선택 점수가 높아지는 방식이다. 초기 가중치도 후보에 넣고, 선택된 가중치 하나만 MSC test 96개에서 평가했다.
- **비교의 공정성과 한계:** CE 단독과 대조 손실은 같은 seed, 기본 512개 대화, 예산을 쓴다. 다만 대조 손실에는 MSC train의 별도 donor 과거도 들어간다. donor는 비교할 기억을 제공하는 다른 대화이며, 이 추가 입력 때문에 학습 입력량까지 완전히 같지는 않다.
- **짧은 실행을 늘린 이유:** 별도 80스텝/256개 대화 파일럿은 선택 test에서 `빈−자기` −0.0567, `타인−자기` −0.0041이었다. 이 짧은 실행만으로 결론을 내리지 않으려고 600스텝으로 확장했다.

## 결과

두 모델을 같은 test 96개, 정답 발화 2,889토큰으로 비교했다. NLL은 정답에 부여한 확률이 낮을수록 커지는 예측 손실이다. 먼저 각 대화 안에서 토큰 평균을 구한 뒤, 대화마다 같은 가중치를 주어 평균했다.

`빈−자기`가 양수면 과거가 없을 때보다 자기 과거가 유리하고, `타인−자기`가 양수면 다른 사람의 과거보다 자기 과거가 유리하다. 원문 직접 읽기는 이 데이터의 과거에 도움이 되는 정보가 있는지 확인하는 대조다. 순환 모델과 입력 경로가 같지는 않다.

| 경로 | 자기 NLL | 빈 NLL | 빈−자기 [95% 구간] | 타인−자기 [95% 구간] |
| --- | ---: | ---: | ---: | ---: |
| 고정 LM, 과거 원문 직접 읽기 | 2.966 | 3.068 | +0.102 [0.070, 0.136] | +0.078 [0.044, 0.112] |
| 고정 LM + 순환 기억, CE만 학습 | 3.031 | 3.068 | +0.037 [0.019, 0.056] | −0.002 [−0.015, 0.009] |
| 고정 LM + 순환 기억, CE+대조 손실 | 3.032 | 3.068 | +0.037 [0.022, 0.051] | +0.003 [0.001, 0.006] |

검증 자료로 고른 상태는 CE 단독이 200스텝, 대조 손실이 500스텝이었다. 두 시험의 대화 ID, donor, 정답 토큰 해시는 정확히 같다. 따라서 같은 문제끼리 비교할 수 있다.

각 test 사례의 `타인−자기` 차이를 짝지어 비교하면 대조 손실 추가 뒤 평균 +0.00547 변했다. 54개는 좋아졌고 42개는 나빠졌다. 이 변화량에 대한 별도의 신뢰구간은 계산하지 않았다.

서로 다른 대화를 읽은 상태끼리도 모양이 매우 비슷했다. 이를 재는 코사인 유사도 평균은 0.951(CE), 0.963(CE+대조)이었다. 공통 성분이 크다는 관찰이지만, 이 숫자만으로 실패 원인을 정할 수는 없다.

더 직접적인 근거는 상태를 실제로 바꿔 넣은 결과다. 다른 사람의 상태를 넣어도 예측이 거의 바뀌지 않았으므로, 개인별 기억의 유용성이 입증되지 않았다.

## 경계와 결정

학습/검증/시험(train/valid/test)의 대화 ID는 서로 겹치지 않는다. 그러나 MSC valid/test는 이 프로젝트의 앞선 실험에서 이미 여러 번 확인한 자료다. 이번에도 길이 제한 때문에 모든 대화에서 과거 이력의 일부가 잘렸다. 따라서 결과는 탐색적으로 해석한다.

첫 정답 토큰 뒤의 예측은 앞선 정답을 제공하는 teacher forcing 방식이다. 모델이 혼자 발화를 끝까지 생성한 평가가 아니다. 기억 텍스트나 `NO_MEMORY`를 출력하는 기능, 언제 반환할지 자동 결정하는 기능도 아직 없다. 완전한 메모리 반환 E2E 성능을 주장하지 않는다.

**결정: 두 가중치 모두 개인별 기억 모델로 채택하지 않는다.** 언어모델을 고정하자 앞선 합성 학습에서 나타났던 일반 대화 성능 저하는 피했다. 하지만 어느 사람의 상태를 읽는지가 예측에 충분히 반영되지 않는 문제는 남았다.

같은 목적함수로 스텝 수만 더 늘리는 일은 여기서 멈춘다. 다음 설계에서는 사람마다 다른 정보를 상태에 남기는지, 남은 차이가 읽기와 예측까지 전달되는지를 따로 검증해야 한다.
