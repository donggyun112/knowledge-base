# 정정 표현 다양화·출력 유지 제약 실험 — 2026-09-27

## 결론

**이번 추가 학습 가중치는 채택하지 않았다.** 세 실행 모두 600스텝 동안 17개 검증 조건의 시작 정확도를 전부 유지하는 후보를 만들지 못했다. 새 표현의 정확도나 평균 답 손실이 좋아져도 기존 정정·간섭 조건이 떨어지면 제외하는 기준을 적용했다.

그 결과 세 실행 모두 **초기 정정 모델(선택 스텝 0)**을 유지했다. 마지막 600스텝 가중치는 무엇이 학습되고 무엇이 나빠졌는지 보는 진단용으로 따로 보존하며, 선택 모델의 성능과 혼동하지 않는다.

학습 자체가 아무 변화도 만들지 않은 것은 아니다. 마지막 가중치의 별도 시험에서 학습한 `is now ...` 표현의 새 값 정확도는 두 KL 모델 모두 **1.56% → 70.31%/75.00%**로 크게 올랐다.

그러나 seed 17에서는 같은 새 값의 본인 정정이 **87.50% → 82.81%**, 이전 값 변경이 **82.03% → 75.78%**로 떨어졌다. 미학습 `The secret word I use now is ...`도 **75.00% → 64.06%**였다. 표현과 새 값을 배우는 것은 가능했지만 모든 조건을 유지하지는 못했다. 여기의 수치는 채택되지 않은 마지막 가중치에 대한 진단이다.

이것은 이번 학습 분포·학습률·제약 강도·예산의 실패다. 이 구조가 원천적으로 학습 불가능하다는 증거도, 전체 메모리 연구의 완료도 아니다. 이전 [[메모리-연구/neural-memory/neural-memory/STREAM_MEMORY_BALANCE_REPORT|반복 간섭 균형 실험]]의 실패 기록과 가중치는 그대로 남겼다.

## 바꾼 것과 유지한 것

직전 균형 실험의 가중치를 이어 쓰지 않고 `stream-rmt-revision-clean-seed{7,17}.pt`에서 각각 시작했다. SmolLM2-135M 본체와 LM head는 고정하고, 기존과 같은 Q/V 저차원 갱신과 bridge/gate/shared write query를 사용했다. **학습 파라미터는 568,513개**, **잠재 상태는 8×576(18 KiB, float32)**다.

독립 대화의 상태는 0에서 시작한다. 외부 KV 기록·검색·수동 화자별 저장·중요도/정정 라벨·도구 문법은 추가하지 않았다.

표현을 다양하게 경험하도록 기존 11개 보존/정정/간섭 조건에 아래 세 표현을 추가했다. 각 표현에 대해 정정 뒤 일반 잡담이 이어지는 경우와 다른 화자의 후보 사실이 여덟 번 이어지는 경우를 만들어 총 여섯 조건을 더했다. 상황 이름은 메타데이터에만 두고 입력 헤더의 무작위 숫자는 유지했다.

```text
Me: I changed my secret word to ...
Me: My secret word is now ...
Me: From now on, my secret word is ...
```

**`I changed ...`는 이번 실험부터 학습에 넣은 표현이다.** 이전 보고서에서 미학습 표현이었다는 이유로 이번 성능을 미학습 표현 일반화의 성공으로 다시 계산하지 않는다. 이번에 시험에만 쓴 표현은 `Me: My new secret word is ...`, `Me: The secret word I use now is ...`다. 이 둘은 가중치 학습이나 검증을 통한 선택에 사용하지 않았다.

## 출력 유지 제약과 대조

새 표현을 배우면서 기존 출력을 유지할 수 있는지 보기 위해 두 자료 묶음을 함께 학습했다. 새 학습 자료는 17조건의 8,704대화이고, 기존 능력을 다시 학습하는 자료는 여섯 정정/보존 조건의 3,072대화다.

매 스텝 각 묶음에서 배치 크기 2를 뽑아 마지막 미래 구간의 **모든 대화 내용**에 대한 다음 토큰 교차엔트로피(CE)를 계산했다. 아래 손실은 토큰 수로 가중한 평균이다.

```text
L = (CE_new_sum + CE_replay_sum) / (N_new + N_replay)
    + 0.25 × mean_KL_on_replay_content
```

출력을 유지하도록 비교할 기준 모델은 시작 가중치를 독립적으로 복사한 것이다. 모든 파라미터를 고정한 채 자기의 0 상태에서 기존 여섯 조건의 실제 토큰을 읽게 하고, 이때 얻은 다음 토큰 분포를 기준으로 삼는다.

학습하는 학생 모델과 기준 모델의 LM 전체 어휘 분포 사이 KL을 **재학습 대화의 모든 미래 내용 토큰**에 적용한다. 기존 출력 분포에서 너무 멀어지는 것을 제약하는 방식이며, 기준 모델의 답이 언제나 정답이라고 가정하지는 않는다.

학생과 기준 모델 어느 쪽에도 사실 위치나 정답 토큰을 상태에 넣어 주지 않는다. 사실/답 위치 메타데이터를 바꿔도 CE/KL이 같은지, 미래 답 입력을 바꿔도 예측 점수가 같은지 검사했다.

기준 모델은 학습 중 손실 계산에만 사용하며 **추론용 가중치에는 저장하지 않는다.** 학습을 마친 뒤에도 기준 모델의 어댑터가 같고 기울기가 없는지 확인한다.

seed 7/17에서는 KL 가중치 0.25를 사용하고, seed 17에서는 KL이 0인 CE 대조도 실행했다. 대조도 같은 재학습 대화를 읽으며 시작점, 학습·검증·시험 입력, 샘플 순서, CE 내용 토큰 예산, 배치 크기/학습률, 최대 스텝을 맞췄다. 다만 KL 조건은 기준 모델의 연산이 추가되므로 **연산량(FLOPs)이나 실제 실행 시간까지 같은 대조는 아니다.**

Apple MPS GPU/float32, 학습률 0.00005, 기울기 노름 상한 1, 최대 600스텝을 사용했다. 컴퓨터 절전으로 중간에 멈췄다가 재개됐지만 스텝 수와 선택 기준은 바꾸지 않았다.

실제 학생 CE 손실 토큰 수를 샘플 순서로 재계산해 기록과 일치함을 확인했다.

| 실행 | 새 대화 CE 토큰 | 재학습 대화 CE 토큰 | 합계 |
| --- | ---: | ---: | ---: |
| KL seed 7 | 10,892 | 10,545 | 21,437 |
| KL seed 17 | 10,580 | 10,434 | 21,014 |
| CE 대조 seed 17 | 10,580 | 10,434 | 21,014 |

## 새 값과 엄격한 검증

MSC 학습 분할의 같은 단어 빈도, 512개 후보, seed 9013으로 만든 값 분리를 연장했다. 기존 학습 256값·검증 32값·진단 8값·이전 시험 128값을 보존하고 그 다음 **64개 값**을 이번 시험으로 남겼다.

새 답 값은 학습·검증 답은 물론 옛값이나 다른 화자의 사실 값으로도 사용하지 않았다. 다만 사전학습 LM에는 익숙한 단어일 수 있다. 이번에도 실제 사람 대화를 학습한 것은 아니다.

선택 기준은 이전보다 엄격하게 정했다. 검증 자료는 32값 × 17조건의 **544사례**이며 100스텝마다 평가했다. 어느 조건도 시작점의 전체 어휘 정확도보다 떨어지면 안 된다. 이전 단계에서 허용한 1/32의 하락을 이번에는 **0으로 고정**한 것이다.

통과한 후보는 최저 조건 정확도를 먼저 보고, 다음으로 평균 답 NLL을 비교했다. 초기 모델도 후보에 포함했고 시험은 학습·선택을 완료한 뒤 구성·평가했다. 이 규칙은 모델을 고르는 기준이며 신경망의 저장·갱신 규칙은 아니다.

예를 들어 seed 17의 300스텝 KL 모델은 17조건 중 16개에서 점수를 유지했지만, 본인 정정이 **87.50% → 84.38%**로 내려가 탈락했다. 같은 시점의 `is now` 검증 점수는 **0% → 68.75%**로 올랐다.

두 결과를 함께 기록해야 한다. 검증 기준에 탈락했다고 학습으로 바뀐 것이 없다는 뜻은 아니다. 반대로 새 표현을 잘 배웠다는 이유만으로 모든 조건의 균형 유지에 성공했다고 할 수도 없다.

| 실행 | 600스텝에서 시작점보다 하락한 검증 조건 | 선택 스텝 |
| --- | --- | ---: |
| KL seed 7 | 본인 값 변경, 본인 두 번 정정, 정정 뒤 후보 사실 여덟 번 | 0 |
| KL seed 17 | 본인 정정, 본인 두 번 정정, 다른 화자의 세 사실, 다른 화자의 한 값 반복, changed, fromnow | 0 |
| CE 대조 seed 17 | 본인 두 번 정정, 후보 단어 언급, 다른 화자의 한 값 반복, changed | 0 |

각 실행의 100~600스텝 **여섯 후보가 모두 탈락**했다. 그 뒤 평균 손실이 낮다는 이유로 다른 후보를 소급 선택하지 않았다.

새 시험은 17조건 × 64값 × 두 잡담 배치의 **2,176사례**, 시험 전용 표현은 네 조건 × 64값의 **256사례**다. 직전 균형 단계의 새 64값도 동일 원문의 1,408사례로 다시 평가한다. 하지만 선택된 모델은 초기 모델이므로 이 시험 점수를 추가 학습의 성공으로 제시하지 않는다.

입력·샘플/내용 토큰 예산·선택 과정을 재생성해 세 실행 모두 일치함을 확인했다. 선택 `.pt`의 모든 adapter 텐서도 원래 시작 `.pt`와 정확히 같았다. 선택 모델의 전체 시험 기록은 시작 모델의 기록과 동일하다. 기준 모델의 adapter도 변경되지 않았다.

## 마지막 가중치의 별도 진단

학습 중 무엇이 달라졌는지 보기 위해 채택 여부와 별개로 600스텝 마지막 가중치를 평가했다. 기본 17조건에는 이번 새 64값과 잡담 배치 하나를 사용했다. 다른 화자의 간섭은 16번으로 늘렸고, 시험 전용 정정 표현도 일반 잡담과 16번 간섭 조건에서 검사했다.

`I changed ...`는 이번에 학습한 표현임을 명시해 재검사했다. 가장 처음의 이전 64값 정정/보존 시험과 단일 사실 유지 검사도 원래 seed 7019/5019로 다시 실행했다.

이 진단의 목적은 조건별 학습 전후 차이와 동일 seed의 CE 대조 차이를 남기는 것이다. **마지막 시험 점수를 보고 선택 가중치를 다시 고르지는 않는다.**

기본 새값 진단은 조건별 64사례지만 선택 모델의 주 시험은 128사례다. 서로 다른 표본의 점수를 빼서 전후 변화로 계산하지 않는다. 마지막 가중치의 비교 대상은 반드시 같은 진단 원문을 읽은 초기 모델이다.

### 새 64값의 기본 조건 — 마지막 가중치 진단

각 행은 64사례의 **LM 전체 어휘 단일 토큰 최고 확률 선택 정확도**다. 8지선다 점수로 대신하지 않는다. CE 대조의 시작 점수는 seed 17 KL 열의 시작 점수와 같다.

| 조건 | seed 7 시작 → KL 마지막 | seed 17 시작 → KL 마지막 | CE 대조 마지막 seed 17 |
| --- | ---: | ---: | ---: |
| 단일 사실 | 71.88% → 78.13% | 65.63% → 71.88% | 70.31% |
| 본인 정정 | 78.13% → 78.13% | 87.50% → 82.81% | 78.13% |
| 정정 표현 없는 본인 값 변경 | 81.25% → 81.25% | 84.38% → 82.81% | 87.50% |
| 본인 두 번 정정 | 71.88% → 73.44% | 76.56% → 73.44% | 70.31% |
| 다른 화자의 세 사실 | 78.13% → 79.69% | 85.94% → 82.81% | 82.81% |
| 정정 뒤 다른 화자의 세 사실 | 76.56% → 76.56% | 84.38% → 79.69% | 78.13% |
| 후보 단어 언급 여덟 번 | 73.44% → 78.13% | 75.00% → 84.38% | 85.94% |
| 다른 화자의 후보 사실 여덟 번 | 62.50% → 73.44% | 62.50% → 64.06% | 67.19% |
| 다른 화자의 한 값 여덟 번 반복 | 75.00% → 78.13% | 82.81% → 76.56% | 75.00% |

`is now`의 개선은 **이미 학습한 표현을 새 답 값에 적용한 전이**다. 학습하지 않은 표현에 성공한 결과는 아니다. seed 17의 CE 대조도 71.88%까지 올랐으므로 이 큰 개선을 KL 제약만의 효과라고 볼 수 없다.

반대로 `from now on`은 학습에 넣었는데도 두 seed에서 일부 성능이 낮아졌다. 표현 종류를 늘리는 것만으로 모든 표현이 함께 개선되지는 않았다.

### 16번 간섭·시험 전용 표현 — 마지막 가중치 진단

각 행 64사례다. 앞 세 행은 학습/검증의 여덟 번보다 강한 16번 간섭이다. 시험 전용 두 표현의 경쟁 조건도 16번이다. 마지막 두 행은 이번에 **학습한** changed 표현을 다른 원문/세 사실 조합으로 재검사한 것이다.

### 처음의 이전 64값 회귀 — 마지막 가중치 진단

각 행은 이전 정정 보고서와 동일 입력의 128사례다. 마지막 세 모델의 reference 평가 기록이 원래 정정 보고서의 선택 평가 기록과 일치한다.

| 조건 | seed 7 시작 → KL 마지막 | seed 17 시작 → KL 마지막 | CE 대조 마지막 seed 17 |

seed 7은 이 이전 시험의 모든 조건을 유지하거나 개선했다. 하지만 검증과 새 표현 조건에서는 하락했으므로 채택 기준을 통과한 것은 아니다. seed 17에서는 KL이 CE 대조보다 일부 회귀를 줄였지만, 이전 값 변경은 여전히 **6.25%p 하락**했다. 같은 KL 모델의 새 사실·간섭·표현 점수도 모두 좋아진 것은 아니다.

### 기억 개입·그룹별 비교

마지막 가중치를 33조건·2,560사례로 검사했을 때 **빈 기억의 전체 어휘 정확도는 세 모델 모두 모든 조건에서 0%**였다. 교환 기억의 최고 정확도는 두 KL 모델이 3.13%, CE 대조가 6.25%였다. 원래 대화의 기억이 답에 기여한다는 증거이지만, 자동 저장 중요도나 반환 시점을 검증한 결과로 확대하지 않는다.

모든 평가 전후의 어댑터는 동일했다. 기준/마지막 모델과 KL/CE 모델을 비교할 때의 입력 해시도 일치했다.

불확실성은 8개 답 그룹 단위의 부트스트랩으로 확인했다. `is now`의 시작 대비 개선 95% 탐색적 구간은 KL seed 7: **+51.56~+81.25%p**, seed 17: **+57.81~+85.94%p**였다.

seed 17의 KL 모델은 CE 대조보다 기존 값 변경 점수가 +3.91%p 높았지만, 구간은 **−1.56~+12.50%p**로 0을 포함했다. KL이 회귀를 확실히 해결했다고 결론내리지 않는 이유다. 표본이 작고 다중 비교 보정은 하지 않았다. 기본 진단·표현·긴 간섭은 그룹당 잡담 배치 하나를, 이전 값 회귀는 두 배치를 함께 묶어 계산했다.

선택된 초기 모델의 기존 8값 전이 원문도 재검사했다. 결과가 원래 정정 모델의 전체 조건 기록과 동일하며, 600스텝 마지막 가중치의 결과로 혼동하지 않는다.

## 검증 범위와 산출물

신규 39개 검사를 포함해 전체 **641개가 통과했고**, 기존 requires-grad scalar 경고 1개가 남았다. 입력의 반사실 균형, 표현 분리, 미래 원문 누출 방지, 기준 모델의 고정, 위치 표시와 독립인 CE/KL, 실제 입력 재생성, 샘플·내용 토큰 예산을 검사했다. 조건별 선택 기준과 마지막 가중치/선택 가중치의 구분도 확인했다.

codecanvas에는 실험 함수가 색인되지 않았다. 따라서 정적 흐름 증거 대신 실제 CPU/GPU 실행과 회귀 검사로 검증했다.

가중치/주 기록은 `local-data/stream-rmt-retention-kl-seed{7,17}.{pt,json}`과 `stream-rmt-retention-ce-seed17.{pt,json}`이며, `-last.pt`는 별도 최종 가중치다. `stream-rmt-retention-manifest.json`에는 이전 manifest SHA-256과 예약한 값이 있다. `stream-rmt-retention-comparison.json`은 선택·입력·예산 감사, `stream-rmt-retention-last-stress-*.json`은 마지막 가중치의 read-only 진단, `stream-rmt-retention-last-comparison.json`은 그룹별 전후/대조 비교다. 기존 8값 원문은 `stream-rmt-retention-transfer-kl-seed{7,17}.json`으로 별도 보존한다. 실행기는 출력 덮어쓰기를 거부하고 이전 파일과 사용자 수정을 보존한다.

여전히 인공 단일 사실 과제다. 여러 사실·실제 사람 대화·자동 저장 중요도·기억 텍스트 반환·`NO_MEMORY`/반환 타이밍은 검증하지 못했다. 이번 실패로 읽기/쓰기/gate 중 어느 하나가 원인이라고 분리 확정할 수도 없다.

```sh
HF_HUB_OFFLINE=1 TRANSFORMERS_OFFLINE=1 .venv/bin/python run_stream_memory_retention.py --manifest local-data/stream-rmt-retention-manifest.json --warm-start local-data/stream-rmt-revision-clean-seed17.pt --seed 17 --steps 600 --kl-weight 0.25 --output local-data/retention-reproduction-seed17.json
```

재현 대조는 새 출력 이름과 `--kl-weight 0`을 사용한다. 다른 값이나 방법으로 학습하려면 이번 시험 기록을 새로운 미사용 시험으로 취급하지 않는다.
