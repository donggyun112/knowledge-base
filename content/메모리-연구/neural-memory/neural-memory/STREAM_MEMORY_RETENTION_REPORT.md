# 정정 표현 다양화·출력 유지 제약 실험 — 2026-09-27

## 결론

**이번 추가 학습판은 채택하지 않았다.** 세 실행 모두 600스텝의 학습 과정에서 17개 검증 조건의 시작 정확도를 전부 유지하는 후보를 만들지 못했다. 새 표현의 정확도나 평균 답 손실이 개선돼도 기존 정정·간섭 조건이 하락하면 제외했다. 따라서 선택 가중치는 세 실행 모두 **초기 정정 모델(선택 스텝 0)**이다. 마지막 600스텝 가중치는 진단용으로 따로 보존하며 선택 모델과 혼동하지 않는다.

마지막 가중치의 별도 시험에서는 학습한 `is now ...` 표현의 새 값 정확도가 두 KL 모델에서 **1.56% → 70.31%/75.00%**로 크게 개선됐다. 그러나 seed 17은 같은 새 값의 본인 정정이 **87.50% → 82.81%**, 이전 값 변경은 **82.03% → 75.78%**로 하락했다. 미학습 `The secret word I use now is ...`도 **75.00% → 64.06%**였다. 표현/새 값의 학습은 가능했지만 조건 전체의 유지에는 실패했다. 이 수치들은 선택되지 않은 마지막 가중치의 진단이다.

이것은 이번 학습 분포·학습률·제약 강도·예산의 실패다. 이 구조가 원천적으로 학습 불가능하다는 증거도, 전체 메모리 연구의 완료도 아니다. 이전 [[메모리-연구/neural-memory/neural-memory/STREAM_MEMORY_BALANCE_REPORT|반복 간섭 균형 실험]]의 실패 기록과 가중치는 그대로 남겼다.

## 바꾼 것과 유지한 것

직전 균형 실험의 가중치를 이어 쓰지 않고, `stream-rmt-revision-clean-seed{7,17}.pt`에서 각각 출발했다. frozen SmolLM2-135M 본체·LM head와 같은 Q/V 저차원 갱신, bridge/gate/shared write query, **568,513개 학습 파라미터**, **8×576 잠재 상태(18 KiB, float32)**를 사용한다. 독립 대화 상태는 0에서 시작한다. 외부 KV 기록·검색·수동 화자별 저장·중요도/정정 라벨·tool 문법은 추가하지 않았다.

기존 11개 보존/정정/간섭 조건에 아래 세 표현을 추가했다. 각각 정정 후 일반 잡담과 정정 후 다른 화자의 후보 사실 여덟 번을 조합해 여섯 조건을 만든다. 상황 이름은 metadata에만 있고 입력 헤더는 기존의 무작위 숫자를 유지한다.

```text
Me: I changed my secret word to ...
Me: My secret word is now ...
Me: From now on, my secret word is ...
```

**`I changed ...`는 이번부터 학습 표현이다.** 이전 보고서에서 미학습 표현이었던 사실을 그대로 이번 일반화 성공으로 재사용하지 않는다. 이번의 시험 전용 표현은 `Me: My new secret word is ...`, `Me: The secret word I use now is ...`다. 이 두 표현은 가중치 학습이나 검증 선택에 넣지 않았다.

## 출력 유지 제약과 대조

새 학습의 17조건 8,704대화와 기존 여섯 정정/보존 조건의 재학습 3,072대화를 준비했다. 매 스텝 두 쪽에서 각각 batch 2를 뽑아, 마지막 미래 구간의 **모든 대화 내용** next-token CE를 계산한다. 손실의 토큰 가중 평균은 다음과 같다.

```text
L = (CE_new_sum + CE_replay_sum) / (N_new + N_replay)
    + 0.25 × mean_KL_on_replay_content
```

유지 제약의 기준 모델은 시작 가중치의 독립 복사본이다. 모든 파라미터를 고정하고, 자기의 0 상태에서 기존 여섯 조건의 실제 토큰을 읽어 만든 다음 토큰 분포를 사용한다. 학생과 기준 모델의 LM 전체 어휘 분포 사이 KL을 **재학습 대화의 모든 미래 내용 토큰**에 적용한다. 기준 모델의 출력이 항상 정답이라는 가정은 하지 않는다.

어느 모델에도 사실 위치나 정답 토큰을 상태에 넣어 주지 않는다. 사실/답 위치 metadata를 바꿔도 CE/KL이 동일한지, 미래 답 입력을 바꿔도 예측 logits가 동일한지 검사했다. 기준 모델은 학습 중 손실을 계산하는 용도이고 **추론용 가중치에는 저장하지 않는다.** 마지막 기준 모델의 adapter 동일성과 gradient 부재도 확인한다.

seed 7/17에 KL 0.25를 적용하고, seed 17에 KL 0인 CE 대조를 실행했다. 대조 역시 동일한 재학습 대화를 읽는다. 동일 시작점·학습/검증/시험 입력·샘플 순서·CE 내용 토큰 예산·batch/lr·최대 스텝으로 비교하며, KL 기준 모델의 추가 연산 때문에 **동일 FLOPs/벽시간 대조는 아니다.** Apple MPS GPU/float32, lr 0.00005, gradient norm 1 clipping, 최대 600스텝을 사용했다. 컴퓨터 절전으로 중간 정지 후 재개됐지만 스텝·선택 기준은 바꾸지 않았다.

실제 학생 CE 손실 토큰 수를 샘플 순서로 재계산해 기록과 일치함을 확인했다.

| 실행 | 새 대화 CE 토큰 | 재학습 대화 CE 토큰 | 합계 |
| --- | ---: | ---: | ---: |
| KL seed 7 | 10,892 | 10,545 | 21,437 |
| KL seed 17 | 10,580 | 10,434 | 21,014 |
| CE 대조 seed 17 | 10,580 | 10,434 | 21,014 |

## 새 값과 엄격한 검증

같은 MSC train 단어 빈도·512후보·seed 9013의 분리를 연장했다. 이전 train 256값·valid 32값·probe 8값·이전 시험 128값을 보존하고, 그 다음 **64개 값**을 이번 시험으로 예약했다. 새 답 값은 학습·검증 답이나 옛값/다른 화자의 사실 값으로 사용하지 않았다. 단어는 사전학습 LM에는 익숙할 수 있고, 실제 사람 대화를 학습한 것은 아니다.

검증은 32값 × 17조건 = **544사례**, 100스텝마다 평가했다. 어떤 조건도 시작점의 전체 어휘 정확도보다 하락하지 않아야 한다. 이전 단계의 1/32 허용 하락을 이번에는 **0으로 고정**했다. 통과 후보 중 최저 조건 정확도, 다음으로 평균 답 NLL을 사용한다. 초기 모델도 후보이며 시험은 학습과 선택을 완료한 다음 구성·평가한다. 이 선택 규칙은 신경망의 저장/갱신 규칙이 아니다.

seed 17의 300스텝 KL 실행은 17조건 중 16개 점수를 유지했지만 본인 정정이 **87.50% → 84.38%**로 내려가 제외했다. 같은 시점 `is now` 표현은 검증에서 **0% → 68.75%**로 개선됐다. 개선 자체와 조건별 유지 실패를 함께 기록한다. 검증을 통과하지 못했다고 학습 변화가 없었다는 뜻은 아니며, 반대로 새 표현 학습만으로 균형 목표를 달성했다고도 하지 않는다.

| 실행 | 600스텝에서 시작점보다 하락한 검증 조건 | 선택 스텝 |
| --- | --- | ---: |
| KL seed 7 | 본인 값 변경, 본인 두 번 정정, 정정 뒤 후보 사실 여덟 번 | 0 |
| KL seed 17 | 본인 정정, 본인 두 번 정정, 다른 화자의 세 사실, 다른 화자의 한 값 반복, changed, fromnow | 0 |
| CE 대조 seed 17 | 본인 두 번 정정, 후보 단어 언급, 다른 화자의 한 값 반복, changed | 0 |

각 실행의 100~600스텝 **여섯 후보 모두** 탈락했으며, 평균 손실이 낮은 후보로 소급 바꾸지 않았다. 새 시험은 17조건 × 64값 × 두 잡담 배치 = **2,176사례**, 시험 전용 표현은 네 조건 × 64값 = **256사례**다. 직전 균형 단계의 새 64값도 동일 원문 1,408사례로 다시 평가한다. 선택 모델은 초기 모델이므로 추가 학습의 성공으로 이 시험 점수를 제시하지 않는다.

입력·샘플/내용 토큰 예산·선택 과정을 재생성해 세 실행 모두 일치함을 확인했다. 선택 `.pt`의 모든 adapter 텐서도 원래 시작 `.pt`와 정확히 같았다. 선택 모델의 전체 시험 기록은 시작 모델의 기록과 동일하다. 기준 모델의 adapter도 변경되지 않았다.

## 마지막 가중치의 별도 진단

600스텝 마지막 가중치는 선택 판정과 분리해서 평가한다. 기본 17조건은 이번 새 64값과 잡담 배치 하나를 사용한다. 다른 화자의 간섭은 16번으로 늘리고 시험 전용 정정 표현도 일반 잡담/16번 간섭으로 검사한다. `I changed ...`는 이번에 학습한 표현으로 명시해서 별도 재검사한다. 가장 처음의 이전 64값 정정/보존 시험과 단일 사실 유지 검사도 원래 seed 7019/5019로 재사용한다.

이 진단은 조건별 모델 전후 비교와 동일 seed의 CE 대조 비교를 남기기 위한 것이며 **최종 시험 점수로 선택 가중치를 다시 정하지 않는다.** 기본 새값 진단은 조건별 64사례, 선택 모델의 주 시험은 128사례이므로 서로 다른 표본의 점수를 직접 전후 변화로 계산하지 않는다. 마지막 가중치는 같은 진단 원문을 읽은 초기 모델과 비교한다.

seed 7은 이 이전 시험의 모든 조건을 유지/개선했지만, 검증 및 새 표현 조건에서 하락했으므로 채택 기준을 통과한 것은 아니다. seed 17은 KL이 CE 대조보다 일부 회귀를 줄였다. 그러나 이전 값 변경은 여전히 **6.25%p 하락**했고, 같은 KL 모델의 새 사실/간섭/표현 점수도 전부 좋아지지는 않았다.

### 기억 개입·그룹별 비교

마지막 가중치의 33조건·2,560사례에서 **빈 기억의 전체 어휘 정확도는 세 모델 모두 모든 조건 0%**였다. 교환 기억의 최고 정확도는 두 KL 모델 3.13%, CE 대조 6.25%였다. 원래 대화의 기억이 답에 기여하는 것은 확인하지만 자동 저장 중요도나 반환 타이밍의 검증으로 확장하지 않는다. 모든 평가 전후 adapter가 동일했고 기준/마지막 및 KL/CE 비교 입력 digest도 일치했다.

8개 답 그룹 단위 bootstrap을 사용했다. `is now`의 시작 대비 개선 95% 탐색적 구간은 KL seed 7: **+51.56~+81.25%p**, seed 17: **+57.81~+85.94%p**다. seed 17의 KL 모델은 CE 대조 대비 기존 값 변경이 +3.91%p 높았지만, 구간 **−1.56~+12.50%p**로 0을 포함한다. KL이 회귀를 확실히 해결했다고 결론내리지 않는다. 표본이 작고 다중 비교 보정은 하지 않았다. 기본 진단/표현/긴 간섭은 그룹당 잡담 배치 하나, 이전 값 회귀는 두 배치를 함께 묶었다.

선택된 초기 모델의 기존 8값 전이 원문도 재검사했다. 결과가 원래 정정 모델의 전체 조건 기록과 동일하며, 600스텝 마지막 가중치의 결과로 혼동하지 않는다.

## 검증 범위와 산출물

신규 39개 검사를 포함해 전체 **641 passed**, 기존 requires-grad scalar 경고 1개다. 입력 반사실 균형·표현 분리·미래 원문 누출 방지·기준 모델 고정·annotation 독립 CE/KL·실제 입력 재생성·샘플/내용 토큰 예산·조건별 선택·최종 가중치와 선택 가중치 구분을 검사한다. codecanvas에는 실험 함수가 색인되지 않아 정적 흐름 증거 대신 실제 CPU/GPU 실행과 회귀 검사를 사용했다.

가중치/주 기록은 `local-data/stream-rmt-retention-kl-seed{7,17}.{pt,json}`과 `stream-rmt-retention-ce-seed17.{pt,json}`이며, `-last.pt`는 별도 최종 가중치다. `stream-rmt-retention-manifest.json`에는 이전 manifest SHA-256과 예약한 값이 있다. `stream-rmt-retention-comparison.json`은 선택·입력·예산 감사, `stream-rmt-retention-last-stress-*.json`은 마지막 가중치의 read-only 진단, `stream-rmt-retention-last-comparison.json`은 그룹별 전후/대조 비교다. 기존 8값 원문은 `stream-rmt-retention-transfer-kl-seed{7,17}.json`으로 별도 보존한다. 실행기는 출력 덮어쓰기를 거부하고 이전 파일과 사용자 수정을 보존한다.

여전히 인공 단일 사실 과제다. 여러 사실·실제 사람 대화·자동 저장 중요도·기억 텍스트 반환·`NO_MEMORY`/반환 타이밍은 검증하지 못했다. 이번 실패로 읽기/쓰기/gate 중 어느 하나가 원인이라고 분리 확정할 수도 없다.

```sh
HF_HUB_OFFLINE=1 TRANSFORMERS_OFFLINE=1 .venv/bin/python run_stream_memory_retention.py --manifest local-data/stream-rmt-retention-manifest.json --warm-start local-data/stream-rmt-revision-clean-seed17.pt --seed 17 --steps 600 --kl-weight 0.25 --output local-data/retention-reproduction-seed17.json
```

재현 대조는 새 출력 이름과 `--kl-weight 0`을 사용한다. 다른 값이나 방법으로 학습하려면 이번 시험 기록을 새로운 미사용 시험으로 취급하지 않는다.
