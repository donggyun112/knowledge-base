# 메모리 모델 재설계 실험 보고 (2026-09-25 KST)

## 목표와 합격 기준

사람 대화의 과거 세션을 텍스트 토큰으로 읽고, 에피소드마다 **0에서 시작하는 신경망 내부 상태**를 갱신해 나중의 발화를 예측한다. 외부 임베딩 검색, 명시적 key/value 기록, 도구 호출 문법은 쓰지 않는다. 과거 전체를 프롬프트에 넣는 실험은 학습 모델이 아니라 정보가 존재하는지 확인하는 상한선이다.

주요 판정값은 미래 발화의 정답 토큰 평균 음의 로그우도(NLL) 차이다. 양수이면 자기 과거가 유리하다. 성공하려면 `빈 상태 − 자기 상태`와 `타인 상태 − 자기 상태`가 모두 양수이고, 미사용 대화에서도 재현되어야 한다. 검증 중 여러 설계를 시도했고 기존 MSC test split도 이미 반복 확인했으므로 아래 수치는 탐색적이다.

인공적인 단일 토큰 지연 복사에서는 자기 상태 정답률 100%, 타인 상태 0%였다. 따라서 신경망의 쓰기→지연 읽기 경로 자체는 작동한다. 반면 실제 발화 한 문장을 뒤늦게 이어 맞히는 양성 대조는 실패했다. 이는 현재 압축·학습 방식이 자연어 내용을 보존하지 못한다는 더 직접적인 경고다.

## 구현과 재현

- [[메모리-연구/neural-memory/neural-memory/RESTART_SPEC|재시작 설계]]: 엄격한 빈 상태, 내용 토큰만 채점, 상태 교환·노이즈·인과성 대조.
- 원시 사람 대화 오라클 (`eval_msc_history_oracle.py`; 원 저장소의 파일 참조): 동일한 현재 대화와 정답에 자기/타인/빈 과거만 교체해 고정 언어모델의 NLL을 비교.
- 처음 순환 메모리 (`neural_memory/recurrent_dialogue_memory.py`; 원 저장소의 파일 참조), 학습기 (`run_restarted_msc_memory.py`; 원 저장소의 파일 참조): 텍스트 토큰의 순환형 잠재 상태. 발화당 최대 48토큰, 8개 상태 위치, 폭 96. Apple MPS GPU에서 학습.
- 사전학습 기반 메모리 (`neural_memory/frozen_lm_memory.py`; 원 저장소의 파일 참조), 학습기 (`run_frozen_lm_memory.py`; 원 저장소의 파일 참조): 고정된 SmolLM2의 내부 토큰 상태를 최대 512개 과거 토큰에서 64토큰 단위로 읽고, 256차원 순환 상태 하나에 압축. 미래 국소 문맥은 별도 인코딩. 압축 상태만으로 예측을 보정하며 언어모델 가중치는 고정.
- 선택적 토큰 메모리 (`neural_memory/selective_token_memory.py`; 원 저장소의 파일 참조), 학습기 (`run_selective_msc_memory.py`; 원 저장소의 파일 참조): 과거 토큰 상태가 8개 잠재 슬롯에 경쟁적으로 쓰고, 미래 문맥이 슬롯을 선택해 읽음. 구간을 실제로 제거했을 때 정답 NLL이 악화되는 정도로 쓰기 점수를 지도하는 실험을 포함한다. 본 실험은 계산상 16토큰마다 하나의 상태를 사용했다. 모든 토큰을 입력하는 모드(`--token-stride 1`)는 소규모 실행 검사만 통과했으며 성능이 검증된 것은 아니다.
- 실제 수치 원본: `local-data/restart-oracle-test-96.json`, `local-data/restart-oracle-smollm-valid-96.json`, `local-data/restart-future-turn-seed7.json`, `local-data/frozen-lm-memory-distill-largeeval-seed7.json`, `local-data/frozen-lm-memory-scaled-seed7.json`, `local-data/selective-token-pilot-seed7.json`, `local-data/selective-token-ablation-seed7.json`, `local-data/selective-token-no-salience-seed7.json`.

## 현재 판단

데이터 부족만으로 실패를 설명하기 어렵다. 같은 데이터의 과거 전체를 직접 읽으면 두 사전학습 모델 모두 타인 과거보다 유의하게 낫지만, 현재 압축 메모리는 그 차이를 안정적으로 보존하지 못한다. 1200→2000개 학습 대화, 256→512차원 상태로 확장해도 이 결론이 바뀌지 않았다. 선택적 쓰기·질의별 읽기와 구간 제거 기반 쓰기 지도를 추가해도, 현재 400쌍 파일럿에서는 학습 밖 대화의 개인별 이득이 확인되지 않았다. 특히 빈 상태와의 비교만으로는 개인 기억을 주장할 수 없다. 구간 제거 지도는 실제 입력 변경의 효과지만 토큰 삭제에 따른 문맥 길이 변화도 섞여 있으므로 정확한 기여도 라벨이라고 단정할 수 없다.

최종 전체 테스트는 `422 passed, 1 warning`이었다. 경고는 기존 `test_trainable.py`의 기울기 추적 텐서를 실수로 변환하는 코드에서 나왔으며 이번 메모리 실험 실패와는 별개다.

## 2026-09-26 추가: 같은 읽기 통로의 원인 분리

[[메모리-연구/neural-memory/neural-memory/MEMORY_PATH_DIAGNOSTIC_REPORT|별도 진단 보고]]에서 동일한 residual 읽기를 쓰는 단일 사실 지연 회상 양성 대조를 수행했다. 정확한 과거 근거 오라클은 100%, 모든 토큰을 받는 순환 쓰기는 두 seed에서 약 90%를 맞혔다. 따라서 앞의 자연어 실패를 읽기 구조의 원천적 불가능성이나 압축만의 문제로 단정할 수 없다. 전체 과거 프롬프트 오라클과 residual 메모리는 원래 서로 다른 읽기 경로이기도 했다.

같은 seed·400스텝·사전학습 없는 메모리에서 모든 토큰 입력은 93.23%, 16토큰 간격은 12.50%였다. 2000스텝에서도 각각 83.85%, 17.71%였다. 이는 인공 양성 대조에서의 입력 간격과 노이즈 일반화 문제를 보여주지만 실제 MSC 실패의 원인을 확정하지는 않는다. 자동 저장 판단·반환 타이밍·다중 사실 기억은 미검증이다. 추가 검사를 포함한 최신 전체 테스트는 `430 passed, 1 warning`이다.
