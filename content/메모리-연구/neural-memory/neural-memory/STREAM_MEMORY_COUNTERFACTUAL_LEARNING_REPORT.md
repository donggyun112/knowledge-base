# 반사실 미래 대화 손실과 중간 구간 획득 진단 — 2026-09-28

## 결론

이번에는 질문과 잡담은 같고 과거의 단어만 다른 8개 대화를 묶어 학습했다. 관측된 미래 대화 내용 전체를 **다른 대화의 상태보다 자기 상태에서 더 잘 예측하도록** 대조 손실을 추가했다. 사실·정답 위치나 저장 중요도 라벨은 손실에 쓰지 않았다.

짧은 거리에서는 자기 대화와 다른 대화의 정보를 구별하도록 학습됐지만, 긴 거리와 새로운 사실 위치로 안정적으로 일반화하지는 못했다. 또한 이런 반사실 묶음은 인공적으로 짝지어 제공한 추가 정보다. 따라서 사람 대화만으로 자동 기억을 배웠다는 결과도 아니다.

가장 중요한 발견은 단순한 망각보다 **중간 구간에서 새 사실을 받아들이지 못하는 문제**였다. 사실·질문·최종 입력을 같게 유지해도 잡담을 사실 앞에 넣으면 정보가 사라지고, 훨씬 많은 잡담을 사실 뒤에 넣으면 유지됐다. 이 양상은 첫 구간에서 기억을 강제로 채운 뒤 이후에는 작은 게이트로만 갱신하는 현재 설계와 맞는다.

## 손실과 맞춘 비교

새 `counterfactual_future_loss`는 완전한 8-way 반사실 묶음의 앞 구간을 시간순으로 처리한다. 이후 마지막 구간의 모든 대화 내용 토큰에 대해 자기 상태와 한 칸씩 교환한 상태의 전체 어휘 교차엔트로피(CE)를 각각 계산한다. 각 사례의 `max(0, 0.2 + 자기 CE − 교환 CE)`를 평균하고 가중치 2를 곱해 원래 CE에 더한다.

이 비교에서는 마지막 구간의 현재 텍스트는 같고 이전 기억 상태만 달라진다. 답 토큰만 따로 고르거나 손실을 8개 후보로 제한하지 않는다. 학습 함수의 `fact_position`, `answer_position`, `target`을 바꿔도 손실이 같다는 테스트를 통과했다.

SmolLM2-135M을 고정하고 순환 8×576 상태, 구간 뒤쪽 쓰기 위치와 공유 질의, 게이트 초기값 0.01, 잔차 읽기 구조, rank 0을 사용했다. 실행 환경은 Apple MPS/float32, seed는 41이다. 짧은 잡담 0·1턴에 마지막 뒤잡담 1턴을 더했으며, 자료는 학습 16블록·검증 4블록·긴 시험 12블록으로 나눴다.

학습량은 400스텝이며 두 조건은 매 스텝 같은 8개 대화 묶음을 선택했다. 초기화와 묶음 추출 순서를 맞추고, 검증에서 자기 상태를 사용한 전체 어휘 NLL로 체크포인트를 골랐다.

| 짧은 단계 손실 | 검증 자기/교환 8-way | 검증 자기 전체 어휘 | 별도 긴 테스트 자기/교환 8-way | 긴 테스트 자기 전체 어휘 |
| --- | --- | ---: | --- | ---: |
| 미래 대화 CE만 | 12.50% / 12.50% | 12.50% | 11.46% / 12.50% | 11.46% |
| CE + 반사실 대조 | 93.75% / 0% | 90.63% | 28.13% / 9.38% | 9.38% |

대조 손실을 추가하자 짧은 과제에서 대화별 정보를 사용하는 능력이 생겼다. 긴 시험에서도 상태를 교환하면 답이 기억을 제공한 대화의 단어 쪽으로 움직였다. 다만 28.13%는 아직 낮고 전체 어휘 출력 정확도는 그보다 더 낮다. 빈 상태의 12.5%는 8지선다에서의 우연 기준이며 자유 텍스트 답변 정확도가 아니다.

## 긴 거리 이어 학습과 새 잡담

긴 거리에서도 효과가 이어지는지 확인하려고 위 대조 손실로 학습한 짧은 단계 체크포인트를 **공통 시작점**으로 삼았다. 긴 잡담 2·4·8턴과 뒤잡담 3턴으로 400스텝 추가 학습하되, 한 조건은 대조 손실을 유지하고 다른 조건은 CE만 썼다. 그러나 선택된 두 모델 모두 긴 검증의 8지선다는 12.5%였다. 안정적으로 일반화됐다고 판정할 수 없는 결과다.

| 이어 학습 손실 | 기본 긴 테스트 자기/교환 8-way | 기본 긴 테스트 전체 어휘 | 새 잡담 8·16턴 자기/교환 8-way | 새 잡담 32·64턴 자기/교환 8-way |
| --- | --- | ---: | --- | --- |
| 대조 유지 | 33.33% / 9.38% | 16.67% | 34.38% / 9.38% | 12.5% / 12.5% |
| CE만 | 29.17% / 9.38% | 19.79% | 20.83% / 10.42% | 12.5% / 12.5% |

새 잡담 8·16턴에서 대조 손실 조건은 12블록 중 3블록의 8개 단어를 모두 맞혔지만, 나머지 9블록은 전부 12.5%였다. 블록 부트스트랩으로 구한 자기 정확도의 95% 구간은 [12.5%, 56.25%]로 우연 수준을 포함했다.

대조 손실 유지와 CE만 사용한 조건의 짝지은 8지선다 정확도 차이는 13.54%p였으나, 95% 구간 [0, 33.33%p]에도 0이 포함됐다. 32·64턴에서는 둘 다 우연 수준이었다. 따라서 대조 손실이 언제나 더 낫다고 결론내리지 않는다.

## 같은 입력의 위치 개입

위치에 따른 실패를 분리하려고 대조 손실을 유지한 긴 단계 체크포인트에서 시험 블록 하나를 고정했다. 정답 후보가 없는 동일한 31토큰 잡담 블록을 사실 **앞** 또는 **뒤**에만 추가하고, 최종 질문 구간과 구간 안의 사실 위치는 바꾸지 않았다.

이는 한 인공 블록에서 잡담 위치의 영향을 따로 보는 인과 진단이다. 일반 모집단의 정확도를 측정하는 시험은 아니다.

| 추가 잡담 | 사실 앞 자기/교환 정확도 | 사실 뒤 자기/교환 정확도 |
| ---: | --- | --- |
| 0블록 | 100% / 0% | 100% / 0% |
| 4블록 | 12.5% / 12.5% | 100% / 0% |
| 32블록 | 12.5% / 12.5% | 100% / 0% |

사실 앞에 4블록을 넣자 질문 직전의 대화별 상태 차이(RMS)는 `1.34e-7`까지 줄었다. 사실 뒤에 32블록을 넣은 경우의 차이는 `0.444`였다. 새 잡담 8·16턴에서 전부 맞힌 3블록도 모두 사실이 첫 31토큰 구간에 있었고, 나머지는 사실이 뒤 구간에 있었다.

즉 현재 체크포인트에는 **첫 구간의 사실을 주로 획득하는 편향**이 강했다. 단지 시간이 오래 지나 잊었다는 설명으로는 이 차이를 설명하기 어렵다.

게이트를 조금 더 열면 해결되는지도 따로 검사했다. 초기값을 0.01에서 0.1로 올리고 처음부터 긴 거리 대조 학습을 400스텝 진행했지만, 긴 검증의 최고 정답률은 12.5%였다. 같은 위치 개입에서는 사실 앞 4블록이 12.5%, 사실 뒤 32블록이 50%였다.

초기 게이트를 조금 더 여는 것만으로는 중간 구간의 새 사실을 안정적으로 얻지 못했다. 다만 두 초기값 조건은 같은 시작 가중치를 사용한 비교가 아니므로 게이트 효과만을 엄격하게 추정한 결과는 아니다.

## 후속 실험: 첫 구간 강제 기록 제거

기존 `gated` 갱신은 빈 상태에서 처음 만나는 비어 있지 않은 구간의 게이트를 무조건 1로 설정했다. 이 예외가 첫 구간 편향을 만드는지 확인하려고 `--no-force-first-write`를 추가했다. 이 옵션을 켜면 첫 구간도 나머지 구간과 같은 학습 게이트를 통과한다. 기본값은 기존 동작을 유지해 이전 체크포인트와 호환된다.

두 비교 조건은 게이트 초기값 0.1, seed 41, 긴 잡담 자료·배치·400스텝·손실·검증 NLL 선택을 모두 맞췄다. 초기 파라미터와 샘플 추출도 같고 옵션만 다르다. 다만 단일 seed의 탐색적 실험이라는 한계는 남는다.

| 강제 첫 기록 | 긴 검증 자기/교환 8-way | 기존 긴 테스트 자기/교환 8-way | 테스트 전체 어휘 | 새 잡담 8·16턴 자기/교환 8-way | 새 잡담 32·64턴 자기/교환 8-way |
| --- | --- | --- | ---: | --- | --- |
| 켬 | 12.50% / 12.50% | 34.38% / 9.38% | 33.33% | 27.08% / 10.42% | 12.50% / 12.50% |
| 끔 | 65.63% / 3.13% | 50.00% / 8.33% | 46.88% | 44.79% / 9.38% | 17.71% / 12.50% |

새 잡담 8·16턴의 동일 12개 블록에서 짝지은 정확도 차이는 **+17.71%p**, 블록 부트스트랩 95% 구간은 **[+5.21,+34.38]%p**였다. 고정된 합성 블록에 대한 탐색적 불확실성이므로 다른 대화 분포나 seed에서도 같은 효과가 난다는 보장은 아니다.

핵심 변화는 첫 구간 뒤의 사실도 일부 획득하기 시작했다는 점이다. 사실이 토큰 37, 즉 두 번째 32토큰 구간에 있는 새 블록은 기존 모델 1/8에서 변경 모델 8/8로 올랐다. 사실이 토큰 87인 블록도 1/8에서 4/8로 개선됐다.

같은 사실과 질문을 둔 채 31토큰 잡담을 앞뒤로 옮긴 한 블록 개입에서도 변화가 있었다. 사실 앞 **1블록**에서는 기존 모델 12.5%, 변경 모델 87.5%였지만, 앞 **2블록**부터는 변경 모델도 12.5%였다. 변경 모델은 사실 뒤 4블록에서 87.5%, 뒤 8블록에서 75%였다.

따라서 강제 첫 기록은 중간 획득 실패의 한 원인이었다. 이를 없애자 획득 가능한 경계가 한 구간 이상 늘었지만, 여러 구간이 지난 뒤에도 새 사실을 안정적으로 기록하는 수준은 아니었다. 뒤 16·32블록에서도 성능이 떨어져 보존 능력 역시 무한하지 않다. 긴 잡담 32·64턴은 여전히 우연 수준 근처였다.

## 후속 진단: 중간 구간 게이트 억제 — 2026-09-29

새 모델의 같은 8개 합성 대화에 동일한 31토큰 잡담 블록을 사실 앞에 0·1·2·4개 넣었다. 이번에는 사실이 들어 있는 구간의 게이트 출력을 관찰하고, 그 구간에서만 게이트를 강제로 열거나 직전 상태를 초기화했다.

이 비교는 게이트의 억제와 기존 상태의 간섭을 진단하기 위한 것이다. 어느 구간에 사실이 있는지 미리 알아야 가능한 개입이므로 실제로 사용할 수 있는 기억 정책은 아니다.

| 사실 앞 잡담 | 학습 게이트 평균 | 원래 8-way | 사실 구간 게이트만 강제 | 사실 직전 상태 초기화 |
| ---: | ---: | ---: | ---: | ---: |
| 0블록 | 0.605 | 87.5% | 100% | 87.5% |
| 1블록 | 0.180 | 87.5% | 75% | 87.5% |
| 2블록 | 0.072 | 12.5% | 62.5% | 87.5% |
| 4블록 | 0.052 | 12.5% | 62.5% | 87.5% |

사실 앞에 2블록이 있을 때 게이트만 강제로 열어도 대화별 상태 차이(RMS)가 0.018→0.206, 정답률이 12.5→62.5%로 올랐다. 새 기록 후보가 완전히 무정보인 것은 아니며, **앞선 잡담이 만든 상태 때문에 게이트가 닫히는 현상**이 중요한 병목이라는 뜻이다. 다만 강제 게이트에서도 100%를 맞히지는 못했으므로 기록 후보의 문제나 기존 상태 간섭을 배제할 수 없다.

기존 강제-첫-기록 모델은 2블록 뒤 게이트 평균이 0.003이었고 그 구간만 강제로 열어도 12.5%였다. 직전 상태를 초기화하면 50%로 회복돼 기존 모델에서 상태 간섭도 더 컸음을 보여 줬다. 이 결과는 한 블록의 인과 진단이며 일반 성능 추정은 아니다.

사실 위치를 몰라도 적용할 수 있는 대안으로, **추론 때 모든 구간의 게이트를 일정 값 이상 열어 두는 개입**을 시험했다. 같은 새 잡담 8·16턴 12블록에서 8-way 정확도는 게이트 하한 0에서 44.79%, 0.05에서 45.83%, 0.1에서 42.71%, 0.2에서 26.04%, 0.4에서 13.54%였다.

하한 0.1은 위 한 블록의 늦은 사실 정확도를 12.5→37.5%로 높였지만 전체 성능은 낮췄다. 늦은 사실 하나에 도움이 된다는 이유로 모든 구간의 게이트를 일괄 개방할 수는 없었다.

다음에는 게이트 구조를 그대로 두고, 학습 중 사실 뒤 잡담만 3턴→1턴으로 줄여 400스텝 다시 학습했다. 훈련 손실은 낮아졌지만 기존 길이의 선택 검증과 시험은 8-way 모두 12.5%였다. 더 짧은 1턴짜리 새 검증에서도 28.13%로 기존 모델의 56.25%보다 낮았다.

따라서 실패를 평가 거리의 차이만으로 설명할 수 없다. 단일 seed와 작은 합성 자료에서 일반화에 실패한 결과이며, 추가 재학습이 효과가 있었다고 주장하지 않는다.

진단 코드: `diagnose_stream_memory_acquisition.py`, `diagnose_stream_memory_gate_floor.py`, `eval_stream_memory_control_checkpoint.py`. 결과: `local-data/stream-rmt-cf-{gatedfirst,gate010}-directlong-seed41-acquisition.json`, `local-data/stream-rmt-cf-gatedfirst-directlong-seed41-gate-floor.json`, `local-data/stream-rmt-cf-gatedfirst-shortcredit-seed41.{json,pt}`, 두 모델의 `-valid-trail1.json`. 모두 합성 대화 진단이며 실제 사람 대화의 저장·반환 성능은 아직 검증하지 않았다.

## 후속 구조 대조: 이전 상태 억제와 비선형 게이트 — 2026-09-29

이전 상태가 게이트를 어떻게 억제하는지 보기 위해 학습된 **선형** 게이트의 입력을 사실 구간에서 분해했다. 사실 앞에 잡담 2블록이 있을 때 평균 로그잇 기여는 이전 상태 **−3.03**, 새 기록 후보 **+2.21**, 현재 토큰 요약 **+0.06**, 편향 **−2.19**였다.

사실 구간에서 이전 상태 항만 가리자 게이트 평균은 0.072→0.518, 그 한 블록의 8-way 정답률은 12.5→62.5%로 올랐다. 이전 상태 항이 강하게 억제한다는 직접적인 증거다. 그러나 사실 구간을 알고 하는 특권적 개입이므로 실제 모델 개선 수치로 취급하지 않는다.

이 억제를 사실 위치 정보 없이 줄여도 도움이 되는지 확인했다. **모든 구간**의 이전 상태 항을 1.0·0.75·0.5·0.25·0배로 줄였을 때 같은 새 잡담 8·16턴의 8-way 정확도는 각각 44.79·42.71·42.71·23.96·17.71%였다. 억제를 없애면 무관한 대화도 기록돼 성능이 크게 낮아졌다.

이에 추론 개입 대신 구조를 바꿔 처음부터 학습했다. 한 모델은 게이트에만 이전 상태를 직접 주지 않고 새 기록 후보는 계속 이전 상태를 보게 했다. 자료·손실·seed·400스텝을 같게 맞췄다. 또 다른 모델은 선형 합 대신 64차원 은닉층을 둔 비선형 게이트를 같은 조건으로 학습했다.

| 게이트 | 긴 검증 8-way | 기존 긴 테스트 8-way | 새 잡담 8·16턴 8-way | 위치 개입: 사실 앞 2블록 8-way |
| --- | ---: | ---: | ---: | ---: |
| 원래 선형 | 65.63% | 50.00% | 44.79% | 12.5% |
| 이전 상태 직접 입력 없음 | 28.13% | 20.83% | 14.58% | 25.0% |
| 비선형 MLP | 62.50% | 45.83% | 33.33% | 12.5% |

새 잡담 12블록에서 원래 모델과 짝지어 비교한 차이는 이전 상태 직접 입력 제거가 **−30.21%p**(블록 부트스트랩 95% 구간 [−50.0,−12.5]%p), MLP가 **−11.46%p**([−20.83,−2.08]%p)였다.

작은 표본과 후보를 반복 관찰한 합성 과제이므로 일반적인 모델 성능 순위로 확정할 수는 없다. 그러나 이 설정에서는 **이전 상태의 억제를 없애거나 게이트 용량만 늘리는 처방이 실패**했다. 기존 상태를 보호하는 기능과 새 사실을 선택적으로 받아들이는 기능을 함께 학습해야 한다. MLP는 파라미터화도 달라 선형 모델과 초기 가중치까지 완전히 같은 A/B 비교는 아니다.

새 옵션 `--gate-state-blind`, `--gate-arch mlp`는 기본값을 바꾸지 않고 체크포인트 설정에 저장된다. 결과: `local-data/stream-rmt-cf-gatedfirst-directlong-seed41-{acquisition-components,gate-state-scale}.json`, `local-data/stream-rmt-cf-gatedfirst-{stateblind,mlpgate}-directlong-seed41.{json,pt}` 및 각 `-position-dense.json`, `-stress.json`. 전체 테스트 **748개 통과**했다.

## 범위와 산출물

이 실험은 단일 인공 단어, 고정 질문, 같은 여덟 후보를 사용해 모델의 용량과 학습 경로를 진단한 것이다. 학습에 쓴 반사실 묶음은 실제 사람 대화 로그에 자동으로 존재하는 자료가 아니다.

## 여러 미래 거리로 학습한 후속 실험 — 2026-09-29

미래를 예측하는 거리도 다양화해 봤다. 기존 모델은 마지막 잡담 3턴만 예측하도록 학습했는데, 이번에는 seed 41·400스텝·반사실 묶음·게이트 구조를 그대로 두고 **학습 단계마다 마지막 잡담 길이를 1·3·6턴 중 하나로 선택**했다. 학습 사례와 잡담 단어는 같고 길이만 다른 변형을 사용했다.

길이 선택용 난수열을 별도로 두어 기존 블록 선택 순서를 보존했으며 길이별 학습 스텝은 각각 130·135·135회였다. 초기 상태에 사용자 개인 정보를 넣은 것은 아니다. 손실은 미래 내용 토큰 예측과 상태 교환 대조 손실을 사용했다. 구현은 `run_stream_memory_control.py`의 `--train-trailing-noise-choices`다.

| 평가 (8지선다 자기 상태 정확도) | 기존 단일 거리 | 1·3·6턴 혼합 학습 |
| --- | ---: | ---: |
| 기존 검증 4블록 | 65.63% | 56.25% |
| 기존 긴 테스트 12블록 | 50.00% | 53.13% |
| 새 seed 3001, 잡담 8·16턴, 24블록 | 42.19% | 54.69% |
| 새 seed 3001, 잡담 32·64턴, 24블록 | 18.75% | 20.31% |

새 24블록의 동일 대화를 짝지어 비교하면 8·16턴 정확도 차이는 **+12.50%p**(블록 부트스트랩 95% 구간 [+3.13,+23.44]%p)였다. 전체 어휘 정답 정확도는 **37.50→54.17%**(+16.67%p, [+7.29,+26.56]%p), 정답 NLL은 **2.700→1.496**으로 바뀌었다.

그러나 같은 평가의 32·64턴 정확도 차이는 **+1.56%p**([−1.56,+5.21]%p)로 불확실했고 두 모델 모두 거의 실패했다. NLL은 **4.170→2.880**으로 낮아졌지만 이것만으로 긴 기억에 성공했다고 볼 수 없다.

먼저 살펴본 seed 1009의 12블록에서도 8·16턴 정확도는 44.79→48.96%였으나 짝비교 구간이 0을 포함했다. 새 seed 결과는 이 탐색을 재현하는 추가 증거다. 완전히 독립된 사전등록 평가는 아니다.

한 블록의 위치 개입에서 사실 앞 잡담이 2·3·4블록일 때 정확도는 기존 모델의 각 12.5%에서 혼합 학습 모델의 37.5·62.5·37.5%로 바뀌었다. 하지만 사실 앞 8·16·32블록에서는 여전히 각 12.5%였다.

앞 잡담 2블록 조건에서 사실이 들어올 때의 평균 쓰기 게이트도 0.0718→0.1539로 높아졌다. 그래도 매번 사실을 포착하지는 못했다. 이 분석은 **선택한 합성 블록 한 개**에서 작동 원리를 진단한 것이며 모집단 정확도를 나타내지 않는다.

여러 미래 거리를 섞은 학습은 중간 거리에서 새 사실을 얻는 능력을 일부 개선했다. 그러나 검증 정확도는 낮아졌고 긴 잡담 32·64턴의 실패도 남았다. 실제 사람 대화를 처음부터 끝까지 처리하는 성능(E2E) 역시 미검증이다.

고정된 합성 단어와 질문의 8지선다 결과를 자동 장기기억이나 자유 텍스트 반환 성능으로 해석하지 않는다. 전체 회귀 테스트는 **749개가 통과**했다.
