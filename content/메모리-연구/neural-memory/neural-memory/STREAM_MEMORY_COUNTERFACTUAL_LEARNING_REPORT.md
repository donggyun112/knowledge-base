# 반사실 미래 대화 손실과 중간 구간 획득 진단 — 2026-09-28

## 결론

같은 질문·잡담에서 과거의 단어만 다른 8개 대화를 한 묶음으로 학습하고, 관측된 미래 대화 내용 전체가 **자기 상태에서 타인 상태보다** 잘 예측되도록 하는 손실을 추가했다. 사실·정답 위치나 저장 중요도 라벨은 손실에 사용하지 않았다. 짧은 거리의 자기/타인 구별은 확실히 학습됐지만, 긴 거리와 새로운 위치로 안정적으로 일반화하지 못했다. 이 묶음 자체가 인공적으로 짝지어진 추가 정보이므로 사람 대화만으로 자동 기억을 배웠다는 결과도 아니다.

가장 중요한 발견은 단순 망각보다 **중간 구간의 새 사실 획득 실패**다. 같은 사실·질문·최종 입력에서 잡담 블록을 사실 앞에 두면 정보가 사라지고, 훨씬 많은 블록을 사실 뒤에 두면 유지된다. 첫 구간은 강제로 메모리를 채우고 이후에는 작은 게이트로 갱신하는 현재 설계와 일치한다.

## 손실과 맞춘 비교

새 `counterfactual_future_loss`는 완전한 8-way 반사실 묶음의 앞 구간을 순서대로 처리한 뒤, 마지막 구간의 모든 대화 내용 토큰에 대해 자기 상태와 한 칸 교환한 상태의 전체 어휘 CE를 계산한다. 각 사례에서 `max(0, 0.2 + 자기 CE − 교환 CE)`의 평균을 원래 CE에 가중치 2로 더한다. 마지막 구간의 현재 텍스트는 같고 이전 상태만 달라진다. 답 토큰만 고르거나 8개 후보로 학습 손실을 제한하지 않는다. 학습 함수의 `fact_position`, `answer_position`, `target`을 바꿔도 손실이 같음을 테스트했다.

고정 SmolLM2-135M, 순환 8×576 상태, suffix writer+공유 query, 게이트 초기값 0.01, residual reader, rank 0, Apple MPS/float32, seed 41. 짧은 잡담 0·1턴, 마지막 뒤잡담 1턴, train 16블록·valid 4블록·긴 test 12블록. 400스텝, 매 스텝 동일한 8개 대화 묶음을 선택한다. 두 팔은 같은 초기화와 묶음 샘플링을 사용한다. 검증 자기 전체 어휘 NLL로 체크포인트를 선택했다.

| 짧은 단계 손실 | 검증 자기/교환 8-way | 검증 자기 전체 어휘 | 별도 긴 테스트 자기/교환 8-way | 긴 테스트 자기 전체 어휘 |
| --- | --- | ---: | --- | ---: |
| 미래 대화 CE만 | 12.50% / 12.50% | 12.50% | 11.46% / 12.50% | 11.46% |
| CE + 반사실 대조 | 93.75% / 0% | 90.63% | 28.13% / 9.38% | 9.38% |

대조 손실은 짧은 과제의 대화별 정보 이용을 만들었다. 긴 테스트에서도 상태 교환 시 정답이 기증 대화의 단어 쪽으로 움직였으나 28.13%는 아직 낮고 전체 어휘 출력은 더 낮다. 빈 상태가 12.5%인 8지선다 값은 우연 기준이며 자유 텍스트 답변 정확도가 아니다.

## 긴 거리 이어 학습과 새 잡담

위 대조 손실의 짧은 단계 체크포인트를 **동일한 시작점**으로 하여 긴 잡담 2·4·8턴, 뒤잡담 3턴을 400스텝 이어 학습했다. 한 팔은 대조 손실을 유지하고 다른 팔은 CE만 사용했다. 두 팔 모두 긴 검증 8지선다는 선택 모델에서 12.5%였으므로 안정적 일반화로 판정할 수 없다.

| 이어 학습 손실 | 기본 긴 테스트 자기/교환 8-way | 기본 긴 테스트 전체 어휘 | 새 잡담 8·16턴 자기/교환 8-way | 새 잡담 32·64턴 자기/교환 8-way |
| --- | --- | ---: | --- | --- |
| 대조 유지 | 33.33% / 9.38% | 16.67% | 34.38% / 9.38% | 12.5% / 12.5% |
| CE만 | 29.17% / 9.38% | 19.79% | 20.83% / 10.42% | 12.5% / 12.5% |

새 잡담 8·16턴의 대조 팔은 12블록 중 3블록에서 8개 단어를 전부 맞히고 나머지 9블록은 모두 12.5%였다. 블록 bootstrap 자기 정확도 95% 구간은 [12.5%, 56.25%]로 우연 수준을 포함한다. 대조 유지와 CE만의 짝지은 8지선다 정확도 차이 13.54%p의 95% 구간도 [0, 33.33%p]로 0을 포함한다. 32·64턴은 둘 다 우연 수준이다. 대조 손실이 항상 더 낫다는 결론은 아니다.

## 같은 입력의 위치 개입

대조 유지 긴 단계 체크포인트에서 테스트 블록 하나를 고정하고, 정답 후보가 없는 동일한 31토큰 잡담 블록을 사실 **앞** 또는 **뒤**에 추가했다. 최종 질문 구간과 사실의 구간 내 위치는 변하지 않는다. 이 시험은 한 인공 블록의 인과 진단이며 모집단 정확도가 아니다.

| 추가 잡담 | 사실 앞 자기/교환 정확도 | 사실 뒤 자기/교환 정확도 |
| ---: | --- | --- |
| 0블록 | 100% / 0% | 100% / 0% |
| 4블록 | 12.5% / 12.5% | 100% / 0% |
| 32블록 | 12.5% / 12.5% | 100% / 0% |

사실 앞 4블록에서 질문 직전 대화별 상태 RMS 차이는 `1.34e-7`까지 줄었고, 사실 뒤 32블록은 `0.444`였다. 실제 새 잡담 8·16턴의 완전 정답 3블록도 모두 사실이 첫 31토큰 구간에 있었다. 반면 나머지 블록은 뒤 구간 사실이었다. 이는 현재 체크포인트의 강한 **첫 구간 획득 편향**을 보여 준다. 단지 오래 지나서 잊어버렸다는 설명과 맞지 않는다.

게이트 초기값을 0.01에서 0.1로 높이고 처음부터 긴 거리 대조 학습 400스텝을 한 별도 진단도 긴 검증 최고 정답률 12.5%였으며, 같은 위치 개입에서 사실 앞 4블록 12.5%, 뒤 32블록 50%였다. 게이트를 조금 더 열기만 해서는 중간 구간의 새 사실을 안정적으로 획득하지 못한다. 이 두 초기값은 동일 시작 가중치 비교가 아니므로 독립적 게이트 효과의 엄격한 추정은 아니다.

## 후속 실험: 첫 구간 강제 기록 제거

기존 `gated` 갱신은 빈 상태의 첫 비어 있지 않은 구간에서 게이트를 무조건 1로 만들었다. `--no-force-first-write`를 추가해 첫 구간도 이후와 같은 학습 게이트를 통과하게 했다. 기본값은 기존 동작을 유지하므로 이전 체크포인트와 호환된다. 두 팔은 게이트 초기값 0.1, seed 41, 긴 잡담 데이터·배치·400스텝·손실·검증 NLL 선택이 같고, 이 옵션만 다르다. 같은 초기 파라미터와 샘플링을 사용하지만 단일 seed의 탐색 실험이다.

| 강제 첫 기록 | 긴 검증 자기/교환 8-way | 기존 긴 테스트 자기/교환 8-way | 테스트 전체 어휘 | 새 잡담 8·16턴 자기/교환 8-way | 새 잡담 32·64턴 자기/교환 8-way |
| --- | --- | --- | ---: | --- | --- |
| 켬 | 12.50% / 12.50% | 34.38% / 9.38% | 33.33% | 27.08% / 10.42% | 12.50% / 12.50% |
| 끔 | 65.63% / 3.13% | 50.00% / 8.33% | 46.88% | 44.79% / 9.38% | 17.71% / 12.50% |

새 잡담 8·16턴의 동일 12개 블록 짝지은 차이는 **+17.71%p**이며, 블록 bootstrap 95% 구간은 **[+5.21,+34.38]%p**였다. 이 구간은 고정된 합성 블록에 대한 탐색적 불확실성이고, 다른 대화 분포·seed로 일반화된다는 보장은 아니다. 중요한 변화는 첫 구간 뒤 사실도 일부 획득했다는 점이다. 예컨대 사실이 토큰 37(두 번째 32토큰 구간)에 있는 새 블록은 기존 모델 1/8, 변경 모델 8/8이었다. 사실이 토큰 87인 블록도 1/8에서 4/8로 올랐다.

같은 사실·질문을 유지하고 31토큰 잡담을 사실 앞/뒤로 옮긴 한 블록 위치 개입에서, 사실 앞 **1블록**은 기존 12.5%, 변경 87.5%; 앞 **2블록**부터는 변경 모델도 12.5%였다. 변경 모델의 뒤 4블록은 87.5%, 뒤 8블록은 75%였다. 즉 강제 첫 기록이 중간 획득 실패의 한 원인이었고 이 변경은 경계를 한 구간 이상 밀었지만, 여러 구간을 지난 후 새 사실을 안정적으로 기록하지는 못했다. 뒤 16·32블록에서도 성능이 하락하므로 유지도 무한하지 않다. 긴 잡담 32·64턴은 여전히 우연 수준 근처다.

후속 산출물: `local-data/stream-rmt-cf-gatedfirst-directlong-seed41.{json,pt}`, `local-data/stream-rmt-cf-gatedfirst-directlong-seed41-{position,position-dense,stress}.json`, 비교 기준 `local-data/stream-rmt-cf-gate010-directlong-seed41-{position-dense,stress}.json`. `diagnose_stream_memory_position.py --noise-blocks`로 위치 개입 간격을 바꿀 수 있다. 새 옵션과 첫 구간 게이트 경사를 테스트했으며 전체 테스트 **744개 통과**했다.

## 후속 진단: 중간 구간 게이트 억제 — 2026-09-29

새 모델의 같은 8개 합성 대화에서 사실 앞에 동일한 31토큰 잡담 블록을 0·1·2·4개 넣었다. 사실이 든 구간의 게이트 출력만 관찰하고, 그 구간에서만 게이트를 강제로 열거나 직전 상태를 초기화했다. 강제 개입은 사실 위치를 알아야 하므로 실제 기억 정책이 아니다.

| 사실 앞 잡담 | 학습 게이트 평균 | 원래 8-way | 사실 구간 게이트만 강제 | 사실 직전 상태 초기화 |
| ---: | ---: | ---: | ---: | ---: |
| 0블록 | 0.605 | 87.5% | 100% | 87.5% |
| 1블록 | 0.180 | 87.5% | 75% | 87.5% |
| 2블록 | 0.072 | 12.5% | 62.5% | 87.5% |
| 4블록 | 0.052 | 12.5% | 62.5% | 87.5% |

2블록 뒤 사실의 경우 게이트 강제만으로 대화별 상태 차이(RMS)가 0.018→0.206, 정답률이 12.5→62.5%로 올랐다. 즉 제안된 기록에 정보가 전혀 없는 것은 아니며, **이전 잡담이 만든 상태에서 게이트가 닫히는 현상**이 중요한 병목이다. 다만 강제 게이트도 100%가 아니므로 기록 제안·기존 상태 간섭을 배제할 수 없다. 기존 강제-첫-기록 모델에서는 2블록 뒤 게이트 평균이 0.003이고, 그 구간만 강제로 열어도 12.5%였다. 직전 상태를 초기화하면 50%로 회복되어 기존 모델에는 상태 간섭도 더 컸다. 이 결과는 한 블록의 인과 진단이지 일반 성능 추정이 아니다.

모든 구간의 게이트를 무조건 일정 이상 열어두는 **사실 위치를 쓰지 않는 추론 개입**도 시험했다. 동일한 새 잡담 8·16턴 12블록의 8-way 정확도는 게이트 하한 0에서 44.79%, 0.05에서 45.83%, 0.1에서 42.71%, 0.2에서 26.04%, 0.4에서 13.54%였다. 0.1은 위 한 블록의 늦은 사실을 12.5→37.5%로 높였지만 전체 성능은 떨어졌다. 따라서 일괄 개방은 해결책이 아니다.

마지막으로 게이트 구조는 유지하고 학습 대화에서 사실 뒤 잡담만 3턴→1턴으로 줄여 400스텝 재학습했다. 훈련 손실은 낮아졌으나 동일한 기존 길이의 선택 검증·테스트 8-way 모두 12.5%였다. 1턴짜리 새 검증에서도 28.13%로 기존 모델의 56.25%보다 낮아, 실패를 평가 거리 차이만으로 설명할 수 없다. 단일 seed·작은 합성 데이터에서의 일반화 실패이며, 추가 재학습으로 효과를 주장하지 않는다.

진단 코드: `diagnose_stream_memory_acquisition.py`, `diagnose_stream_memory_gate_floor.py`, `eval_stream_memory_control_checkpoint.py`. 결과: `local-data/stream-rmt-cf-{gatedfirst,gate010}-directlong-seed41-acquisition.json`, `local-data/stream-rmt-cf-gatedfirst-directlong-seed41-gate-floor.json`, `local-data/stream-rmt-cf-gatedfirst-shortcredit-seed41.{json,pt}`, 두 모델의 `-valid-trail1.json`. 모두 합성 대화 진단이며 실제 사람 대화의 저장·반환 성능은 아직 검증하지 않았다.

## 후속 구조 대조: 이전 상태 억제와 비선형 게이트 — 2026-09-29

학습된 **선형** 게이트의 입력을 사실이 등장한 구간에서 분해했다. 사실 앞 잡담 2블록일 때 평균 로그잇 기여는 이전 상태 **−3.03**, 새 기록 후보 **+2.21**, 현재 토큰 요약 **+0.06**, 편향 **−2.19**였다. 이전 상태 항만 사실 구간에서 가리면 게이트 평균이 0.072→0.518, 그 한 블록의 8-way 정답률이 12.5→62.5%로 올랐다. 이는 이전 상태 항의 강한 억제를 직접 보여 주지만, 어느 구간이 사실인지 아는 특권적 개입이므로 모델 개선 수치가 아니다.

특권 없이 **모든 구간**에서 이전 상태 항을 1.0·0.75·0.5·0.25·0배로 줄이면 동일 새 잡담 8·16턴의 8-way 정확도는 각각 44.79·42.71·42.71·23.96·17.71%였다. 억제를 전부 제거하면 무관한 대화도 기록되어 성능이 크게 떨어진다. 이에 게이트만 이전 상태를 직접 받지 않고 새 기록 후보는 계속 이전 상태를 보도록 한 모델을 처음부터 동일 데이터·손실·seed·400스텝으로 학습했다. 또 선형 합 대신 64차원 은닉층의 비선형 게이트도 같은 조건으로 학습했다.

| 게이트 | 긴 검증 8-way | 기존 긴 테스트 8-way | 새 잡담 8·16턴 8-way | 위치 개입: 사실 앞 2블록 8-way |
| --- | ---: | ---: | ---: | ---: |
| 원래 선형 | 65.63% | 50.00% | 44.79% | 12.5% |
| 이전 상태 직접 입력 없음 | 28.13% | 20.83% | 14.58% | 25.0% |
| 비선형 MLP | 62.50% | 45.83% | 33.33% | 12.5% |

새 잡담 12블록의 원래 모델 대비 짝지은 차이는 이전 상태 직접 입력 제거 **−30.21%p**(블록 bootstrap 95% 구간 [−50.0,−12.5]%p), MLP **−11.46%p**([−20.83,−2.08]%p)였다. 표본과 후보가 작고 반복적으로 관찰된 합성 과제이므로 일반 성능 비교로 확정할 수는 없지만, 이 설정에서는 **이전 상태 억제를 없애거나 게이트 용량만 늘리는 처방은 실패**했다. 이전 상태 보호와 새 사실의 선택적 유입을 동시에 학습해야 한다. MLP는 파라미터화가 달라 선형 모델과 초기 가중치가 완전히 동일한 A/B는 아니다.

새 옵션 `--gate-state-blind`, `--gate-arch mlp`는 기본값을 바꾸지 않고 체크포인트 설정에 저장된다. 결과: `local-data/stream-rmt-cf-gatedfirst-directlong-seed41-{acquisition-components,gate-state-scale}.json`, `local-data/stream-rmt-cf-gatedfirst-{stateblind,mlpgate}-directlong-seed41.{json,pt}` 및 각 `-position-dense.json`, `-stress.json`. 전체 테스트 **748개 통과**했다.

## 범위와 산출물

이 실험은 단일 인공 단어·고정 질문·동일한 여덟 후보의 용량/학습 경로 진단이다. 훈련에 사용한 반사실 묶음은 실제 사람 대화 로그에 자동으로 존재하지 않는다. 실제 사람 대화 E2E, 새 의미 범주, 복수 사실·정정, 불필요한 반환 억제, 기억 텍스트 출력·`NO_MEMORY`는 평가하지 않았다. 검증/테스트 세트를 이전 실험에서도 여러 차례 보았으므로 탐색적 결과다.

- 구현: 대조 실행기 (`run_stream_memory_control.py`; 원 저장소의 파일 참조)의 묶음 손실 및 CLI. 위치 진단 (`diagnose_stream_memory_position.py`; 원 저장소의 파일 참조)은 새 읽기/쓰기 모드 복원을 지원한다.
- 짧은 비교: `local-data/stream-rmt-cf-paired-{ce,contrastive}-short-seed41.json` 및 같은 이름의 `.pt`.
- 긴 이어 학습: `local-data/stream-rmt-cf-paired-{ce,contrastive}-long-seed41.json` 및 `.pt`.
- 새 잡담과 짝지은 비교: `local-data/stream-rmt-cf-paired-{ce,contrastive}-long-seed41-stress.json`.
- 위치 개입: `local-data/stream-rmt-cf-paired-contrastive-long-seed41-position.json`, `local-data/stream-rmt-cf-gate010-directlong-seed41-position.json`.
- 게이트 0.1 진단: `local-data/stream-rmt-cf-gate010-directlong-seed41.json` 및 `.pt`.

## 여러 미래 거리로 학습한 후속 실험 — 2026-09-29

기존의 마지막 잡담 3턴만 예측하도록 학습한 모델과 같은 seed 41·400스텝·반사실 묶음·게이트 구조를 유지하고, **학습 단계마다 마지막 잡담 길이를 1·3·6턴 중 하나로 선택**했다. 학습 사례와 잡담 단어는 동일하게 두고 길이만 바꾼 변형을 사용했으며, 길이 선택용 난수열을 별도로 두어 기존 블록 선택 순서를 보존했다. 길이별 학습 스텝은 각각 130·135·135회였다. 처음에 사용자 개인 정보가 들어간 것은 아니며, 학습 손실은 미래 내용 토큰 예측과 상태 교환 대조 손실이다. 구현: `run_stream_memory_control.py`의 `--train-trailing-noise-choices`.

| 평가 (8지선다 자기 상태 정확도) | 기존 단일 거리 | 1·3·6턴 혼합 학습 |
| --- | ---: | ---: |
| 기존 검증 4블록 | 65.63% | 56.25% |
| 기존 긴 테스트 12블록 | 50.00% | 53.13% |
| 새 seed 3001, 잡담 8·16턴, 24블록 | 42.19% | 54.69% |
| 새 seed 3001, 잡담 32·64턴, 24블록 | 18.75% | 20.31% |

새 24블록의 동일 대화 짝비교에서 8·16턴 정확도 차이는 **+12.50%p**(블록 bootstrap 95% 구간 [+3.13,+23.44]%p), 전체 어휘 정답 정확도는 **37.50→54.17%**(+16.67%p, [+7.29,+26.56]%p), 정답 NLL은 **2.700→1.496**이었다. 같은 평가의 32·64턴 정확도 차이는 **+1.56%p**([−1.56,+5.21]%p)로 불확실하며 둘 다 거의 실패했다. NLL은 **4.170→2.880**으로 감소했지만, 이것만으로 긴 기억이 성공했다고 볼 수 없다. 먼저 살펴본 seed 1009의 12블록에서도 8·16턴 정확도는 44.79→48.96%였으나 짝비교 구간이 0을 포함했다. 새 seed의 결과는 이 탐색을 재현하는 추가 증거이지, 완전히 독립적인 사전등록 평가가 아니다.

한 블록 위치 개입에서는 사실 앞에 잡담 2·3·4블록을 둔 정확도가 기존 모델의 각 12.5%에서 혼합 학습 모델의 37.5·62.5·37.5%로 바뀌었다. 그러나 사실 앞 8·16·32블록은 여전히 각 12.5%였다. 사실 입력 시 평균 쓰기 게이트도 앞 잡담 2블록 조건에서 0.0718→0.1539로 높아졌지만, 매번 사실을 포착하지는 못한다. 이 위치 분석은 **선택한 합성 블록 한 개**의 메커니즘 진단이지 모집단 정확도가 아니다.

따라서 혼합 미래 거리 학습은 중간 거리의 새 사실 획득을 일부 개선했지만, 검증 정확도는 떨어졌고 긴 잡담 32·64턴 실패와 실제 사람 대화 E2E 미검증 문제는 남았다. 8지선다와 고정 합성 단어·질문의 결과를 자동 장기기억이나 자유 텍스트 반환 성능으로 해석하지 않는다. 전체 회귀 테스트는 **749개 통과**했다.
