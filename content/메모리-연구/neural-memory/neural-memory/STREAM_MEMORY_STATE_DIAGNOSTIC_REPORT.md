# 사람 대화 기억 상태의 정보·읽기 분리 진단 — 2026-09-28

## 결론

현재 순환 기억 모델은 빈 상태보다 자기 과거 상태에서 미래 발화 예측이 낫지만, 과거를 다른 사람 것으로 바꾸어도 거의 변하지 않는다. 과거 원문을 직접 읽는 고정 언어모델은 같은 사례에서 사람별 차이를 보인다. 별도 선형 판독기는 순환 상태에서 일부 과거 단어 정보를 읽어냈지만, 기억 학습 전과 후의 차이는 작았다. 따라서 **정보가 전혀 없다고 단정할 수는 없으나, 지금의 학습이 쓸 만한 개인별 내용을 상태에 더 싣고 미래 예측에 활용한다는 증거는 없다.**

## 원문 과거와 순환 기억의 사례별 비교

기존 [[메모리-연구/neural-memory/neural-memory/STREAM_MEMORY_READ_ADAPTER_REPORT|토큰 조건부 읽기 모델]]의 선택 체크포인트를 같은 MSC test 96개에 다시 평가하면서 원문 과거 직접 읽기 점수도 사례별로 저장했다. 두 경로는 입력 구조가 달라 원문 점수를 순환 모델의 달성 가능 성능으로 해석하지 않는다.

| 경로 | test `타인−자기` NLL [95% 구간] |
| --- | ---: |
| 고정 언어모델, 원문 과거 직접 읽기 | +0.0777 [0.0443, 0.1115] |
| 고정 언어모델 + 순환 기억 | +0.00421 [0.00047, 0.00768] |

원문 교환 효과가 가장 큰 24개 사례에서 원문의 평균 효과는 +0.291이지만 순환 기억의 평균 효과는 +0.00082다. 전체 96개 사례에서 두 효과의 피어슨 상관은 −0.186이다. 이는 탐색적 사례 분석이며, test에서 사후 선택한 상위 24개에 대한 일반화 통계가 아니다.

## 상태 내용 판독기

진단 코드 (`diagnose_stream_memory_state.py`; 원 저장소의 파일 참조)는 모델 가중치를 고정한 채, 과거 이력에서 특정 토큰이 등장했는지를 **별도의** 선형 ridge 판독기로 맞힌다. 토큰 목록은 train 512개 과거에서만 선택하고 규제 강도는 valid 96개에서 고른 뒤 test 96개에서 AUC를 계산했다. 일반 알파벳 토큰 64개와 길이 5자 이상·영어 불용어 제외 내용 토큰 64개를 따로 검사했다. 무작위로 train 라벨을 섞은 대조도 같은 절차를 썼다. 이 라벨은 본 기억 모델 학습에 사용하지 않았다.

| 상태 | 일반 토큰 test macro AUC | 내용 토큰 test macro AUC |
| --- | ---: | ---: |
| 학습 전 writer | 0.538 | 0.586 |
| 기존 600스텝 기억 모델 | 0.541 | 0.587 |
| 아래 100스텝 보조 손실 모델 | 0.537 | 0.560 |
| train 라벨 섞기 대조 (기존/보조) | 0.498 / 0.498 | 0.472 / 0.505 |

학습 전 상태도 내용 토큰에 대한 선형 신호가 있으므로 ‘상태가 비어 있다’는 해석은 틀리다. 반면 기존 600스텝 학습이 그 진단에서 거의 늘리지 못했고, 아래 100스텝 후보도 개선하지 못했다. 단어 존재 판독은 정확한 개인 사실·정정·필요한 때의 반환을 재는 시험이 아니며, 선형 판독의 낮은 점수가 비선형 정보 부재를 증명하지도 않는다. 두 학습 모델의 스텝 예산도 다르므로 직접 우열 판단에 쓰지 않는다.

## 구간 경계 자기지도 보조 손실 파일럿

기존 학습은 과거 토큰을 상태에 흘려보내고 **마지막 세션의 한 발화**에서만 예측 손실을 얻는다. 이를 보완하는 선택 옵션 `--history-aux-weight`를 추가했다. 두 번째 이후 과거 구간의 시작에서 최대 32개 실제 다음 토큰을 예측하며, 동일한 토큰에 자기 이전 상태와 타인의 이전 상태를 넣어 CE 및 기존 자기/타인 대조 손실을 계산한다. 수작업 중요도·기억 텍스트 라벨은 쓰지 않고, 본 모델의 기본값은 0(꺼짐)이다. 학습 후 빈 상태 예측과 고정 언어모델 경로는 유지한다.

초기 1스텝 점검에서 이 경계 손실이 답변 손실보다 커서 가중치 0.5는 검증 NLL을 크게 악화시켰다. 그래서 0.05로 낮춰 seed 29, MSC train 512·valid/test 각 96개, Apple MPS에서 100스텝 파일럿을 실행했다. 기존 600스텝 실험의 100스텝 시점과 같은 검증 사례·목적을 비교한다.

| 100스텝 검증 | `빈−자기` | `타인−자기` [95% 구간] |
| --- | ---: | ---: |
| 기존 학습 | +0.06257 | −0.00018 [−0.00412, 0.00404] |
| 구간 경계 보조 손실 0.05 | +0.06311 | +0.00124 [−0.01105, 0.01165] |

보조 손실 후보의 선택 test는 `빈−자기` +0.06382, `타인−자기` −0.00071 [−0.00796, 0.00601]이다. valid/test 모두 사전 개인별 기억 기준(`빈−자기`와 `타인−자기` 각각 최소 +0.02, 신뢰구간 하한 양수)을 통과하지 못했다. 상태 판독에도 개선이 없어 이 보조 손실의 600스텝 확장은 보류한다. 100스텝 결과만으로 장기 학습의 가능성을 배제하지는 않는다.

전체 Python 테스트 **730개 통과**(기존 경고 1개). 파일럿 `.json`/`.pt`, 원문 사례별 감사 자료, 두 종류의 상태 판독 JSON은 `local-data/stream-rmt-human-read-history-aux-100-seed29*`, `local-data/stream-rmt-human-read-residual-contrastive-600-test-raw-audit.json`, `local-data/stream-rmt-human-read-*-probe-seed29.json`에 보존했다. MSC test는 프로젝트에서 이미 반복 확인한 탐색적 자료이며, 여전히 기억 텍스트/`NO_MEMORY`와 자동 반환 시점은 구현·검증되지 않았다.

## 후속 원인 분해: 공통 상태의 지름길

동일 checkpoint에서 MSC valid 96개 과거 상태의 평균을 만들고 test 96개 모든 사람에게 공통으로 주입했다. test 평균 NLL은 자기 상태 2.9809, 평균 상태 2.9833, 다른 사람 상태 2.9851, 빈 상태 3.0682다. 평균 상태와 자기 상태의 차이는 +0.00241 [−0.00026, 0.00499]뿐이며, 평균 상태가 빈 상태 대비 자기 상태 이득의 약 97%를 재현했다. 관측 표식만 켠 0 상태는 NLL 3.4121로 악화되므로 단순 `observed` 스위치 효과가 아니다.

같은 가중치에서 잔차 읽기 모듈만 추론 중 끄면 자기/타인/평균 상태의 NLL이 각각 3.0451/3.0508/3.0477이 된다. 잔차 읽기를 켰을 때의 NLL 개선은 각각 +0.0642/+0.0657/+0.0643으로 거의 같다. 따라서 새 읽기 경로가 학습한 큰 이득은 **개인별 내용을 선택해 읽는 효과가 아니라 공통 상태에 대한 보정**이다. 첫 정답 토큰의 타인−자기 차이 +0.0207도 95% 구간 [−0.0028, 0.0410]으로 불확실하다.

원문 직접 읽기의 자기/타인 차이를 과거 길이만으로 설명할 수는 없다. 자기와 타인의 과거 길이가 같은 test 67개에서도 +0.0554다. 과거의 첫 256토큰만 다른 사람 것으로 바꾸고 나머지 길이와 최근 토큰을 동일하게 유지한 93개 사례에서 원문 읽기는 +0.0476 [0.0234, 0.0719] 손해를 보지만 순환 기억은 +0.00441 [0.00075, 0.00805]만 변한다. 같은 방식으로 최근 구간만 바꾸면 원문 −0.00106 [−0.0167, 0.0156], 순환 기억 −0.00003 [−0.00015, 0.00008]로 거의 변하지 않는다. 이어 붙인 대화의 어색함도 바뀌므로 순수한 개인 사실 효과로 단정하지 않지만, 이 과제에서 활용 가능한 과거 차이가 주로 첫 구간에 있다는 진단이다.

두 번째 과거 구간의 갱신 gate 평균은 0.038이고, 전체 상태와 첫 구간만 본 상태의 코사인은 0.991이다. 첫 구간만으로 점수 차이가 −0.00106 [−0.00307, 0.00070]이어서 최근 구간이 현재 평가에 기여하지 않았다. 그러나 최근 구간 치환은 원문 읽기에도 영향이 없었으므로 **작은 gate만을 주원인으로 지목할 수 없다.**

학습 부족도 일부 확인된다. 600스텝 동안 train 512개 중 실제 선택된 대화는 355개뿐이다. 감사한 train 96개에서 노출 0/1/2/3회 이상 그룹의 타인−자기 차이는 각각 −0.0023/+0.0029/+0.0088/+0.0134다. 원문 직접 읽기 효과를 공변량으로 둔 노출 횟수 기울기는 약 +0.00537 nats/회, 사후 permutation p≈0.0032다. 노출된 70개만 보아도 평균 +0.0063으로 합격 기준 +0.02보다 작고, 이 관계가 미사용 대화로 일반화될지는 별개다. CE만 학습한 이전 모델의 200스텝 선택 상태도 노출 163/512개이며, 학습에 노출된 사례에서 타인−자기 +0.0151, 미노출 사례에서 거의 0이었다. 개인별 효과가 반복 노출에 의존하는 현상은 대조 손실만의 문제가 아니다.

**현재 확인된 실패 모드:** 순환 상태는 전혀 비어 있지 않지만, 예측 이득 대부분이 사람별로 교환 가능한 공통 상태에서 나온다. 첫 과거 구간에 원문 기준 유용한 차이가 있는데, 이 모델의 상태→읽기→출력 경로에서는 그 차이가 약 10분의 1로 줄어든다. 유용한 정보가 쓰기에서 사라졌는지, 상태에는 남았지만 읽기가 무시하는지의 정확한 비율은 아직 분리하지 못했다. 고정된 writer, 마지막 답변 한 개에 집중된 손실, 낮은 사례당 노출은 가능한 기여 요인이지만 각각을 단독 원인으로 확정하지 않는다.

후속 개입 원자료: `local-data/stream-rmt-human-read-residual-mechanism-first-seed29.json`, `local-data/stream-rmt-human-read-residual-writer-two-splice-seed29.json`, `local-data/stream-rmt-human-read-residual-train96-raw-audit.json`, `local-data/stream-rmt-human-frozen-ce-train96-raw-audit.json`. 진단 코드는 공통 상태 개입 (`diagnose_stream_memory_mechanism.py`; 원 저장소의 파일 참조), 쓰기 구간 치환 (`diagnose_stream_memory_writer.py`; 원 저장소의 파일 참조), 학습 노출 분석 (`diagnose_stream_memory_sampling.py`; 원 저장소의 파일 참조)에 있다. 모두 기존 체크포인트의 파라미터를 바꾸지 않았다.

## 후속 원인 분해: 빠진 학습 대화를 전부 보게 하면 해결되는가

학습 대화 512개 중 157개가 한 번도 선택되지 않았던 문제를 분리하기 위해, 학습 코드 (`train_stream_memory_human.py`; 원 저장소의 파일 참조)에 `--sampling epochs`를 추가했다. 기존 기본값인 복원 추첨은 그대로 두고, 새 옵션에서만 각 512개 대화를 임의 순서로 한 번씩 본 뒤 다음 epoch로 넘어간다. seed 29, 동일 train/valid/test 대화 512/96/96개, 600스텝, 손실·모델·학습률·평가 간격을 고정했다. 새 실험의 선택 체크포인트는 600스텝이므로 실제로 **512개 대화 모두를 본 상태**다. 기존 실험의 600스텝 선택 상태는 355개를 보았다.

| 선택 상태, MSC test 96개 | 본 train 대화 | `빈−자기` NLL | `타인−자기` NLL [95% 구간] |
| --- | ---: | ---: | ---: |
| 기존 복원 추첨 | 355/512 | +0.08727 | +0.00421 [+0.00044, +0.00768] |
| 전체 순회 후 재섞기 | 512/512 | +0.09181 | −0.00180 [−0.00384, +0.00017] |

새 모델은 빈 상태보다 자기 상태에서 예측이 낫지만, 다른 사람 상태로 교환하면 나빠지기는커녕 평균상 약간 좋아졌다. 사전 기준인 `빈−자기`와 `타인−자기` 각각 +0.02 이상 및 95% 구간 하한 양수를 valid/test 모두 통과하지 못했다. 독립 실행한 사례별 감사 평가 (`eval_stream_memory_human.py`; 원 저장소의 파일 참조)에서 같은 96개 대화와 점수가 재현되었고, 체크포인트 파라미터는 변하지 않았다. 원문 과거를 직접 보는 고정 언어모델의 같은 test 교환 효과는 +0.07766이다.

새 체크포인트에 공통 상태 개입 (`diagnose_stream_memory_mechanism.py`; 원 저장소의 파일 참조)을 반복했다. test 평균 NLL은 빈 상태 3.06818, 자기 2.97637, 타인 2.97457, **valid 96개로 만든 공통 평균 상태 2.97529**다. 공통 상태가 자기 상태의 빈 상태 대비 이득을 100% 이상 재현한다. 잔차 읽기를 끄면 자기/타인/공통 상태 NLL은 3.03286/3.03155/3.03181로 함께 악화된다. 즉 새 읽기 경로의 약 0.056 NLL 개선도 개인별 선택 읽기보다는 공통 보정이다. 자기/타인 상태 코사인 평균은 0.99476이다. 코사인 유사도만으로 내용 부재를 증명하지는 않는다.

과거에 등장한 내용 토큰 64개를 별도 선형 판독기로 알아맞히면, 초기 writer의 test macro AUC는 0.58587이고 전체 순회 학습 뒤에는 0.58170이다. 기존 복원 추첨 학습 뒤에는 0.58667이었다. 이번 학습이 선형적으로 판독 가능한 과거 단어 정보를 늘렸다는 증거도 없다. 다만 토큰 존재 판독은 개인 사실, 정정, 필요한 시점의 반환을 직접 평가하지 않으며 비선형 정보의 부재를 증명하지 않는다.

**업데이트된 결론:** 학습 대화 일부를 아예 못 본 것은 약점이지만, 이번 동일 예산·단일 seed 실험에서는 그것만 해결해도 개인별 기억 성능은 살아나지 않았다. 관측된 직접 실패 모드는 사람별로 거의 교환 가능한 상태와 그 상태에 대한 공통 읽기 보정이다. 정확히 어느 부분이 정보 쓰기 병목이고 어느 부분이 읽기 병목인지는 아직 분리되지 않았다. 샘플링 변경은 노출 수뿐 아니라 순서와 반복 분포도 바꾸므로, 이 결과로 낮은 노출의 모든 인과효과를 부정할 수는 없다. 이미 여러 차례 확인한 MSC test에 대한 탐색적 결과이며, 다른 seed·사람 대화 데이터에서의 재현과 실제 기억 텍스트/`NO_MEMORY`·자동 반환은 미검증이다.

## 후속 원인 분해: 쓰기와 읽기 경로를 각각 더 학습하기

위의 전체 순회 600스텝 체크포인트에서 **동일한 가중치로 시작**해 학습 가능한 경로만 바꾸었다. 읽기 전용은 bridge·write queries·update gate를 고정하고 잔차 reader만 학습한다. 쓰기 전용은 reader를 고정하고 writer만 학습한다. 결합 대조는 둘 다 학습한다. 세 실험 모두 같은 512/96/96개 대화, seed 29, 순회 샘플링, 600 추가 스텝, 손실·학습률·검증 선택 절차를 사용한다. 고정 언어모델은 계속 동결했고, 저장된 체크포인트에는 학습 중 고정한 부분의 가중치도 함께 넣어 재로드 가능하게 했다.

| 시작점에서 추가 학습 | 학습 파라미터 | valid `타인−자기` | test `빈−자기` | test `타인−자기` [95% 구간] |
| --- | ---: | ---: | ---: | ---: |
| 시작점 (추가 0스텝) | — | +0.00096 | +0.09181 | −0.00180 [−0.00384, +0.00017] |
| 읽기만 600스텝 | 297,793 | +0.00131 | +0.09154 | −0.00122 [−0.00323, +0.00077] |
| 쓰기만 600스텝 | 338,113 | +0.00673 | +0.10054 | +0.00511 [−0.00198, +0.01401] |
| 쓰기·읽기 600스텝 | 635,906 | +0.00201 | +0.10919 | +0.00144 [−0.00250, +0.00556] |

모두 valid에서 선택된 600스텝 체크포인트다. **읽기만 추가 학습해서는 개인별 효과가 나타나지 않았다.** 쓰기만 학습했을 때 가장 큰 개선이 있었지만 test 구간은 0을 포함하고, 사전 목표 +0.02에 크게 못 미친다. 결합 학습은 빈 상태 대비 예측만 가장 많이 개선하고 개인별 차이는 쓰기 전용보다 작다. 따라서 추가 600스텝 자체가 개인별 차이의 개선을 보장하지는 않는다. 다만 단일 seed·탐색적 test라 세 방식의 우열을 확정하지 않는다.

쓰기 전용 체크포인트에서 valid 96개로 만든 공통 평균 상태를 test 모든 사람에게 넣으면 NLL 2.97458로, 본인 상태 2.96764보다 +0.00694 [95% 구간 +0.00001, +0.01563] 나쁘다. 기존 전체 순회 모델에서 평균 상태가 본인보다 오히려 좋았던 것과 달리 **작은 개인별 성분이 생겼을 가능성**은 있다. 그래도 공통 평균 상태가 빈 상태 대비 본인 상태 이득의 약 93%를 재현한다. 자기/타인 상태 코사인 평균은 0.99476에서 0.97749로 떨어졌다. 내용 토큰 64개의 별도 선형 판독 test AUC는 초기 writer 0.58587, 전체 순회 모델 0.58170, 쓰기 전용 추가 학습 모델 0.57821로 개선되지 않았다. 상태 차이가 어떤 개인 사실을 뜻하는지는 아직 증명되지 않았다.

**현재 가장 좁힌 결론:** 개인별 정보가 *전혀* 없다는 주장은 틀리지만, 현재 목적함수는 공통 상태 보정을 훨씬 쉽게 학습한다. 추가 쓰기 학습이 작은 개인별 차이를 만들 수 있는 반면 읽기 전용 추가 학습은 그러지 못했다. 따라서 쓰기/상태 형성이 우선 의심되며, 읽기의 표현력·쓰기와 읽기의 공동 최적화·데이터 신호 부족을 각각 배제한 것은 아니다. 다음 주장에는 새 대화 분포·다른 seed 검증이 필요하다. 실제 기억 텍스트 출력과 자동 반환 시점은 여전히 구현되지 않았다.

## 후속 원인 분해: 드문 유용 사례의 학습 신호가 묻히는가

train 96개 원문 감사 자료에서 본인 과거가 타인 과거보다 직접 예측에 유리한 경우는 63개였다. 전체 `타인−자기` 평균 +0.04589에 비해 상위 24개 평균은 +0.21223으로, 원문 이득이 소수 사례에 집중됐다. 이 때문에 일반 다음 토큰 손실이 유용한 기억 신호를 희석한다는 가설을 시험했다.

학습 코드 (`train_stream_memory_human.py`; 원 저장소의 파일 참조)에 기본값이 꺼진 `--oracle-priority` 진단 옵션을 추가했다. **train 대화에만** 고정 언어모델로 원문 자기/타인 이력을 각각 직접 읽혀 같은 미래 발화 NLL 차이를 계산한다. 효과가 양수인 상위 1/4에 가중치 2.5, 나머지에 0.5를 주어 평균 가중치를 1로 맞춘다. MSC train 512개 중 원문 자기 이력이 유리한 것은 328개였고, 상위 128개를 강조했다. 수작업 사실·중요도 라벨은 쓰지 않았지만, 원문 전체와 미래 정답을 함께 쓰는 **교사 기반 진단**이므로 이를 최종 자율 기억 학습 방식으로 해석하지 않는다.

전체 순회 600스텝 체크포인트에서 같은 writer만 600스텝 더 학습한 이전 실험과 시작 가중치·대화 순서·손실 구성·학습률·검증 선택을 맞추고, 사례별 손실 가중치만 바꾸었다.

| 쓰기 전용 추가 600스텝 | valid `타인−자기` | 기존 MSC test `타인−자기` [95% 구간] | 미학습 train 수신자 96개 `타인−자기` [95% 구간] |
| --- | ---: | ---: | ---: |
| 균등 가중치 | +0.00673 | +0.00511 [−0.00198, +0.01401] | −0.00114 [−0.00712, +0.00491] |
| 원문 효과 상위 사례 강조 | +0.00256 | −0.00077 [−0.00697, +0.00535] | +0.00184 [−0.00363, +0.00761] |
| 고정 LM + 원문 과거 직접 읽기 | — | +0.07766 | +0.03143 [+0.00760, +0.05434] |

마지막 열은 기존 학습에서 사용한 train shuffle seed 29의 첫 512개와 겹치지 않는 **offset 1000의 수신 대화 96개**를 같은 사례·정답 토큰으로 두 체크포인트에 처음 평가한 것이다. 수신 대화 ID 교집합은 0이고, 감사 평가에서 체크포인트 가중치는 그대로였다. 타인 donor는 같은 전체 train 분할에서 고르므로 donor 이력까지 미학습이라고 주장하지 않는다. 원문 대조와 순환 모델은 입력 경로가 달라 절대 차이를 순수 압축 손실로 해석하지 않는다.

**결론:** 이 한 가지 원문 효과 기반 가중치는 개인별 기억을 살리지 못했다. 기존 쓰기 전용 모델의 작은 test 이득도 새 미학습 수신자 집합에서는 재현되지 않았다. 원문 이력에는 유용한 차이가 남아 있는데 순환 상태→읽기→출력 경로에서 대부분 전달되지 않는 관찰은 강화됐다. 그렇다고 드문 사례 신호의 역할 자체를 배제할 수는 없다. 가중치 형태 하나, 단일 seed, MSC 역할극 데이터만 시험했고, 사람별 사실을 정확히 복원하거나 적절한 때 반환하는 최종 과제는 아직 검사하지 않았다.
