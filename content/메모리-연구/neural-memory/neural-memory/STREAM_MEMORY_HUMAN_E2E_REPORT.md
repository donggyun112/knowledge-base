# 실제 사람 대화 연속성 평가 — 2026-09-28

## 판정

현재 합성 대화에서 강했던 StreamRMT 체크포인트는 **실제 사람 대화에서 유용한 과거 기억을 입증하지 못했다.** 같은 96개 대화에서 과거 원문을 직접 읽는 언어모델에는 이득이 있었지만, 과거를 순환 상태로만 전달한 모델은 자기 과거가 빈 과거보다 오히려 불리했다. 개선 후보도 이 결과를 뒤집지 못했다. 따라서 후보를 채택하거나 메모리 E2E 성공이라고 주장하지 않는다.

이 평가는 최종 목표 중 **과거 대화를 읽은 내부 상태가 나중 대화 예측에 유용한가**만 검사한다. 모델에는 아직 기억 내용을 텍스트로 반환하거나 `NO_MEMORY`를 출력하거나 반환 시점을 결정하는 헤드가 없다. 엄밀한 의미의 자동 메모리 반환 E2E는 아직 테스트할 수 없다.

## 프로토콜

- 데이터: 로컬 MSC `valid`의 사람-사람 페르소나 역할극 대화 96개, 마지막 세션의 두 발화 이후 세 번째 발화 2,944토큰. 처음 16개로 파일럿을 실행한 뒤 같은 고정 프로토콜을 96개로 확대했다. MSC는 자연스러운 사적 대화가 아니며 이 split은 이전 연구에서 이미 확인했으므로 탐색적 결과다.
- 각 대화의 이전 세션에서 최근 최대 12발화/1,800자/384토큰을 시간순으로, 0으로 시작하는 8 × 576 잠재 상태에 스트리밍한다. 이후 원문은 메모리 모델에 다시 제공하지 않는다. **96개 모두 과거 이력 일부가 잘렸고**, 현재 접두부와 정답 발화는 잘리지 않았다. 따라서 전체 장기 이력의 평가는 아니다.
- 동일한 현재 두 발화와 동일한 정답 토큰을 자기 과거 상태, 빈 *이전* 상태, 다른 대화의 과거 상태에서 비교한다. 빈 조건도 현재 두 발화는 정상 처리한다. 정답 첫 토큰 이후의 손실은 앞선 정답 토큰을 본 teacher-forced 예측이다. 정답 발화는 이전 상태 구성에 사용하지 않는다.
- 추가 대조: 원래 SmolLM2와 체크포인트의 Q/V adapter가 적용된 SmolLM2가 각각 과거 **원문**을 직접 읽는다. 직접 읽기와 순환 상태는 입력 방식과 위치/attention 경로가 달라, 절대 NLL 차이를 압축 손실 하나의 인과 효과로 해석할 수 없다.
- 표의 NLL은 대화별 정답 토큰 평균 NLL을 96개 대화에 동일 가중치로 평균한 값이다. `빈−자기`가 양수여야 자기 과거가 유리하다. 95% 구간은 대화 단위 paired bootstrap 2,000회이며 donor 재사용과 이미 확인한 split 때문에 탐색적이다.

| 조건 | 자기 과거 NLL | 빈 과거 NLL | 빈−자기, 95% 구간 | 다른 과거−자기, 95% 구간 |
| --- | ---: | ---: | ---: | ---: |
| 원본 LM + 원문 직접 읽기 | 2.979 | 3.085 | +0.106 [0.077, 0.134] | +0.070 [0.042, 0.098] |
| 원래 rank-4 adapter + 원문 직접 읽기 | 4.764 | 5.322 | +0.558 [0.464, 0.651] | +0.108 [0.032, 0.182] |
| 원래 rank-4 adapter + 순환 기억 | 8.517 | 8.405 | -0.112 [-0.182, -0.042] | -0.050 [-0.141, 0.036] |
| 보호된 rank-8 후보 + 원문 직접 읽기 | 4.764 | 5.314 | +0.550 [0.456, 0.643] | +0.111 [0.038, 0.187] |
| 보호된 rank-8 후보 + 순환 기억 | 8.509 | 8.391 | -0.118 [-0.195, -0.046] | -0.060 [-0.153, 0.032] |

두 체크포인트의 평가 대화 ID·donor·정답 토큰 해시가 정확히 일치한다. 순환 기억 모델의 첫 정답 토큰 argmax 정답률은 두 체크포인트 모두 1/96이다. 원래 adapter는 순환 상태가 자기 과거인 경우 빈 과거보다 낮은 NLL을 보인 대화가 37/96개뿐이다.

## 해석과 남은 일

원문 대조의 양의 이득은 이 96개 발화에 과거 정보가 예측에 쓰일 여지가 있음을 보여준다. 그러나 원본 LM 대비 학습된 adapter 자체의 대화 NLL도 높아졌고, 원문을 직접 읽는 adapter와 순환 기억 경로의 격차도 크다. **합성 과제 적응에 따른 언어모델 저하와 순환 인터페이스/기억 전달 실패가 둘 다 관찰된다.** 이 실험만으로 내부 상태의 압축, attention/position 구성, 학습 분포 차이 중 어느 하나를 단독 원인으로 확정할 수 없다.

다음 실험은 사람 대화의 긴 이력을 더 충실하게 학습·검증하고, 같은 backbone에서 원문을 읽는 경우와 순환 상태를 읽는 경우의 손실을 줄이는 것이다. 이후 명시적 기억 텍스트와 `NO_MEMORY`/반환 시점 출력을 설계·학습하고, 실제로 필요한 순간에만 정확한 내용을 반환하는지 별도 평가해야 한다. 이 단계 전에 합성 정정 과제의 개선만으로 E2E 성능을 주장하지 않는다.

재현: `eval_stream_memory_human.py`의 `--raw-oracle --adapted-plain-control --device mps --limit 96`을 원래 체크포인트에, `--adapted-plain-control --device mps --limit 96`을 보호 후보에 적용했다. 결과는 각각 `local-data/stream-rmt-human-valid-96-adapted-seed7.json`, `local-data/stream-rmt-human-valid-96-protected-seed7.json`에 있다. 둘 다 학습 스텝 0, adapter 비트 동일성 검사 통과. 스크립트는 기존 결과 파일 덮어쓰기를 거부하며 대화 원문 대신 ID와 정답 토큰 해시를 보고한다.

## 합성 과제 최신 모델의 사람 대화 전이 검사 — 2026-09-29

사람 대화 평가기가 체크포인트의 `write_mode`, 첫 쓰기 강제 여부, 게이트 옵션을 복원하도록 수정하고, 동일한 MSC valid 96개·2,944개 정답 토큰에서 합성 과제 단일 거리 모델과 1·3·6턴 혼합 거리 모델을 비교했다. 두 결과의 대화 ID·donor ID·정답 토큰 해시는 모두 일치한다. 둘 다 **MSC로 추가 학습하지 않은** 합성 과제 체크포인트다.

| 모델 | 자기 과거 NLL | 빈−자기 [95% 구간] | 타인−자기 [95% 구간] | 첫 정답 토큰 정확도 |
| --- | ---: | ---: | ---: | ---: |
| 합성 단일 거리 | 8.986 | −0.065 [−0.200,+0.070] | +0.046 [−0.046,+0.143] | 1/96 |
| 합성 1·3·6턴 혼합 거리 | 7.786 | +0.702 [+0.571,+0.833] | +0.019 [−0.062,+0.102] | 0/96 |
| 원본 LM + 과거 원문 직접 읽기 | 2.979 | +0.106 [+0.077,+0.134] | +0.070 [+0.042,+0.098] | 28/96 |

혼합 거리 학습은 빈 이전 상태 대비 과거 상태의 영향을 크게 늘리고 절대 NLL도 낮췄지만, **타인의 과거와 구별되는 개인별 효과는 입증하지 못했다.** 원본 LM의 원문 직접 읽기는 다른 입력 경로이므로 절대 NLL 격차를 순수 압축 손실로 해석하지 않는다. 기존 valid split을 이미 반복 관찰했으며, 여기서 평가한 것은 teacher-forced 미래 발화 예측뿐이다. 저장 내용, 자유 텍스트 기억 반환, `NO_MEMORY` 및 반환 시점은 여전히 학습·평가되지 않았다. 따라서 이 결과로 체크포인트를 채택하지 않는다.

추가 결과: `local-data/stream-rmt-cf-gatedfirst-{directlong,multihorizon-directlong}-seed41.pt`에 대한 `local-data/stream-rmt-cf-gatedfirst-human-valid96-seed7.json`, `local-data/stream-rmt-cf-gatedfirst-multihorizon-human-valid96-seed7.json`. 회귀 테스트 **750개 통과**(기존 경고 1개).

## 제외된 사람 대화 요약문 지도학습 파일럿 — 2026-09-29

**2026-09-30 정정:** 아래 실험은 사람이 쓴 기억 요약문을 학습 정답으로 주었다. 이는 원 대화만으로 저장 가치와 반환을 스스로 학습해야 한다는 연구 목표와 다르다. 수치는 해당 지도 과제의 기록으로만 남기고, 목표 메모리 모델의 성공·실패 근거에서 제외한다. 학습기의 요약문 정답 분기는 제거했다.

제거 후 학습기의 입력·정답은 MSC 대화 원문과 그다음 실제 발화뿐이다. `local-data/stream-rmt-human-unlabeled-smoke-seed30.json`은 MPS에서 2/2/2개 대화·1스텝으로 경로 실행만 확인한 결과이며 성능 평가가 아니다. 전체 Python 테스트 751개 통과(기존 경고 1개).

목표를 미래 발화 예측에서 **이전에 나눈 대화의 중요한 내용을 텍스트로 예측**하는 것으로 좁혔다. MSC의 첫 세션 사람-사람 대화를 빈 상태에서 순서대로 읽고, 해당 대화에 대해 사람이 작성한 Speaker 1 요약문을 정답으로 사용했다. 정답은 입력 이력에 넣지 않았다. 이는 사람 요약문을 이용한 **지도 학습**이지, 저장 판단이나 반환 시점의 자율 학습이 아니다. 135M 언어모델은 고정하고 순환 기억 경로 635,906개 파라미터만 MPS에서 학습했다. 평가 NLL은 정답 앞부분을 본 teacher forcing이며 자유 생성 결과가 아니다.

256개 학습 대화·32개 검증·32개 테스트, 300스텝 실험의 검증 기준 선택은 50스텝이었다. 테스트에서 `빈−자기` NLL은 **+0.235** [0.200, 0.266]이지만 `타인−자기`는 **−0.008** [−0.029, +0.012]이다. 첫 토큰 정확도도 자기·타인 모두 31/32로 같다. 반면 과거 **원문을 직접 읽는** 고정 언어모델의 테스트 `타인−자기`는 +1.341이다. 즉 이 데이터에 개인별 정보는 있지만, 현재 순환 기억 모델의 이득은 개인별 내용 사용으로 설명되지 않는다. 선택된 50스텝에 실제 노출된 학습 대화 32개의 `타인−자기`도 −0.025 [−0.065, +0.002]였다.

가능성과 일반화를 분리하려고 학습 대화 8개만 300스텝 반복했다. **마지막 학습 상태**에서는 8개 모두 자기 이력이 타인 이력보다 유리했고 `타인−자기` NLL은 +0.687 [0.441, 0.938]이었다. 그러나 같은 상태의 미지 검증 32개에서는 `빈−자기`가 −1.028, `타인−자기`가 −0.010이었다. 검증 점수가 악화해 실제로 선택된 체크포인트는 학습 전 0스텝이다. 이는 경로가 소수 대화를 암기할 수는 있어도, 이 학습 설정으로 미지 대화의 중요 정보를 일반화하지 못했다는 뜻이다. 8개 학습 사례의 구간은 독립 일반화 근거가 아니다.

당시 판정은 모델을 채택하지 않는 것이었지만, 위 정정에 따라 **이 파일럿은 목표 메모리 모델의 성능 판정 자체에 쓰지 않는다.** `NO_MEMORY`, 기억 반환 시점, 자유 텍스트 반환도 이 파일럿에서 구현·평가하지 않았다. 원문 직접 읽기와 순환 상태의 절대 NLL 차이는 입력 경로가 달라 순수 압축 손실로 해석하지 않는다. MSC는 페르소나 역할극이며 valid/test는 과거에 이미 확인한 split이므로 모든 수치는 탐색적이다. 결과 파일: `local-data/stream-rmt-msc-summary-cf-300-seed29.json`, `local-data/stream-rmt-msc-summary-train-seen-seed29.json`, `local-data/stream-rmt-msc-summary-overfit8-last-seed29.json`. 당시 회귀 테스트 **751개 통과**(기존 경고 1개).
