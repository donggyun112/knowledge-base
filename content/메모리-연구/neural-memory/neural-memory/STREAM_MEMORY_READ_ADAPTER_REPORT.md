# 토큰 조건부 기억 읽기 실험 — 2026-09-28

## 결론

고정된 언어모델의 텍스트 위치에서 이전 순환 기억 상태를 직접 읽는 경로를 추가했다. 같은 사람 대화 실험에서 빈 기억 대비 자기 기억의 예측 이득은 커졌지만, **다른 사람 기억 대비 이득은 여전히 사전 합격 기준에 크게 못 미친다.** 따라서 이 체크포인트는 개인별 장기 기억 모델로 채택하지 않는다.

## 변경과 검증

- 기존 8 × 576 잠재 상태를 유지한다. 읽기 모듈은 현재 텍스트 hidden을 query로, *이전* 상태의 슬롯을 key/value로 삼아 읽은 결과를 텍스트 hidden에 잔차로 더한다. 여기서 key/value는 신경망 내부 attention 연산이지 외부 사실별 기록이나 검색 인덱스가 아니다.
- 언어모델 본체와 출력 헤드는 계속 고정한다. 기억 bridge/gate/write query와 새 읽기 모듈만 학습한다. 빈 상태의 읽기 결과는 정확히 0이며, 읽기 모듈의 마지막 projection은 0에서 출발한다. 기본 `prefix` 모드는 이전 동작을 유지한다.
- 학습에는 MSC 사람-사람 역할극 train 512개, valid/test 각 96개, Apple MPS, 600스텝, seed 29, 동일한 CE+자기/타인 대조 목적함수와 평가 설정을 사용했다. 선택된 스텝은 600이고 학습 가능 파라미터는 635,906개다. 첫 역전파에서 읽기 projection과 기억 bridge에 gradient가 도달했고 고정 언어모델에는 gradient가 없었다.
- 새 테스트에서 초기 읽기 no-op, 학습 후 빈 상태의 원래 언어모델 예측 일치, 인과성, gradient 경로를 확인했다. 전체 Python 테스트 726개 통과(기존 경고 1개). 기존 test 대화 ID·donor ID·정답 토큰 해시가 사례별로 모두 일치한다.

## 결과

수치는 대화별 평균 NLL의 동일 가중치 평균이며, 양수일수록 자기 기억이 유리하다. 기준은 `빈−자기`와 `타인−자기`가 모두 최소 +0.02 nats/target-token이고 각 95% bootstrap 구간 하한도 0보다 커야 한다.

| 선택 모델 | valid 빈−자기 | valid 타인−자기 | test 빈−자기 [95% 구간] | test 타인−자기 [95% 구간] |
| --- | ---: | ---: | ---: | ---: |
| 이전 prefix 읽기, CE+대조 | +0.0359 | +0.00134 | +0.0366 [0.0222, 0.0513] | +0.00328 [0.00077, 0.00588] |
| 새 토큰 조건부 잔차 읽기, CE+대조 | +0.0864 | +0.00069 | +0.0873 [0.0704, 0.1066] | +0.00421 [0.00044, 0.00768] |

test 96개의 짝지은 사례에서 새 읽기의 `빈−자기` 변화 평균은 +0.0506이고 73개에서 증가했다. 그러나 `타인−자기` 변화 평균은 +0.00093이며 49개 증가·47개 감소다. 별도 짝지은 변화 신뢰구간은 계산하지 않았다. 이전 원문 직접 읽기 대조는 같은 test에서 `타인−자기` +0.0777이었지만, 입력 경로가 달라 그대로 이 모델의 달성 가능 성능으로 해석할 수는 없다.

선택 모델의 자기/타인 상태 코사인 유사도 평균은 0.980(이전 prefix 0.963)이다. 공통 성분이 크다는 진단일 뿐 단독으로 원인을 확정하지 않는다. 결정적인 관찰은 **자기와 타인의 상태를 바꿔 넣어도 예측 차이가 매우 작다**는 개입 결과다. 읽기 통로만 추가해도 개인별 정보를 충분히 보존·활용하지 못했다.

## 결정과 한계

새 구조의 빈 상태 대비 예측 개선은 인정하지만, 개인별 기억 게이트는 valid/test 모두 실패했다. 본 구조를 기본값으로 바꾸거나 기존 체크포인트를 덮어쓰지 않는다. 이전 실험과 마찬가지로 모든 과거 이력이 길이 제한으로 잘렸고, MSC test는 프로젝트에서 이미 여러 차례 관찰한 탐색적 자료다. 정답 발화는 teacher forcing NLL로 평가했다. 기억 텍스트/`NO_MEMORY` 반환과 자동 반환 시점은 아직 없다. 따라서 완전한 E2E 메모리 기능의 성공은 아니다.
