# 토큰 조건부 기억 읽기 실험 — 2026-09-28

## 결론

이번에는 기억을 만드는 방식보다 **기억을 읽는 통로**를 바꾸었다. 고정된 언어모델이 텍스트를 처리하는 각 위치에서 이전 순환 기억을 직접 읽을 수 있게 했다. 읽기 통로가 부족해서 개인별 정보를 활용하지 못하는지 확인하려는 비교다.

같은 사람 대화 시험에서 빈 기억보다 자기 기억의 이득은 커졌다. 그러나 **다른 사람 기억보다 자기 기억이 유리한 정도는 여전히 사전 합격 기준에 크게 못 미쳤다.** 이 체크포인트는 개인별 장기 기억 모델로 채택하지 않는다.

## 변경과 검증

- **어디에서 기억을 읽는가:** 기존 8 × 576 잠재 상태는 유지한다. 현재 텍스트의 내부 표현(hidden)을 query, 즉 무엇을 찾을지 정하는 신호로 쓴다. *이전* 기억 슬롯은 attention의 key/value가 된다. 읽은 결과를 현재 텍스트 표현에 더하는 것이 잔차(residual) 읽기다. 여기서 key/value는 신경망 내부 연산이며 외부의 사실별 기록이나 검색 인덱스가 아니다.
- **무엇을 학습하는가:** 언어모델 본체와 출력 헤드는 고정한다. 기억 bridge/gate/write query와 새 읽기 모듈만 학습한다. 빈 상태에서 읽기 결과는 정확히 0이고, 읽기 모듈 마지막 projection도 0에서 시작한다. 기본 `prefix` 모드의 이전 동작은 그대로 둔다.
- **어떻게 비교하는가:** MSC 사람-사람 역할극 train 512개, valid/test 각 96개를 쓴다. Apple MPS, 600스텝, seed 29이며 CE+자기/타인 대조 목적함수와 평가 설정은 기존과 같다. 선택된 상태는 600스텝이고 학습 가능 파라미터는 635,906개다. 첫 역전파에서 읽기 projection과 기억 bridge까지 기울기가 도달했고, 고정 언어모델에는 기울기가 없었다.
- **구현이 비교를 깨지 않았는가:** 초기 읽기가 아무 변화도 만들지 않는 no-op인지, 학습 후에도 빈 상태가 원래 언어모델의 예측과 같은지, 미래 정보가 새지 않는지, 기울기 경로가 이어지는지 검사했다. 전체 Python 테스트 726개 통과(기존 경고 1개). 기존 시험과 대화 ID·donor ID·정답 토큰 해시가 사례별로 모두 일치한다.

## 결과

NLL은 정답 토큰을 얼마나 잘 예측했는지 재는 손실로, 낮을수록 좋다. 대화별 평균을 먼저 구하고 모든 대화에 같은 가중치를 주었다. 표에는 빈 기억 또는 타인 기억의 손실에서 자기 기억의 손실을 뺀 값을 적었다. 따라서 양수일수록 자기 기억이 유리하다.

채택하려면 `빈−자기`와 `타인−자기`가 모두 최소 +0.02 nats/target-token이어야 하며, 각각의 95% bootstrap 구간 하한도 0보다 커야 한다. 단순히 평균이 조금 양수라는 것만으로는 통과가 아니다.

| 선택 모델 | valid 빈−자기 | valid 타인−자기 | test 빈−자기 [95% 구간] | test 타인−자기 [95% 구간] |
| --- | ---: | ---: | ---: | ---: |
| 이전 prefix 읽기, CE+대조 | +0.0359 | +0.00134 | +0.0366 [0.0222, 0.0513] | +0.00328 [0.00077, 0.00588] |
| 새 토큰 조건부 잔차 읽기, CE+대조 | +0.0864 | +0.00069 | +0.0873 [0.0704, 0.1066] | +0.00421 [0.00044, 0.00768] |

test 96개를 같은 사례끼리 비교하면 새 읽기는 `빈−자기` 이득을 평균 +0.0506 늘렸고, 73개 사례에서 이 값이 증가했다. 반면 개인별 구별을 보는 `타인−자기` 변화는 평균 +0.00093에 그쳤다. 증가 49개, 감소 47개로 나뉘었다. 이 짝지은 변화량의 신뢰구간은 따로 계산하지 않았다.

이전 원문 직접 읽기 대조의 같은 test `타인−자기`는 +0.0777이었다. 다만 원문과 순환 기억은 입력 경로가 다르다. 그 값을 이 모델이 그대로 달성할 수 있는 성능이라고 해석해서는 안 된다.

자기 상태와 타인 상태의 방향이 얼마나 비슷한지를 재는 코사인 유사도는 평균 0.980이었다(이전 prefix는 0.963). 공통 성분이 크다는 진단이지만, 이 유사도만으로 원인을 확정하지 않는다.

핵심 근거는 **자기 상태를 타인 상태로 실제 교환해도 예측 차이가 매우 작았다**는 점이다. 읽기 통로를 추가했는데도 개인별 정보를 충분히 보존하고 활용하는 데 이르지 못했다.

## 결정과 한계

빈 상태 대비 예측 개선은 확인했다. 하지만 개인별 기억의 채택 기준은 valid/test 모두 통과하지 못했으므로, 새 구조를 기본값으로 바꾸거나 기존 체크포인트를 덮어쓰지 않는다.

이번에도 길이 제한으로 모든 과거 이력이 일부 잘렸다. MSC test는 프로젝트에서 이미 여러 차례 본 자료여서 결과는 탐색적이다. 정답 발화는 앞선 정답 토큰을 제공하는 teacher forcing NLL로 평가했다. 기억 텍스트/`NO_MEMORY` 반환과 자동 반환 시점은 아직 구현하지 않았으므로, 완전한 E2E 메모리 기능의 성공으로 보지 않는다.
