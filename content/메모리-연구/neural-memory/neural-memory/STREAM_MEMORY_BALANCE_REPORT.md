# 정정·반복 간섭 균형 실험 — 2026-09-27

후속 [[메모리-연구/neural-memory/neural-memory/STREAM_MEMORY_RETENTION_REPORT|표현 다양화·출력 유지 제약 실험]]은 세 실행 모두 조건별 검증 유지 기준을 못 넘어 새 가중치를 채택하지 않았다. 마지막 가중치에서 새 값의 `is now` 표현은 학습됐지만 표현/정정/간섭 회귀가 남았다. 아래는 그 이전 균형 실험 결과로 보존한다.

## 결론

**반복 간섭 내성은 개선됐지만, 정정과 표현 일반화를 함께 유지한다는 목표는 통과하지 못했다.** 새로 남겨둔 64개 답 값에서 다른 화자의 후보 사실 여덟 번 조건은 seed 7: **62.50% → 78.13%**, seed 17: **59.38% → 78.91%**였다. 같은 시작점의 일반 잡담 대조(seed 17)는 65.63%였다.

반면 같은 새 값의 본인 정정은 **85.16% → 81.25%, 84.38% → 78.91%**로 내려갔다. 미학습 정정 표현은 두 seed 모두 **48.44%**로 악화됐다. 검증에서는 조건별 유지 기준을 통과했지만 시험의 유지까지 보장하지 못했다. 따라서 이번 선택 가중치를 모든 조건에서 더 좋은 모델로 채택하지 않고, **개선과 회귀를 모두 포함한 실험 가중치로 보존**한다. 이전 정정 가중치는 덮어쓰지 않았다.

## 유지한 구조와 변경한 학습

시작점은 [[메모리-연구/neural-memory/neural-memory/STREAM_MEMORY_REVISION_REPORT|정정 학습]]의 깨끗한 재실험 `stream-rmt-revision-clean-seed{7,17}.pt`다. frozen SmolLM2-135M 본체·LM head, Q/V 저차원 갱신, bridge/gate/shared write query, **568,513개 학습 파라미터**, **8×576 상태(18 KiB, float32)**를 그대로 사용했다. 독립 대화의 기억은 0에서 시작한다. 외부 KV 기록, 검색, 화자별 수동 저장, 중요도/정정 라벨, tool 문법은 추가하지 않았다.

기존 여섯 조건에 다섯 간섭 조건을 추가했다. 기본 조건은 단일 사실, 본인 정정, 정정 표현 없는 본인 값 변경, 두 번 정정, 다른 화자의 세 사실, 정정 뒤 다른 화자의 세 사실이다. 추가 조건은 후보 단어 언급, 다른 화자의 후보 사실 여덟 번, 다른 화자의 한 값 여덟 번 반복, 정정 뒤 후보 사실 여덟 번, 한 단어 언급 여덟 번 반복이다. 후보 경쟁 조건은 현재 8개 답 후보를 모두 같은 순서로 제시하며, 한 값 반복 조건은 답 그룹 밖의 학습 값 하나를 사용한다.

학습 답 256값 × 11조건 × 잡담 배치 두 개 = **5,632대화**다. 기존 정정 조건도 함께 재학습했다. 옛값과 다른 화자의 값은 학습 split에서만 뽑았다. 헤더는 무작위 숫자이고 상황 이름은 감사용 metadata에만 있다. 8개 반사실 대화에서 본인 사실의 현재 값과 마지막 답만 달라지며, 사실은 마지막 32토큰 원문 창 밖에 있다. 이 제약은 입력 감사에만 사용하고 손실은 **마지막 미래 구간의 모든 대화 내용 next-token CE**다. 답 전용 손실이나 정답 위치를 이용한 메모리 쓰기는 아니다.

Apple M4 Pro/MPS GPU, float32, batch 2, lr 0.00015, gradient norm 1 clipping, 최대 추가 **800스텝**을 세 실행에 동일하게 적용했다. 모델별 전체 학습·검증·시험 실행은 약 19~20분이었다. backbone의 사전학습 지식과 공유 학습 가중치는 존재하므로, 상태가 0이라는 것이 모델 전체에 사전 지식이 없다는 뜻은 아니다.

## 새 값과 선택 기준

MSC train 발화의 단어 빈도로 만들었던 같은 512개 후보를 같은 seed로 다시 섞어 이전 manifest를 연장했다. 기존 train 256값·valid 32값·이전 probe 8값·이전 test 64값을 정확히 보존하는지 확인하고, 추가 64값을 이번 시험으로 분리했다. 이전 test는 `previous_test`, 새 64값은 `test`다. **이번 추가 학습/검증의 답·옛값·다른 화자 사실 값으로 새 시험 답을 쓰지 않았고, 학습과 선택을 끝낸 후에 시험 대화를 구성·평가했다.** LM 사전학습 미사용 단어라는 뜻은 아니다. 단어 추출에 MSC를 썼지만 실제 사람 대화로 학습한 실험은 아니다.

32개 검증 값 × 11조건 = 352사례를 100스텝마다 검사했다. 각 조건의 전체 어휘 정확도가 시작점보다 **1/32사례(3.125%p)를 초과해 하락하면 탈락**시켰다. 통과한 후보에서 가장 낮은 조건 정확도를 최대화하고 동률이면 평균 답 NLL을 최소화했다. 초기 가중치도 선택 가능하다. 이 선택 규칙은 검증용이며 신경망 안에 저장 규칙을 넣은 것이 아니다. 하락을 전혀 허용하지 않는 기준도 아니고, 시험 점수의 보증도 아니다.

| 실행 | 선택 스텝 | 검증 최저 정확도 시작 → 선택 | 실제 미래 내용 손실 토큰 수 |
| --- | ---: | ---: | ---: |
| 간섭 혼합 seed 7 | 400 | 50.00% → 68.75% | 13,812 |
| 간섭 혼합 seed 17 | 700 | 46.88% → 65.63% | 14,050 |
| 일반 잡담 대조 seed 17 | 400 | 46.88% → 65.63% | 13,203 |

seed 7의 800스텝은 정정/값 변경 하락으로 탈락했다. seed 17의 혼합 학습은 700스텝만 통과했고 나머지 일곱 후보는 조건별 하락으로 탈락했다. 모든 선택 결정을 저장된 검증 기록으로 재계산해 일치하는지 검사했다. 시험을 보고 선택 스텝이나 허용 하락을 바꾸지 않았다.

일반 잡담 대조는 같은 seed 17 시작점·답 샘플 순서·대화 수·최대 스텝·batch/lr·검증/선택 규칙을 사용한다. 다섯 추가 간섭 조건의 여덟 발화만 일반 잡담으로 바꿨고, 기존 여섯 정정/보존 조건은 같다. **최대 갱신·답 샘플 예산을 맞춘 대조이지 문장 길이나 내용 토큰 예산까지 동등한 대조는 아니다.**

## 새 64값 주 시험

조건별 64값 × 두 잡담 배치 = **128사례**, 전체 1,408사례다. 표는 LM **전체 어휘의 단일 토큰 argmax 정확도**이며 후보 제한 8지선다 점수로 대체하지 않는다.

자기 기억을 비우면 선택 모델의 모든 주 시험 조건에서 전체 어휘 정확도 **0%**다. 다른 대화의 기억으로 바꾸면 후보 사실 여덟 번에서 seed 7은 1/128건(0.78%), seed 17은 2/128건(1.56%)이고 나머지는 0%다. 자기 상태가 빈/교환 상태보다 낫지만, 이는 정확한 저장 중요도나 반환 시점이 학습됐다는 증거는 아니다.

같은 8개 답 후보 그룹을 공유하는 두 잡담 배치를 함께 bootstrap했다. 후보 사실 여덟 번의 시작 대비 개선 95% 탐색적 구간은 seed 7: **+0.78~+32.03%p**, seed 17: **+5.47~+39.06%p**다. seed 17의 대조 대비 개선은 +13.28%p, 구간 **+4.69~+24.22%p**다. 128행을 독립 표본으로 취급하지 않았고 다중 비교 보정은 하지 않았다. 정정 하락의 구간은 두 seed 모두 0을 포함하므로 통계적으로 확정된 일반 회귀라고 단정하지 않는다. 다만 관측 점수가 하락한 이상 정정 유지 목표를 달성했다고도 주장하지 않는다.

## 16번 간섭과 미학습 표현

이번 학습·검증의 간섭은 여덟 번이며, 별도 시험은 **16번**으로 늘렸다. 새 64값 × 잡담 배치 하나, 조건별 64사례다. 잡담은 16·32턴을 사실 앞뒤에 분산했다. 미학습 표현은 `I changed my secret word to ...`이며 학습에 넣거나 가중치 선택에 사용하지 않았다.

seed 17의 긴 간섭 개선과 seed 7의 회귀가 공존한다. 잡담 draw/구간 경계도 다른 별도 시험이므로 여덟 번과 16번의 점수 차이를 반복 횟수만의 인과 효과로 해석하지 않는다. **두 seed 모두 미학습 정정 표현이 악화**됐고 전체 균형 목표를 미달했다고 판단하는 중요한 근거다. 두 비교의 입력 digest는 일치하고 평가 전후 adapter도 동일했다. 빈 상태는 모든 조건 0%, 교환 상태는 최대 1/64건이었다.

## 검증 범위와 보존한 산출물

반복 간섭 대화를 추가하면 이 구조의 보존 성능이 변하고 일부 간섭은 개선된다. 하지만 이번 검사만으로 writer/gate/reader 중 무엇이 원인인지 분리하지 않았다. 32값의 검증 유지 기준이 다른 어휘·미학습 표현·긴 간섭까지 일반화되지 않았다는 **관측**은 얻었지만, 실패 원인을 한 모듈로 확정할 증거는 없다. 여러 속성·실제 사람 대화·자동 저장 중요도·기억 텍스트 반환·`NO_MEMORY`/반환 타이밍은 여전히 미검증이다.

전체 **602 passed**, 기존 requires-grad scalar 경고 1개다. 신규 29개 검사는 반사실 균형, 입력 헤더 힌트 방지, annotation 독립 손실과 gradient, 미래 답 누출 방지, manifest 연장, 대조의 샘플 순서, 조건별 선택·비교 불일치 거부를 포함한다. 실행 후 분석은 학습/검증/새 시험/이전 시험 입력을 전부 재생성하고 선택 결정을 검증했다. 정적 codecanvas 색인에는 해당 실험 함수가 없어 CPU/GPU 실행과 테스트로 확인했다.

가중치/전체 기록은 `local-data/stream-rmt-balance-mixed-seed{7,17}.{pt,json}`, 대조는 `stream-rmt-balance-replay-seed17.{pt,json}`다. 각 실행의 `-last.pt`에는 800스텝 마지막 가중치를 별도로 남겼다. `stream-rmt-balance-manifest.json`에 이전 manifest SHA-256과 분리한 값을 기록했다. 입력 감사·그룹별 비교는 `stream-rmt-balance-comparison.json`, 기존 원문 평가는 `stream-rmt-balance-transfer-mixed-seed{7,17}.json`, 긴 간섭/표현 검사는 `stream-rmt-balance-stress-mixed-seed{7,17}.json`이다. 출력 덮어쓰기는 거부한다. 이전 가중치와 사용자 수정은 보존했다.

실행기는 `run_stream_memory_balance.py`, 데이터/선택 기준은 `stream_memory_balance_data.py`, 분석은 `analyze_stream_memory_balance.py`, 별도 검사는 `eval_stream_memory_balance_stress.py`다. 새 출력 이름으로 재현한다.

```sh

HF_HUB_OFFLINE=1 TRANSFORMERS_OFFLINE=1 .venv/bin/python eval_stream_memory_balance_stress.py --checkpoint local-data/balance-reproduction-seed17.pt --reference local-data/stream-rmt-revision-clean-seed17.pt --manifest local-data/stream-rmt-balance-manifest.json --output local-data/balance-reproduction-stress-seed17.json
```
