# 정정·반복 간섭 균형 실험 — 2026-09-27

후속 [[메모리-연구/neural-memory/neural-memory/STREAM_MEMORY_RETENTION_REPORT|표현 다양화·출력 유지 제약 실험]]은 세 실행 모두 조건별 검증 유지 기준을 못 넘어 새 가중치를 채택하지 않았다. 마지막 가중치에서 새 값의 `is now` 표현은 학습됐지만 표현/정정/간섭 회귀가 남았다. 아래는 그 이전 균형 실험 결과로 보존한다.

## 결론

**반복 간섭에 대한 내성은 개선됐지만, 정정 능력과 새로운 표현으로의 일반화를 함께 유지하는 목표는 통과하지 못했다.** 새로 남겨 둔 64개 답 값에서 다른 화자의 후보 사실을 여덟 번 제시한 조건은 seed 7: **62.50% → 78.13%**, seed 17: **59.38% → 78.91%**로 개선됐다. 같은 시작점에서 일반 잡담만 추가한 대조(seed 17)는 65.63%였다.

하지만 같은 새 값의 본인 정정은 **85.16% → 81.25%, 84.38% → 78.91%**로 낮아졌다. 학습에 없던 정정 표현도 두 seed 모두 **48.44%**로 악화됐다. 검증 자료에서 조건별 유지 기준을 통과해도 시험에서 같은 성능을 유지한다는 보장은 없었다.

따라서 이번 가중치를 모든 조건에서 더 좋은 모델로 채택하지 않는다. **개선과 회귀를 함께 보여 주는 실험 가중치로 보존**하며, 이전 정정 가중치는 덮어쓰지 않았다.

## 유지한 구조와 변경한 학습

출발점은 [[메모리-연구/neural-memory/neural-memory/STREAM_MEMORY_REVISION_REPORT|정정 학습]]에서 입력 힌트를 제거하고 다시 학습한 `stream-rmt-revision-clean-seed{7,17}.pt`다. SmolLM2-135M 본체와 LM head는 고정했다. Q/V 저차원 갱신, bridge/gate/shared write query를 사용하는 **568,513개 학습 파라미터**와 **8×576 상태(18 KiB, float32)**는 그대로다.

각 독립 대화의 기억은 0에서 시작한다. 외부 KV 기록이나 검색, 수동 화자별 저장, 중요도/정정 라벨, 도구 문법은 추가하지 않았다.

반복 간섭을 직접 경험하게 하려고 기존 여섯 조건에 다섯 조건을 추가했다. 기존 조건은 단일 사실, 본인 정정, 정정 표현 없는 본인 값 변경, 두 번 정정, 다른 화자의 세 사실, 정정 뒤 다른 화자의 세 사실이다.

추가 조건은 후보 단어 언급, 다른 화자의 후보 사실 여덟 번, 다른 화자의 한 값 여덟 번 반복, 정정 뒤 후보 사실 여덟 번, 한 단어 언급 여덟 번 반복이다. 후보가 경쟁하는 조건에서는 현재 8개 답 후보를 모두 같은 순서로 제시한다. 한 값만 반복하는 조건에서는 답 그룹 밖의 학습 값 하나를 쓴다.

학습 자료는 답 256값 × 11조건 × 잡담 배치 두 개로, 모두 **5,632대화**다. 기존 정정 조건도 함께 재학습하고 옛값과 다른 화자의 값은 학습 분할에서만 골랐다. 상황 이름은 감사용 메타데이터에만 남기고 입력 헤더에는 무작위 숫자를 썼다.

같은 묶음의 8개 반사실 대화는 본인 사실의 현재 값과 마지막 답만 다르다. 사실은 마지막 32토큰 원문 창 밖에 있어야 한다. 이 위치 제약은 입력 검사에만 쓰며 손실은 **마지막 미래 구간의 모든 대화 내용에 대한 다음 토큰 교차엔트로피(CE)**다. 답만 학습하는 손실도, 정답 위치를 이용해 기억을 쓰는 방식도 아니다.

세 실행 모두 Apple M4 Pro/MPS GPU의 float32에서 배치 크기 2, 학습률 0.00015, 기울기 노름 상한 1로 최대 **800스텝** 추가 학습했다. 모델별 학습·검증·시험 전체 실행에는 약 19~20분이 걸렸다.

대화 상태가 0에서 시작한다는 것은 개인별 기억이 비어 있다는 뜻이다. 기반 모델의 사전학습 지식과 대화들이 공유하는 학습 가중치는 여전히 있으므로, 모델 전체에 사전 지식이 없다는 의미는 아니다.

## 새 값과 선택 기준

새 시험 값을 확보하려고 MSC 학습 발화의 단어 빈도로 만든 같은 512개 후보를 같은 seed로 다시 섞고, 이전 값 분할 목록을 연장했다. 기존 학습 256값·검증 32값·이전 진단 8값·이전 시험 64값을 정확히 보존하는지 확인한 다음 추가 64값을 이번 시험으로 분리했다. 이전 시험은 `previous_test`, 새 64값은 `test`다.

**이번 추가 학습과 검증에서는 새 시험 답을 답·옛값·다른 화자의 사실 값 어느 용도로도 쓰지 않았다. 시험 대화는 학습과 모델 선택을 마친 뒤 구성·평가했다.** 다만 LM 사전학습에서도 사용하지 않은 단어라는 뜻은 아니다. MSC는 단어 추출에만 이용했으므로 실제 사람 대화로 학습한 실험도 아니다.

모델 선택에서는 평균 개선만으로 기존 능력의 하락을 가리지 않도록 조건별 기준을 뒀다. 32개 검증 값 × 11조건의 352사례를 100스텝마다 평가하고, 어느 조건이든 전체 어휘 정확도가 시작점보다 **1/32사례(3.125%p)를 초과해 떨어지면 탈락**시켰다.

통과한 후보 중에서는 가장 낮은 조건 정확도가 높은 모델을 고르고, 동률이면 평균 답 NLL이 낮은 모델을 선택했다. 초기 가중치도 후보였다. 이는 검증용 선택 규칙이지 신경망 안에 넣은 저장 규칙은 아니다. 성능 하락을 전혀 허용하지 않는 기준도 아니며 시험 점수를 보증하지도 않는다.

| 실행 | 선택 스텝 | 검증 최저 정확도 시작 → 선택 | 실제 미래 내용 손실 토큰 수 |
| --- | ---: | ---: | ---: |
| 간섭 혼합 seed 7 | 400 | 50.00% → 68.75% | 13,812 |
| 간섭 혼합 seed 17 | 700 | 46.88% → 65.63% | 14,050 |
| 일반 잡담 대조 seed 17 | 400 | 46.88% → 65.63% | 13,203 |

seed 7의 800스텝은 정정/값 변경 하락으로 탈락했다. seed 17의 혼합 학습은 700스텝만 통과했고 나머지 일곱 후보는 조건별 하락으로 탈락했다. 모든 선택 결정을 저장된 검증 기록으로 재계산해 일치하는지 검사했다. 시험을 보고 선택 스텝이나 허용 하락을 바꾸지 않았다.

일반 잡담 대조는 간섭 대화를 추가한 효과를 확인하기 위한 것이다. seed 17의 시작점, 답 샘플 순서, 대화 수, 최대 스텝, 배치 크기/학습률, 검증·선택 규칙을 같게 맞췄다. 다섯 추가 간섭 조건에 있는 여덟 발화만 일반 잡담으로 바꾸고 기존 여섯 정정/보존 조건은 유지했다.

따라서 **최대 갱신 횟수와 답 샘플 예산은 같지만, 문장 길이나 내용 토큰 예산까지 동등한 대조는 아니다.**

## 새 64값 주 시험

각 조건은 64값에 두 잡담 배치를 적용한 **128사례**이며 전체는 1,408사례다. 표에는 LM **전체 어휘에서 가장 높은 확률의 단일 토큰을 고른 정확도**를 제시한다. 후보를 제한한 8지선다 점수로 대신하지 않는다.

자기 기억을 비우면 선택 모델의 모든 주 시험 조건에서 전체 어휘 정확도 **0%**다. 다른 대화의 기억으로 바꾸면 후보 사실 여덟 번에서 seed 7은 1/128건(0.78%), seed 17은 2/128건(1.56%)이고 나머지는 0%다. 자기 상태가 빈/교환 상태보다 낫지만, 이는 정확한 저장 중요도나 반환 시점이 학습됐다는 증거는 아니다.

불확실성은 같은 8개 답 후보 그룹을 공유하는 두 잡담 배치를 함께 묶어 부트스트랩했다. 후보 사실 여덟 번 조건의 시작 대비 개선 95% 탐색적 구간은 seed 7: **+0.78~+32.03%p**, seed 17: **+5.47~+39.06%p**였다. seed 17의 일반 잡담 대조 대비 개선은 +13.28%p, 구간은 **+4.69~+24.22%p**였다. 128행을 독립 표본으로 취급하지 않았고 다중 비교 보정은 하지 않았다.

정정 하락의 구간은 두 seed 모두 0을 포함한다. 따라서 일반적인 회귀가 통계적으로 확정됐다고 단정하지 않는다. 다만 실제 관측 점수가 떨어졌으므로 정정 유지 목표를 달성했다고도 주장하지 않는다.

## 16번 간섭과 미학습 표현

이번 학습·검증의 간섭은 여덟 번이며, 별도 시험은 **16번**으로 늘렸다. 새 64값 × 잡담 배치 하나, 조건별 64사례다. 잡담은 16·32턴을 사실 앞뒤에 분산했다. 미학습 표현은 `I changed my secret word to ...`이며 학습에 넣거나 가중치 선택에 사용하지 않았다.

| 조건 | seed 7 정정 모델 → 이번 혼합 | seed 17 정정 모델 → 이번 혼합 |
| --- | ---: | ---: |
| Friend 후보 사실 16번 | 60.94% → 56.25% | 56.25% → 84.38% |
| Friend 한 값 16번 반복 | 53.13% → 70.31% | 50.00% → 84.38% |
| 본인 정정 뒤 후보 사실 16번 | 92.19% → 84.38% | 79.69% → 89.06% |
| 미학습 정정 표현 | 62.50% → 48.44% | 60.94% → 48.44% |
| 미학습 정정 표현 뒤 Friend 세 사실 | 51.56% → 42.19% | 57.81% → 68.75% |

긴 간섭에서 seed 17은 개선됐지만 seed 7은 일부 회귀했다. 이 별도 시험은 뽑힌 잡담과 구간 경계도 다르므로, 여덟 번과 16번 조건의 점수 차이를 반복 횟수만의 인과 효과로 읽지 않는다.

특히 **두 seed 모두 미학습 정정 표현이 악화**됐다. 전체 균형 목표를 달성하지 못했다고 판단한 중요한 근거다. 두 모델 비교의 입력 해시는 같고 평가 전후 어댑터도 동일했다. 빈 상태는 모든 조건 0%, 교환 상태는 최대 1/64건이었다.

## 검증 범위와 보존한 산출물

반복 간섭 대화를 학습에 추가하면 이 구조의 보존 성능이 바뀌고 일부 간섭 조건은 개선된다. 하지만 이번 실험은 쓰기·게이트·읽기 중 어느 부분이 변화를 일으켰는지 분리하지 않았다.

확인한 것은 **32값에서 통과한 검증 유지 기준이 다른 어휘·미학습 표현·긴 간섭까지 이어지지 않았다는 관측**이다. 실패를 특정 모듈 하나로 확정할 근거는 없다. 여러 속성, 실제 사람 대화, 자동 저장 중요도 판단, 기억 텍스트 반환, `NO_MEMORY`/반환 시점은 여전히 미검증이다.

전체 **602개 검사가 통과했고** 기존 requires-grad scalar 경고 1개가 남았다. 신규 29개 검사에는 반사실 균형, 입력 헤더의 힌트 방지, 위치 표시와 독립인 손실·기울기, 미래 답 누출 방지, 값 분할 목록 연장, 대조의 샘플 순서, 조건별 선택과 잘못된 비교의 거부가 포함된다.

실행 후에는 학습·검증·새 시험·이전 시험의 입력을 모두 재생성하고 선택 결정도 검증했다. 정적 codecanvas 색인에는 해당 함수가 없어 CPU/GPU 실행과 테스트로 확인했다.

가중치/전체 기록은 `local-data/stream-rmt-balance-mixed-seed{7,17}.{pt,json}`, 대조는 `stream-rmt-balance-replay-seed17.{pt,json}`다. 각 실행의 `-last.pt`에는 800스텝 마지막 가중치를 별도로 남겼다. `stream-rmt-balance-manifest.json`에 이전 manifest SHA-256과 분리한 값을 기록했다. 입력 감사·그룹별 비교는 `stream-rmt-balance-comparison.json`, 기존 원문 평가는 `stream-rmt-balance-transfer-mixed-seed{7,17}.json`, 긴 간섭/표현 검사는 `stream-rmt-balance-stress-mixed-seed{7,17}.json`이다. 출력 덮어쓰기는 거부한다. 이전 가중치와 사용자 수정은 보존했다.

실행기는 `run_stream_memory_balance.py`, 데이터/선택 기준은 `stream_memory_balance_data.py`, 분석은 `analyze_stream_memory_balance.py`, 별도 검사는 `eval_stream_memory_balance_stress.py`다. 새 출력 이름으로 재현한다.

```sh
HF_HUB_OFFLINE=1 TRANSFORMERS_OFFLINE=1 .venv/bin/python run_stream_memory_balance.py --manifest local-data/stream-rmt-balance-manifest.json --warm-start local-data/stream-rmt-revision-clean-seed17.pt --seed 17 --steps 800 --mode mixed --output local-data/balance-reproduction-seed17.json
HF_HUB_OFFLINE=1 TRANSFORMERS_OFFLINE=1 .venv/bin/python eval_stream_memory_balance_stress.py --checkpoint local-data/balance-reproduction-seed17.pt --reference local-data/stream-rmt-revision-clean-seed17.pt --manifest local-data/stream-rmt-balance-manifest.json --output local-data/balance-reproduction-stress-seed17.json
```
