# 연속 대화로 학습하는 신경망 메모리 — 2026-09-27

## 목표와 이번 단계의 경계

최종 목표는 계속 들어오는 텍스트 토큰을 보고 개인별 빈 기억에서 출발해 내부 기억을 갱신하고, 적절한 때 기억 내용을 반환하는 **메모리 역할의 딥러닝 모델**이다. 외부 key/value 기록, 벡터 검색, 저장·검색 도구 문법은 사용하지 않는다.

이번 단계는 그중 **중요도 라벨 없이 대화 자체에서 기억 동작을 배우는지** 검증한다. 기억 내용 텍스트/`NO_MEMORY` 출력은 아직 구현하지 않았다. 출력 예측에 도움이 되는 기억 상태를 학습한 결과만으로 최종 인터페이스의 성공을 주장하지 않는다.

이 문서는 앞선 residual 보정 모듈 실험의 결과를 지우지 않는다. 사용자와 다시 합의한 목표에 맞춰 다음 구현의 학습 경로를 정의한다.

## 입력·상태·출력

공유 학습 파라미터와 대화별 기억은 구분한다. 공유 파라미터는 여러 대화에서 기억 동작을 학습한다. 새로운 대화의 기억 `M0`는 전부 0이며 해당 대화에 대한 정보를 포함하지 않는다. 대화 구간·세션 사이에는 상태를 유지하고, 독립 대화로 바꿀 때 초기화한다.

```text
이전 기억 M(t-1) + 현재 구간의 텍스트 토큰
    → 공유 Transformer의 모든 층에서 처리
    → 현재 구간의 읽기 표현 + 갱신된 기억 M(t)

뒤 구간의 대화 내용 예측 손실
    → 읽기 경로 → 앞선 기억 상태 → 앞선 갱신 파라미터
```

기본 구현의 기억은 `[batch, 8, 576]` 잠재 상태다. 대화별 18 KiB(float32)이며, 문장별 key/value 레코드가 아니다. `observed` 불리언은 빈 초기 상태의 prefix를 마스킹하기 위한 표식이지 저장할 사실의 중요도 라벨이 아니다.

## 구현

StreamRecurrentMemory (`neural_memory/stream_recurrent_memory.py`; 원 저장소의 파일 참조)는 입력을 `[읽기 기억, 현재 텍스트, 쓰기 기억]`으로 처리한다. 끝의 기억 위치에서 나온 상태를 다음 구간으로 전달한다. 이는 [RMT](https://arxiv.org/html/2207.06881v2)의 순환 원리를 따른다.

- 텍스트 위치는 이전 기억과 현재까지의 텍스트만 볼 수 있다. 뒤의 쓰기 위치를 볼 수 없다.
- 읽기 기억 위치는 이전 기억 블록만 볼 수 있다. 현재·미래 텍스트를 미리 보지 않는다.
- 쓰기 위치는 이전 기억과 현재 구간의 모든 관측 토큰을 본다.
- 기억 블록 내부의 attention은 양방향, 텍스트 내부는 인과적이다.
- 초기 빈 기억은 텍스트에서 완전히 가려진다. 동일 모델에 메모리 없이 텍스트만 넣은 hidden과 일치하는지 검사한다.
- 패딩 길이에 따라 쓰기 위치의 rotary position을 보정한다. 패딩 추가가 기억을 바꾸는 버그를 검사에서 발견해 수정했다.
- 구간 사이의 Transformer KV cache는 사용하지 않는다. 이전 원문은 다음 구간에 다시 제공하지 않는다. 다만 예측 경계에서 누락되는 토큰이 없도록 직전 관측 토큰 1개를 겹친다. 이 토큰은 자기/빈/교환 조건에 동일하게 제공한다.
- 학습 에피소드 안에서 기억 상태를 `detach`하지 않는다.

논문 전체 재현은 아니다. 계산을 줄이기 위해 SmolLM2-135M의 본체·출력 헤드를 고정하고 attention Q/V의 저차원 갱신과 기억 상태의 bias-free projection만 학습한다. 최종 normalized hidden을 입력 크기로 맞추는 projection도 원 논문과 다른 요소다. 기본 rank 4에서 학습 파라미터는 562,176개다. Q/V 갱신은 일반 언어 예측도 바꿀 수 있으므로 동일 가중치의 빈/교환 상태 대조가 필수다.

출력 헤드는 학습 신호를 제공하는 보조 예측기다. 메모리 모듈의 `forward_segment` 자체는 전체 답변을 생성하지 않고 읽기 표현과 다음 기억 상태를 반환한다. 하지만 공유 Transformer를 포함하므로 아직 별도의 작은 독립 메모리 모델로 분리한 것도 아니다.

## 학습 데이터와 목적함수

실행기 (`run_stream_recurrent_memory.py`; 원 저장소의 파일 참조)는 MSC 사람 대화를 원래 시간 순서로 읽는다. 사람이 정한 중요도·저장 여부·정답 근거·구간 제거 라벨, 교사 hidden 증류, contrastive 학습 손실은 사용하지 않는다.

```text
L = 관측 대화 내용 토큰의 평균 next-token cross entropy
```

화자·세션 표식은 입력에 있지만 주요 손실에는 들어가지 않는다. 이 마스크는 대화 내용과 형식을 구분할 뿐, 어떤 내용이 중요하다고 지정하지 않는다. 같은 인물 쌍의 세션을 모아 독립 에피소드로 사용한다.

파일럿은 64토큰 구간 6개, 총 최대 379토큰의 대화 앞부분만 처리한다. 따라서 여러 세션 전체를 장기간 학습했다거나 생애 기억을 검증했다고 말할 수 없다. 장기 horizon 확대는 이 짧은 경로의 검증 이후다.

모든 구간에서 쓰기 결과는 전달된다. 무엇을 표현에 보존하는지는 학습되지만, 명시적 무쓰기·망각·출력 침묵 판단이 학습됐다고 주장하지 않는다.

## 후속 갱신 안정성 변형

기본 `overwrite`는 이전 결과를 전부 교체하며 이전 실험 재현을 위해 유지한다. 선택 가능한 `gated` 변형은 다음처럼 기존 상태의 직접 전달 경로를 추가한다.

```text
proposal = bridge(쓰기 위치의 Transformer 출력)
gate = sigmoid(Linear[이전 상태, proposal, 현재 유효 입력의 평균])
M(t) = M(t-1) + gate * (proposal - M(t-1))
```

gate는 슬롯별 값이며 관측 텍스트 예측 손실로 학습한다. 저장 중요도 라벨은 입력하지 않는다. 첫 비어 있던 상태는 제안 상태로 채우고 이후부터 gate를 적용한다. 빈 구간은 아무것도 바꾸지 않는다. 초기 gate 값 0.01은 보존 경로의 초기화일 뿐, 학습 이후에도 고정한 규칙이 아니다.

별도 옵션으로 쓰기 위치에 작은 학습 가능한 공유 query를 더한다. 이는 모든 대화에서 공유하는 파라미터이며 해당 인물의 기억 내용이 아니다. 초기 `M0`는 여전히 0이고 query는 현재 텍스트에서 보이지 않는 suffix에만 있다. 이 옵션과 gate의 효과는 각각 제거한 대조 실행으로 확인한다.

8슬롯·576차원·rank 4에서 gate와 query를 모두 추가하면 학습 파라미터는 568,513개다. 대화별 상태 크기는 그대로다.

인공 회상 과제에서는 짧은 구간 간 거리에서 먼저 학습하고 긴 거리로 늘리는 curriculum도 검사한다. 각 단계가 실제 과거 원문을 읽고 뒤 관측 텍스트를 예측하며, 사실 위치를 보고 state를 채우는 oracle 경로와 구분한다. 결과·제약은 [[메모리-연구/neural-memory/neural-memory/STREAM_MEMORY_UPDATE_REPORT|갱신 진단 보고서]]에 기록한다.

후속 획득 대조의 `--freeze-reader`는 공유 Transformer의 Q/V 저차원 가중치를 고정하고 bridge/gate/query만 학습한다. 따라서 쓰기 Transformer까지 고정된 제한된 조건이지 별도 writer 본체를 학습하는 구조가 아니다. 체크포인트에는 고정 이전의 모든 adapter를 저장해 평가할 때 읽기 가중치가 빠지지 않게 한다. `--allow-initial-best`는 초기 체크포인트도 새 valid NLL로 선택 가능하게 한다. 결과는 [[메모리-연구/neural-memory/neural-memory/STREAM_MEMORY_ACQUISITION_REPORT|획득 보고서]]에 기록한다.

후속 [[메모리-연구/neural-memory/neural-memory/STREAM_MEMORY_TRANSFER_REPORT|어휘 전이·간섭 검사]]는 가중치 학습 없이 정답 어휘를 바꾸고 잡담의 후보 언급·다른 화자의 사실·본인의 정정을 검사한다. 새 단어는 메모리 학습 정답 어휘에서 제외된 값이며 LM 사전학습 미사용 값이라는 뜻은 아니다. 같은 가중치의 원문 직접 읽기 대조와 달리 기억 경로는 새 단어에서 실패했다. 따라서 이 8값 모델의 성공 범위는 알려진 소수 값으로 제한한다.

이후 같은 구조·손실·최대 스텝 예산에서 8값/256값 학습을 대조했다. [[메모리-연구/neural-memory/neural-memory/STREAM_MEMORY_OPEN_VOCAB_REPORT|값 다양성 보고서]]에서는 학습·검증과 별개인 64값의 전이가 두 seed에서 개선됐다. 이는 인공 단일 사실 과제의 전이이며 일반 저장 판단의 검증이 아니다. 정정은 여전히 실패하고 일부 조건에서 악화돼, 전체 목표의 완료로 판단하지 않는다.

후속 [[메모리-연구/neural-memory/neural-memory/STREAM_MEMORY_REVISION_REPORT|정정 학습]]은 같은 상태·구조·미래 내용 CE로 본인 값 변경과 다른 화자의 사실이 있는 대화를 추가 학습했다. 상황 이름이 입력에 들어간 예비 실행은 제외하고 무작위 헤더로 다시 학습했다. 미학습 64값 정정은 두 seed에서 78.13%/82.81%로 개선됐고 이전 clock 정정도 크게 개선됐다. 그러나 미학습 표현에는 옛값 오류가 남고, 반복 간섭에서 기존 성능이 악화돼 정정/간섭 전체가 해결된 것은 아니다. 명시적인 저장·정정 라벨이나 외부 기록은 추가하지 않았다.

후속 [[메모리-연구/neural-memory/neural-memory/STREAM_MEMORY_BALANCE_REPORT|정정·반복 간섭 균형 실험]]은 기존 정정 대화와 여덟 번 반복 간섭을 함께 학습하고, 11개 검증 조건의 유지 기준으로 가중치를 선택했다. 새로 남겨둔 64값에서 다른 화자의 후보 사실 여덟 번 정확도는 78.13%/78.91%로 개선됐지만, 정정 점수가 약 4~5%p 하락하고 미학습 정정 표현은 두 seed 모두 48.44%로 악화됐다. 검증 조건별 유지가 시험의 유지까지 보장하지 않았으므로 전체 균형 목표의 완료나 일반 사람 대화 메모리로 판단하지 않는다. 구조·18 KiB 상태·미래 내용 CE는 유지했다.

후속 [[메모리-연구/neural-memory/neural-memory/STREAM_MEMORY_RETENTION_REPORT|표현 다양화·출력 유지 제약 실험]]은 정정 표현 세 가지를 학습하고 기존 대화를 재학습하면서 시작 모델의 출력 분포를 유지하는 KL 제약을 대조했다. 17개 검증 조건의 하락을 허용하지 않는 기준에서는 두 KL seed와 CE 대조 모두 새 가중치를 채택하지 못했다. 마지막 600스텝 가중치의 별도 진단에서 학습 표현 `is now`의 새 값 전이는 1.56% → 70.31%/75.00%로 개선됐으나 다른 표현·갱신의 회귀가 남았다. 선택 가중치는 원래 시작점으로 유지했고, 이 진단을 가중치 재선택에 사용하지 않았다. 학습에만 고정 기준 모델을 추가했으며 추론의 구조·18 KiB 상태는 그대로다.

후속 [[메모리-연구/neural-memory/neural-memory/STREAM_MEMORY_REGRESSION_REPAIR_REPORT|성능저하 복구 실험]]은 원래 adapter를 비트 단위로 고정하고 새 Q/V rank와 입력 의존 gate, 기존 출력·과거 상태·결정 여유 증류를 추가했다. seed 7의 학습 후보는 17개 검증 정확도를 모두 유지했고 이전 수정 조건을 회복하면서 새 표현 전이도 개선했지만, 회귀 시험의 단순 보존은 79.69%에서 77.34%로 내려가고 다섯 조건의 하락이 남았다. 앞선 공유 gate 프로토콜의 seed 17도 검증 유지 기준을 통과하지 못했다. 따라서 원본을 대체하지 않았으며, 마지막 미평가 8값은 소비하지 않았다. 대화별 18 KiB 상태와 외부 기록 없는 구조는 유지하지만 일반적인 성능저하 해결의 완료로 판단하지 않는다.

후속 [[메모리-연구/neural-memory/neural-memory/STREAM_MEMORY_HUMAN_E2E_REPORT|실제 사람 대화 평가]]는 MSC `valid` 96개 대화의 과거 세션을 상태에 스트리밍하고 나중 발화를 예측했다. 원문 직접 읽기는 이득이 있었지만, 원래와 보호 후보의 순환 기억 경로는 자기 과거가 빈 과거보다 낫지 않았다. 자동 기억 텍스트/`NO_MEMORY` 반환은 아직 구현·평가되지 않았다.

후속 [[메모리-연구/neural-memory/neural-memory/STREAM_MEMORY_HUMAN_FROZEN_REPORT|사람 대화 기반 기억 전용 학습]]은 언어모델을 완전히 고정하고 실제 MSC 대화의 나중 발화 CE와 대화 짝짓기 대조 손실을 비교했다. 빈 상태보다 나은 예측은 학습했지만 타인 상태보다 유용한 개인별 기억은 입증하지 못했다. 두 후보 모두 채택하지 않았다.

후속 [[메모리-연구/neural-memory/neural-memory/STREAM_MEMORY_READ_ADAPTER_REPORT|토큰 조건부 읽기 실험]]은 기존 prefix 읽기 외에 이전 상태를 텍스트 hidden에서 직접 읽는 잔차 경로를 선택 옵션으로 추가했다. 빈 기억 대비 예측 이득은 커졌으나 타인 기억과의 차이는 여전히 작아 개인별 기억 게이트를 통과하지 못했다. 기본 구조와 기존 체크포인트는 바꾸지 않았다.

후속 [[메모리-연구/neural-memory/neural-memory/STREAM_MEMORY_STATE_DIAGNOSTIC_REPORT|상태 정보·읽기 분리 진단]]은 원문 직접 읽기와 순환 기억의 사례별 효과를 대조하고, 고정된 잠재 상태의 과거 단어 정보에 선형 판독기를 적용했다. 일부 정보는 학습 전에도 읽히지만 기존 학습으로 의미 있게 늘지는 않았다. 과거 구간 경계의 실제 다음 토큰을 추가로 학습하는 100스텝 파일럿도 개인별 기억 기준과 상태 판독을 개선하지 못했다. 보조 손실은 선택 옵션으로 남기고 기본값은 0이다.

## 검증

독립 대화별로 다음 구간 내용의 NLL을 비교한다. 첫 구간은 기억이 모두 비어 있어 주 비교에서 제외하고, 전체 내용 NLL도 안전 지표로 함께 기록한다.

1. 자기 상태: 실제 앞선 구간으로 갱신한 상태.
2. 빈 상태: 동일한 모델·현재 토큰에서 이전 상태만 초기화.
3. 교환 상태: 다른 대화의 앞선 구간에서 만든 상태만 주입.

평가의 교환·초기화는 학습 입력/라벨이 아니라 원인 분리를 위한 개입이다. 교환 예측에서 나온 기억을 자기 상태에 다시 쓰지 않는다. 데이터가 한 개 남는 평가 배치에도 실제 다른 대화를 기증자로 사용한다.

미사용 대화에서 자기 상태가 빈 상태와 교환 상태를 모두 이겨야 기억의 이득을 주장한다. 95% paired bootstrap은 대화 단위로 계산한다. 같은 기증자가 여러 비교에 쓰이는 의존성을 완전히 재표집하지는 않으므로 신뢰구간은 탐색적이며, MSC 기존 test도 이미 여러 번 확인한 자료다.

첫 판정의 최소 유용 효과는 기존 기준인 0.02 nats/content-token을 참고한다. 평균 양수만으로 통과하지 않는다. 짧은 연속 문맥 예측의 이득이 나와도 정확한 사실 회상·수정·필요 없는 반환 억제를 따로 검사해야 한다.

## 아직 남은 것

- 긴 세션·대화 전체의 학습과 더 긴 구간 간 역전파.
- 여러 사실과 사람 대화의 정정/간섭, 미학습 표현 및 강한 반복 간섭에서의 안정성, 메모리가 불필요한 시점의 검사.
- 보존된 기억을 근거에 충실한 텍스트로 반환하는 출력 인터페이스.
- 자동 반환 타이밍과 `NO_MEMORY`의 학습 가능성/식별성 검증.
- 동등한 예산의 TTT 방식 비교 및 원 논문에 더 충실한 기준 모델.
