# 신경망 기억의 정정 학습 — 2026-09-27

후속 [[메모리-연구/neural-memory/neural-memory/STREAM_MEMORY_BALANCE_REPORT|정정·간섭 균형 실험]]에서는 새로 남겨둔 64값으로 반복 간섭의 개선을 확인했지만 정정/미학습 표현의 회귀가 남았다. 아래는 그 이전 정정 학습 결과이며, 후속 결과로 소급 변경하지 않았다.

## 결론

**옛값을 계속 출력하는 정정 실패는 크게 줄였지만, 정정과 간섭 문제를 전반적으로 해결하지는 못했다.** 구조와 기억 크기를 바꾸지 않고 값이 변경되는 대화를 미래 내용 예측으로 추가 학습한 결과다. 정보를 저장할 위치를 지정하거나 clock만 예외 처리하는 규칙은 넣지 않았다.

학습/검증 정답으로 사용하지 않은 64개 값·128사례의 정정 정확도는 seed 7에서 **3.13% → 82.81%**, seed 17에서 **4.69% → 78.13%**였다. 같은 시작점·최대 추가 스텝 예산의 단일 사실 학습 대조(seed 17)는 32.81%였다. 이전 clock 정정 실패 원문에서도 미학습 8값 정확도가 **7.81% → 76.56%, 3.13% → 93.75%**로 개선됐고, 그 정정 검사에서 옛 clock 출력은 두 모델 모두 없어졌다.

학습에 없던 표현에서는 옛값을 답하는 오류가 일부 남았다. 또 **다른 화자의 사실이 많이 반복되는 기존 시험에서는 일부 성능이 크게 떨어졌다.** 따라서 이 가중치는 정정 능력을 개선한 실험 모델로 보존하며, 실제 사람 대화용 기억이 완성됐다고 보지는 않는다.

## 바꾼 것과 유지한 것

시작 가중치는 이전 [[메모리-연구/neural-memory/neural-memory/STREAM_MEMORY_OPEN_VOCAB_REPORT|값 다양성 실험]]에서 선택한 `stream-rmt-open-vocab-diverse-seed{7,17}.pt`다. RMT형 구조와 8×576 잠재 상태(18 KiB)는 그대로 유지했다. Q/V 저차원 갱신·bridge·gate·write query의 **568,513개 파라미터**를 학습한다. 각 독립 대화의 기억은 0에서 시작하며 구간 사이 원문 검색이나 Transformer KV 캐시는 추가하지 않았다.

학습에는 이전과 같이 MSC 학습 분할의 단어 빈도로 만든 256값을 썼다. 실제로 모델에 제공한 문장은 여전히 인공 대화다. 여섯 종류의 상황을 섞었다. 단일 사실, 본인 정정, 정정 표현 없는 본인 값 변경, 본인 두 번 정정, 다른 화자의 세 사실, 본인 정정 뒤 다른 화자의 세 사실이다. 각 값은 모든 상황과 4·8턴 잡담 조건을 경험한다.

옛값과 다른 화자의 값도 학습 분할에서 고르되 해당 8개 정답 그룹과 겹치지 않게 했다. **clock, 이전 미학습 8값, 검증/시험의 답 값은 추가 학습의 사실 값으로 쓰지 않았다.**

자료는 384개 반사실 그룹/3,072대화로 구성했다. 같은 그룹에서는 마지막 본인 사실과 마지막 답만 달라지고, 옛값·잡담·다른 사람의 사실·현재 질문은 모두 답과 독립이다.

마지막 사실을 현재 원문 창에서 직접 읽을 수 없도록 잡담 세 턴을 덧붙였다. 사실 위치 표시는 입력이 조건을 지키는지 확인하거나 시험할 때만 쓰며, 학습 손실에는 사용하지 않는다.

손실은 기존 `control_loss(..., future_only=True, oracle_prefix=False)`를 사용한다. **마지막 미래 구간에 포함된 모든 대화 내용의 다음 토큰 교차엔트로피(CE)**를 계산한다.

저장·정정·중요도를 알려 주는 라벨이나 과거 근거를 직접 전달하는 특권 경로, 도구 문법, 코드로 정해 둔 덮어쓰기 규칙은 넣지 않았다. 누구의 말인지도 모델이 텍스트에서 배운다. 파이썬 코드가 화자별로 기억을 나눠 주는 방식이 아니다.

Apple MPS/float32에서 배치 크기 2, 학습률 0.0003, 기울기 노름 상한 1로 최대 1,000스텝 추가 학습했다. 100스텝마다 별도 32값·192사례에서 여섯 상황의 평균 답 NLL을 확인했다. 초기 가중치도 선택 후보에 넣었으며, **검증만으로 선택을 끝낸 다음** 시험 자료를 구성하고 평가했다.

선택 스텝은 seed 7: 900, seed 17: 700, 단일 사실 대조: 1,000이었다. 모든 실행에서 선택 가중치와 마지막 가중치를 따로 보존했다.

정정 대화를 학습한 효과를 비교하려고 seed 17의 시작 가중치와 학습 답 어휘를 맞춘 단일 사실 대조를 두었다. 대화 수 3,072, 최대 스텝, 배치 크기/학습률, 선택 규칙은 같았다.

다만 문장 길이와 손실 토큰 수까지 맞춘 대조는 아니다. 실제 미래 내용 손실에 사용한 토큰 수는 정정 seed 7/17이 17,507/17,368, 대조가 20,169였다. 따라서 최대 갱신 예산은 같지만 전체 토큰 예산까지 같다고 주장하지 않는다.

## 입력 감사 중 발견한 힌트와 재실험

입력 감사에서 첫 세 실행의 헤더에 `Earlier conversation train-correction-...`처럼 상황 이름이 들어간 문제를 발견했다. 이를 모델이 힌트로 사용할 수 있으므로 해당 실행은 **예비 결과로만 보존하고 주 결과에서 제외**했다.

상황 이름은 감사용 ID에만 남기고, 실제 입력 헤더는 답이나 상황과 독립인 무작위 숫자로 바꿨다. 이후 두 정정 모델과 단일 사실 대조를 각각 원래 시작점에서 다시 학습했다. 아래 결과는 모두 `*-clean-*` 재실험이며 예비 가중치를 이어 학습한 결과가 아니다.

학습·검증·주 시험·기존 새값 기억 시험의 입력을 다시 만들어 저장된 SHA-256과 정확히 일치하는지 확인했다. 실제 행 수·조건·예산은 `stream-rmt-revision-clean-comparison.json`의 `training_audits`를 근거로 한다.

시작 설정을 상속한 부가 `train_blocks/valid_blocks` 필드에는 옛 값이 남을 수 있어 근거로 쓰지 않는다. 실제 계산에는 영향이 없었고 원본 산출물은 소급 수정하지 않았다. 이후 실행기에서는 저장할 때 실제 구간 수로 이 필드를 덮어쓰도록 수정했다.

## 주 시험: 미학습 답 값의 갱신

각 조건은 동일한 64개 값에 두 잡담 배치를 적용한 128사례다. 주 지표는 **LM 전체 어휘에서 가장 높은 확률의 단일 토큰을 고른 정확도**다. 괄호의 8지선다 점수를 전체 어휘 출력의 성공으로 대신 해석하지 않는다.

| 조건 | seed 7 시작 → 정정 학습 | seed 17 시작 → 정정 학습 | 단일 사실 대조, seed 17 |
| --- | ---: | ---: | ---: |
| 단일 사실 | 59.38% → 75.78% | 60.16% → 69.53% | 62.50% |
| 본인 정정 | 3.13% → 82.81% (106/128) | 4.69% → 78.13% (100/128) | 32.81% |
| 정정 표현 없는 값 변경 | 1.56% → 77.34% | 3.13% → 82.03% | 27.34% |
| 본인 두 번 정정 | 4.69% → 84.38% | 4.69% → 81.25% | 33.59% |
| 다른 화자의 세 사실 | 25.00% → 73.44% | 36.72% → 62.50% | 22.66% |
| 본인 정정 뒤 다른 화자의 세 사실 | 0% → 75.00% | 0.78% → 77.34% | 7.81% |
| 기존 새값 단일 사실 원문 유지 검사 | 54.69% → 79.69% | 50.00% → 68.75% | 50.78% |

본인 정정의 8지선다는 두 모델 모두 100%였지만, 전체 어휘에서 고른 답은 위 표처럼 아직 불완전했다. 또 두 정정 모델은 **모든 주 시험 조건에서 기억을 비우거나 교환하면 전체 어휘 정확도가 0%**였다. 따라서 현재 원문 창이나 질문만으로 답을 맞힌 결과는 아니다.

같은 8개 답 그룹을 공유하는 두 잡담 배치를 묶어 bootstrap했다. 본인 정정의 시작 대비 개선 95% 탐색적 구간은 seed 7: +75.78~+82.81%p, seed 17: +63.28~+82.81%p다. seed 17의 단일 사실 대조 대비 정정 학습 개선은 +45.31%p, 구간 +29.69~+58.59%p다. 128행을 독립 표본으로 취급하지 않았다. 작은 인공 표본이며 다중 비교 보정은 하지 않았다.

## 별도 표현·옛값·긴 거리 시험

학습과 선택을 마친 가중치를 고정해 새 잡담 seed 8019로 검사했다. 각 조건은 128사례이며, 같은 입력을 시작 가중치와 선택 가중치에 넣었다.

| 조건 | seed 7 시작 → 정정 학습 | seed 17 시작 → 정정 학습 | 단일 사실 대조, seed 17 |
| --- | ---: | ---: | ---: |
| 미학습 표현 `I changed my secret word to ...` | 0% → 51.56% | 1.56% → 61.72% | 5.47% |
| 미학습 표현 뒤 다른 화자의 사실 | 0% → 46.09% | 0% → 60.16% | 0% |
| 옛값도 추가 학습에 미사용인 정정 | 4.69% → 82.03% | 2.34% → 77.34% | 29.69% |
| 옛값 clock, 새 64값 정정 | 2.34% → 82.81% | 0% → 82.81% | 42.97% |
| 32·64턴 잡담 조건의 정정 | 3.91% → 78.13% | 1.56% → 76.56% | 24.22% |
| 본인 사실 뒤 Friend의 `Actually` 정정 세 번 | 58.59% → 65.63% | 39.84% → 57.03% | 33.59% |

clock을 옛값으로 쓴 조건에서 옛 clock 오류는 seed 7이 **101/128 → 0/128**, seed 17이 **126/128 → 0/128**로 줄었다. 옛값 자체도 미학습인 조건에서는 옛값 오류가 65/88건에서 모두 0건으로 줄었다. 긴 잡담 조건에는 seed 7의 옛값 오류 1건, seed 17의 0건이 남았다.

여기서 32·64는 사실 앞뒤에 나눠 넣은 잡담의 총 턴 수다. 정정 뒤의 거리를 그만큼으로 고정한 것은 아니다. 짧은 조건과 긴 조건은 뽑힌 잡담과 구간 경계도 다르므로 길이 증가를 개선 원인이라고 주장하지 않는다.

미학습 표현에서는 옛값 오류가 seed 7: 31/128, seed 17: 14/128 남았다. 특정 정정 문장 틀에서 좋아진 결과를 일반 언어의 정정 능력 완성으로 해석할 수 없는 이유다.

Friend 정정 조건에서도 다른 사람의 clock을 따라가는 오류가 17/29건 남아, 시작 모델의 1/22건보다 늘었다. 평균 정확도가 올랐어도 이 실패 유형까지 사라진 것은 아니다.

두 정정 모델은 이 별도 시험의 모든 조건에서도 빈/교환 상태의 전체 어휘 정확도가 0%였다. 평가 전후 adapter 동일성을 검사했고, 비교 입력 digest도 일치했다.

## 이전 clock 실패 원문 재검사와 회귀

이전 seed 4009의 동일한 원문·후보·구간 위치를 그대로 사용했다. 각 칸은 64사례이며 **정정 전 모델 → 이번 모델**의 전체 어휘 정확도다.

| 어휘·조건 | seed 7 | seed 17 |
| --- | ---: | ---: |
| 원래 8값, 본인 정정 | 62.50% → 100% | 23.44% → 100% |
| 이전 미학습 8값, 본인 정정 | 7.81% → 76.56% | 3.13% → 93.75% |
| 원래 8값, 중립 | 100% → 92.19% | 100% → 87.50% |
| 이전 미학습 8값, 중립 | 62.50% → 70.31% | 78.13% → 85.94% |
| 원래 8값, 후보 단어 언급 잡담 | 96.88% → 71.88% | 96.88% → 62.50% |
| 이전 미학습 8값, 후보 단어 언급 잡담 | 59.38% → 60.94% | 70.31% → 48.44% |
| 원래 8값, Friend의 후보 사실 여덟 번 | 82.81% → 50.00% | 95.31% → 34.38% |
| 이전 미학습 8값, Friend의 후보 사실 여덟 번 | 45.31% → 31.25% | 60.94% → 34.38% |

이전 미학습 8값의 정정에서 clock 출력은 기존 seed 7/17의 54/62건에서 모두 0건으로 줄었다. 예를 들어 clock 뒤 cat으로 정정한 답은 두 모델 모두 8/8번 cat이었다. 남은 오답은 sun에 sunny, ocean에 summer처럼 다른 단어를 출력하는 경우도 있으며 후보 제한 평가만으로 성공을 판정하지 않았다.

반대로 seed 17의 Friend clock 반복 조건에서는 48/64번 다른 화자의 clock을 출력했다. 학습에서 다른 사람의 사실 세 번을 구분한 능력이 여덟 번 반복되는 조건까지 안정적으로 이어지지는 않았다. **기존 간섭 내성이 나빠지는 회귀가 확인됐으므로 이번 모델을 모든 조건에서 더 나은 모델로 선언하지 않는다.**

## 원인에 대한 판단과 검증 범위

현재 구조에서도 다양한 옛값을 새값으로 갱신하는 동작은 학습할 수 있었다. 따라서 이 구조는 원천적으로 정정을 할 수 없다는 해석은 실험과 맞지 않는다. 오히려 단일 사실만 반복 학습할 때의 보존 편향과 정정·화자 경쟁을 경험하는 학습 분포가 중요하다는 해석을 지지한다.

다만 게이트 하나의 효과를 분리해 검증한 실험은 아니다. Q/V의 읽기·쓰기 공유 가중치도 함께 학습했으므로 개선을 쓰기 경로만의 효과라고 주장하지 않는다.

주 시험 값은 이번 추가 학습의 답이나 옛값, 검증 답으로 쓰지 않았다. 그러나 이전 연구에서 이미 검사한 64값이며 LM 사전학습에서 보지 못한 값이라는 뜻도 아니다. 미학습 표현 역시 이번 정정 학습의 문장 틀에 없었다는 의미다.

실제 사람 대화 전체, 여러 속성이나 사실, 무엇을 저장할지 자동으로 판단하는 능력, 기억 텍스트 반환과 `NO_MEMORY`/반환 시점은 여전히 검증하지 않았다.

신규 검사 31개를 포함해 전체 **573개가 통과했고**, 기존 requires-grad scalar 경고 1개가 남았다. 반사실 균형과 상황 이름 누출 방지, 위치 표시와 손실의 독립성, gate/bridge/query까지의 기울기 전달, 미래 답의 입력 누출 방지, 입력의 정확한 재생성을 검사했다. 예산이나 시작 모델이 다르면 비교를 거부하는지와 읽기 전용 평가에서 어댑터가 바뀌지 않는지도 확인했다.

codecanvas에 실험 함수가 색인되지 않아 정적 호출 그래프 증거는 얻지 못했다. 대신 실제 CPU/GPU 실행과 회귀 검사로 검증했다.

## 보존한 결과

선택 가중치는 `local-data/stream-rmt-revision-clean-seed7.pt`, `local-data/stream-rmt-revision-clean-seed17.pt`다. 같은 이름의 JSON에 전체 학습·검증·시험 기록이 있으며 `-last.pt`에 1,000스텝 마지막 가중치를 별도 보존했다. 단일 사실 대조는 `stream-rmt-revision-clean-neutral-seed17.*`다.

별도 시험은 `stream-rmt-revision-holdout-clean-*.json`, 이전 원문 재검사는 `stream-rmt-revision-transfer-clean-seed{7,17}.json`, 입력 감사와 그룹별 비교는 `stream-rmt-revision-clean-comparison.json`이다. 헤더 힌트가 있던 세 예비 실행 `stream-rmt-revision-seed{7,17}.*` 및 `stream-rmt-revision-neutral-seed17.*`도 삭제하지 않았다. 이전 가중치/사용자 수정 파일은 보존했다.

실행기는 기존 출력 파일의 덮어쓰기를 거부한다. `neural-memory/`에서 새 출력 이름을 사용해 재현할 수 있다.

```sh
HF_HUB_OFFLINE=1 TRANSFORMERS_OFFLINE=1 .venv/bin/python run_stream_memory_revision.py --manifest local-data/stream-rmt-open-vocab-manifest.json --warm-start local-data/stream-rmt-open-vocab-diverse-seed17.pt --seed 17 --steps 1000 --mode revision --output local-data/revision-reproduction-seed17.json
HF_HUB_OFFLINE=1 TRANSFORMERS_OFFLINE=1 .venv/bin/python eval_stream_memory_revision.py --checkpoint local-data/stream-rmt-revision-clean-seed17.pt --reference local-data/stream-rmt-open-vocab-diverse-seed17.pt --manifest local-data/stream-rmt-open-vocab-manifest.json --output local-data/revision-reproduction-eval-seed17.json
```
