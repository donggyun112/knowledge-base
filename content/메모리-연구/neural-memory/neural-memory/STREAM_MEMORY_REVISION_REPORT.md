# 신경망 기억의 정정 학습 — 2026-09-27

후속 [[메모리-연구/neural-memory/neural-memory/STREAM_MEMORY_BALANCE_REPORT|정정·간섭 균형 실험]]에서는 새로 남겨둔 64값으로 반복 간섭의 개선을 확인했지만 정정/미학습 표현의 회귀가 남았다. 아래는 그 이전 정정 학습 결과이며, 후속 결과로 소급 변경하지 않았다.

## 결론

**옛값을 고집하는 정정 실패는 크게 줄였다. 하지만 일반적인 정정·간섭 문제를 모두 해결한 것은 아니다.** 모델 구조와 기억 크기는 유지하고, 값이 바뀌는 대화를 미래 내용 예측으로 추가 학습했다. 저장 위치를 지정하거나 clock을 예외 처리하는 규칙은 넣지 않았다.

학습/검증 정답으로 사용하지 않은 64개 값·128사례의 정정 정확도는 seed 7에서 **3.13% → 82.81%**, seed 17에서 **4.69% → 78.13%**였다. 같은 시작점·최대 추가 스텝 예산의 단일 사실 학습 대조(seed 17)는 32.81%였다. 이전 clock 정정 실패 원문에서도 미학습 8값 정확도가 **7.81% → 76.56%, 3.13% → 93.75%**로 개선됐고, 그 정정 검사에서 옛 clock 출력은 두 모델 모두 없어졌다.

반면 미학습 표현에서는 옛값 오류가 일부 남았으며, **다른 화자의 사실이 많이 반복되는 기존 시험은 일부 크게 악화됐다.** 따라서 아래 가중치는 개선된 실험 모델이지 완성된 사람 대화 메모리가 아니다.

## 바꾼 것과 유지한 것

시작점은 이전 [[메모리-연구/neural-memory/neural-memory/STREAM_MEMORY_OPEN_VOCAB_REPORT|값 다양성 실험]]의 선택 가중치 `stream-rmt-open-vocab-diverse-seed{7,17}.pt`다. 같은 RMT형 구조, 8×576 잠재 상태(18 KiB), Q/V 저차원 갱신·bridge·gate·write query의 **568,513개 학습 파라미터**를 유지했다. 독립 대화의 기억은 0에서 출발하며, 구간 사이 원문 검색이나 Transformer KV cache를 추가하지 않았다.

학습 데이터는 기존 MSC train 단어 빈도로 만든 동일한 256값을 사용했다. 실제 학습 대화는 여전히 인공 대화다. 다음 여섯 종류를 섞었다: 단일 사실, 본인 정정, 정정 표현 없는 본인 값 변경, 본인 두 번 정정, 다른 화자의 세 사실, 본인 정정 뒤 다른 화자의 세 사실. 각 값은 모든 종류와 4·8턴 잡담 조건을 경험한다. 이전 값과 다른 화자의 값도 학습 split에서 골랐으며, 해당 8개 정답 그룹과 겹치지 않는다. **clock, 이전 미학습 8값, 검증/시험 답 값은 추가 학습의 사실 값으로 사용하지 않았다.**

384개 반사실 그룹/3,072대화에서 같은 그룹 안에는 마지막 본인 사실과 마지막 답만 달라진다. 옛값·잡담·다른 사람의 사실·현재 질문은 모두 답과 독립이다. 마지막 사실도 현재 원문 창 밖에 있도록 잡담 세 턴을 추가했다. 사실 위치 표시는 입력 감사와 시험에만 쓰고, 학습 손실에는 쓰지 않는다.

손실은 기존 `control_loss(..., future_only=True, oracle_prefix=False)`의 **마지막 미래 구간에 포함된 모든 대화 내용 next-token CE**다. 저장/정정/중요도 라벨, privileged source routing, tool 문법, hard-coded overwrite 규칙은 사용하지 않았다. 화자 구분도 모델이 텍스트에서 학습하며 파이썬 코드가 기억을 화자별로 나눠 주지 않는다.

Apple MPS/float32, batch 2, lr 0.0003, gradient norm 1 clipping, 최대 추가 1,000스텝으로 학습했다. 100스텝마다 별도 32값·192사례의 여섯 종류 평균 답 NLL을 확인했다. 초기 가중치도 선택 가능하며, **검증만으로 선택을 마친 후** 시험을 구성·평가했다. 선택 스텝은 seed 7: 900, seed 17: 700, 단일 사실 대조: 1,000이다. 모두 선택 가중치와 마지막 가중치를 별도로 보존했다.

대조는 같은 seed 17 시작 가중치, 학습 답 어휘, 3,072대화 수, 최대 스텝, batch/lr 및 선택 규칙을 사용했다. 그러나 문장 길이와 손실 토큰 수까지 같지는 않다. 실제 미래 내용 손실 토큰 수는 정정 seed 7/17: 17,507/17,368, 대조: 20,169다. 동등한 최대 갱신 예산 대조이지 동등한 전체 토큰 예산 대조라고 주장하지 않는다.

## 입력 감사 중 발견한 힌트와 재실험

첫 세 실행에는 상황 이름이 `Earlier conversation train-correction-...`처럼 입력 헤더에도 들어가는 문제가 있었다. 이 실행은 **예비 결과로 보존하고 주 결과에서 제외**했다. 상황 이름은 감사용 ID에만 두고 모델 입력 헤더는 답/상황과 독립인 무작위 숫자로 바꿨다. 수정 뒤 두 정정 모델과 단일 사실 대조를 각각 같은 원래 시작점부터 다시 학습했다. 아래 결과는 모두 `*-clean-*` 재실험이다. 예비 가중치에서 이어 학습하지 않았다.

학습·검증·주 시험·기존 새값 기억 시험 입력을 정확히 재생성해 저장된 SHA-256과 일치하는지 확인했다. `stream-rmt-revision-clean-comparison.json`의 `training_audits`가 실제 행 수·조건·예산의 근거다. 실행 시작 시 상속된 config의 부가 `train_blocks/valid_blocks` 필드는 옛 값일 수 있으므로 사용하지 않는다. 실제 계산에는 영향을 주지 않았고 원본 artifact는 소급 수정하지 않았다. 실행기의 이후 저장에서는 실제 구간 수로 덮어쓰도록 수정했다.

## 주 시험: 미학습 답 값의 갱신

각 조건은 동일한 64개 값 × 두 잡담 배치 = 128사례다. 주 지표는 **LM 전체 어휘의 단일 토큰 argmax 정확도**다. 괄호의 8지선다를 전체 어휘 성공으로 대신 쓰지 않는다.

| 조건 | seed 7 시작 → 정정 학습 | seed 17 시작 → 정정 학습 | 단일 사실 대조, seed 17 |
| --- | ---: | ---: | ---: |
| 단일 사실 | 59.38% → 75.78% | 60.16% → 69.53% | 62.50% |
| 본인 정정 | 3.13% → 82.81% (106/128) | 4.69% → 78.13% (100/128) | 32.81% |
| 정정 표현 없는 값 변경 | 1.56% → 77.34% | 3.13% → 82.03% | 27.34% |
| 본인 두 번 정정 | 4.69% → 84.38% | 4.69% → 81.25% | 33.59% |
| 다른 화자의 세 사실 | 25.00% → 73.44% | 36.72% → 62.50% | 22.66% |
| 본인 정정 뒤 다른 화자의 세 사실 | 0% → 75.00% | 0.78% → 77.34% | 7.81% |
| 기존 새값 단일 사실 원문 유지 검사 | 54.69% → 79.69% | 50.00% → 68.75% | 50.78% |

본인 정정의 8지선다는 두 정정 모델 모두 100%였다. 그러나 전체 어휘 답은 위와 같이 불완전하다. 두 정정 모델의 **모든 주 시험 조건에서 빈 상태·교환 상태의 전체 어휘 정확도는 0%**였다. 현재 원문 창이나 질문만으로 답한 결과가 아니다.

같은 8개 답 그룹을 공유하는 두 잡담 배치를 묶어 bootstrap했다. 본인 정정의 시작 대비 개선 95% 탐색적 구간은 seed 7: +75.78~+82.81%p, seed 17: +63.28~+82.81%p다. seed 17의 단일 사실 대조 대비 정정 학습 개선은 +45.31%p, 구간 +29.69~+58.59%p다. 128행을 독립 표본으로 취급하지 않았다. 작은 인공 표본이며 다중 비교 보정은 하지 않았다.

## 별도 표현·옛값·긴 거리 시험

학습과 선택을 마친 가중치를 고정해 새 잡담 seed 8019로 검사했다. 각 조건은 128사례이며, 같은 입력을 시작 가중치와 선택 가중치에 넣었다.

| 조건 | seed 7 시작 → 정정 학습 | seed 17 시작 → 정정 학습 | 단일 사실 대조, seed 17 |
| --- | ---: | ---: | ---: |
| 미학습 표현 `I changed my secret word to ...` | 0% → 51.56% | 1.56% → 61.72% | 5.47% |
| 미학습 표현 뒤 다른 화자의 사실 | 0% → 46.09% | 0% → 60.16% | 0% |
| 옛값도 추가 학습에 미사용인 정정 | 4.69% → 82.03% | 2.34% → 77.34% | 29.69% |
| 옛값 clock, 새 64값 정정 | 2.34% → 82.81% | 0% → 82.81% | 42.97% |
| 32·64턴 잡담 조건의 정정 | 3.91% → 78.13% | 1.56% → 76.56% | 24.22% |
| 본인 사실 뒤 Friend의 `Actually` 정정 세 번 | 58.59% → 65.63% | 39.84% → 57.03% | 33.59% |

clock 조건에서 옛 clock 오류는 seed 7: **101/128 → 0/128**, seed 17: **126/128 → 0/128**이다. 옛값도 미학습인 조건의 옛값 오류 역시 65/88건에서 모두 0건으로 줄었다. 긴 잡담 조건에서는 seed 7에 옛값 오류 1건, seed 17에는 0건이 남았다. 32·64는 사실 앞뒤에 분산한 총 잡담 턴 수이며 정정 뒤의 거리로 고정한 수가 아니다. 짧음/길음은 잡담 draw와 구간 경계도 달라 길이 증가가 개선 원인이라고 주장하지 않는다.

하지만 미학습 표현에는 옛값 오류가 seed 7: 31/128, seed 17: 14/128 남았다. 따라서 특정 정정 템플릿의 갱신 개선을 일반 언어의 정정 완성으로 해석하지 않는다. Friend 정정 조건에서는 다른 사람의 clock을 따라가는 오류도 17/29건 남았고, 시작 모델의 1/22건보다 증가했다. 평균 정확도가 개선돼도 이 실패 유형이 사라진 것은 아니다.

두 정정 모델은 이 별도 시험의 모든 조건에서도 빈/교환 상태의 전체 어휘 정확도가 0%였다. 평가 전후 adapter 동일성을 검사했고, 비교 입력 digest도 일치했다.

## 이전 clock 실패 원문 재검사와 회귀

이전 seed 4009의 동일한 원문·후보·구간 위치를 그대로 사용했다. 각 칸은 64사례이며 **정정 전 모델 → 이번 모델**의 전체 어휘 정확도다.

| 어휘·조건 | seed 7 | seed 17 |
| --- | ---: | ---: |
| 원래 8값, 본인 정정 | 62.50% → 100% | 23.44% → 100% |
| 이전 미학습 8값, 본인 정정 | 7.81% → 76.56% | 3.13% → 93.75% |
| 원래 8값, 중립 | 100% → 92.19% | 100% → 87.50% |
| 이전 미학습 8값, 중립 | 62.50% → 70.31% | 78.13% → 85.94% |
| 원래 8값, 후보 단어 언급 잡담 | 96.88% → 71.88% | 96.88% → 62.50% |
| 이전 미학습 8값, 후보 단어 언급 잡담 | 59.38% → 60.94% | 70.31% → 48.44% |
| 원래 8값, Friend의 후보 사실 여덟 번 | 82.81% → 50.00% | 95.31% → 34.38% |
| 이전 미학습 8값, Friend의 후보 사실 여덟 번 | 45.31% → 31.25% | 60.94% → 34.38% |

이전 미학습 8값의 정정에서 clock 출력은 기존 seed 7/17의 54/62건에서 모두 0건으로 줄었다. 예를 들어 clock 뒤 cat으로 정정한 답은 두 모델 모두 8/8번 cat이었다. 남은 오답은 sun에 sunny, ocean에 summer처럼 다른 단어를 출력하는 경우도 있으며 후보 제한 평가만으로 성공을 판정하지 않았다.

반면 seed 17의 Friend clock 반복 조건에서는 48/64번 다른 화자의 clock을 출력했다. 정정 학습에 포함된 다른 사람의 사실 세 번을 구별하는 능력이 여덟 번 반복 조건까지 안정적으로 일반화되지 않았다. 위 표처럼 **기존 간섭 내성의 회귀가 확인됐으므로 이번 모델을 모든 조건에서 더 좋은 모델로 선언하지 않는다.**

## 원인에 대한 판단과 검증 범위

이 구조로도 다양한 옛값을 새값으로 갱신하는 동작은 학습됐다. 따라서 현재 구조가 원천적으로 정정을 할 수 없다는 주장은 실험과 맞지 않는다. 단일 사실 반복만으로 학습할 때의 보존 편향과, 정정·화자 경쟁을 경험하는 학습 분포가 중요한 원인이라는 해석을 지지한다. 그러나 gate 한 개가 원인이라고 분리 검증한 것은 아니며, Q/V 읽기·쓰기 공유 가중치도 함께 학습했으므로 writer만의 효과라고 주장하지 않는다.

주 시험 값은 이번 추가 학습의 답/옛값과 검증 답으로 사용하지 않았다. 그러나 이전 연구에서 이미 검사한 64값이고 LM 사전학습 미사용 값도 아니다. 미학습 표현 역시 이번 정정 학습 템플릿에 없다는 의미다. 실제 사람 대화 전체, 여러 속성/사실, 자동 저장 중요도 판단, 기억 텍스트 반환과 `NO_MEMORY`/반환 타이밍은 여전히 검증되지 않았다.

신규 검사 31개를 포함해 전체 **573 passed**, 기존 requires-grad scalar 경고 1개다. 반사실 균형, 상황 이름 누출 방지, annotation 독립 손실, gate/bridge/query gradient, 미래 답 입력 누출 방지, 정확한 입력 재생성, 예산/시작 모델 불일치 거부, read-only adapter 동일성을 검사했다. codecanvas에서 실험 함수가 색인되지 않아 정적 호출 그래프 증거는 얻지 못했고 실제 CPU/GPU 실행과 회귀 검사로 확인했다.

## 보존한 결과
