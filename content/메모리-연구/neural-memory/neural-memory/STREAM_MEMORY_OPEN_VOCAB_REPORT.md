# 값 다양성 대조와 미학습 값 전이 — 2026-09-27

## 확인된 결과

**구조는 그대로 두고 학습할 정답 값만 다양화하자, 학습에 없던 값을 기억하는 성능이 두 seed에서 개선됐다.** 별도의 64개 시험 값/128사례에서 전체 어휘 정확도는 seed 7이 0% → 54.69%, seed 17이 0% → 50.00%였다. 최대 추가 학습 예산을 맞춘 8값 대조는 모두 0%에 머물렀다. 따라서 이번 차이를 단순히 오래 학습한 효과만으로 설명하기는 어렵다.

새 잡담과 32·64턴 조건에서도 미학습 값으로의 전이가 유지됐다. 다만 **정정 문제는 남았고 일부 조건에서는 오히려 악화됐다.** 값이 바뀌었는데도 옛값 clock을 계속 출력했다.

이 결과로 확인한 것은 학습 어휘 밖의 단일 사실을 전달하는 능력의 개선이다. 필요한 정보만 갱신하는 능력, 실제 사람 대화로의 일반화, 기억을 텍스트로 반환하거나 침묵할 시점까지 해결한 것은 아니다.

후속 [[메모리-연구/neural-memory/neural-memory/STREAM_MEMORY_REVISION_REPORT|정정 학습 보고서]]에서는 같은 구조로 변경 대화를 학습해 이 clock 정정 실패를 크게 줄였다. 이 문서의 이전 결과는 보존하며, 후속 실험에서도 반복 간섭의 회귀와 미학습 표현의 남은 실패를 별도로 기록한다.

## 실제 수행한 대조

두 조건은 같은 seed의 기존 `stream-rmt-control-acquire-joint-seed{7,17}.pt`에서 출발했다. 모두 Apple MPS/float32에서 실행하며 기존 8슬롯·576차원 상태와 게이트/쓰기 질의 구조를 유지했다. Q/V 저차원 갱신과 bridge/gate/query를 합친 학습 파라미터는 총 568,513개다. 각 대화의 기억은 여전히 0에서 시작하고 상태 크기도 18 KiB로 같았다.

학습 값은 **공개 MSC 학습 분할의 사람 대화 4,000개에서 단어 빈도만 추출**해 정했다. 단일 토큰 후보 12,787개 가운데 빈도가 높은 512개를 대상으로 고정 seed 9013을 사용해 선택·분리했다.

사람 대화에서 가져온 것은 단어 목록의 근거뿐이다. 모델이 실제로 학습한 문장은 여전히 비밀 단어를 말하는 인공 대화이므로, 사람 대화 전체로 기억을 학습한 실험이라고 부르지 않는다.

| 답 값 집합 | 수 | 사용 |
| --- | ---: | --- |
| 학습 | 256 | 원래 8값 포함, 나머지 값 추가 |
| 검증 | 32 | 학습 값과 별개, checkpoint 선택만 사용 |
| 새 시험 | 64 | 학습·검증 값과 별개, 학습 완료 후 평가 |
| 이전 실패 검사 | 8 | cat/sun/paper/bird/ocean/table/blue/cloud, 이번 학습·검증에도 제외 |

학습·검증·시험 등 각 분할의 답 문자열과 실제 토큰 ID는 서로 겹치지 않는다. 새 값은 정해진 잡담과 질문에 쓰이는 단어에서도 제외했다. 여기서 미학습이란 **메모리 학습의 답 값으로 사용하지 않았다**는 뜻이다. LM의 사전학습에서도 보지 못한 단어라는 의미는 아니다.

값 다양성 이외의 차이를 줄이기 위해 목록 크기와 입력 배치를 맞췄다. 다양화 조건은 256개 값을 사용하고, 8값 대조는 원래 8개를 32번 반복했다. 두 조건 모두 96블록/768대화이며, 전체 값 목록을 한 차례씩 도는 주기마다 잡담 2·4·8턴을 적용했다.

근거와 답 토큰만 가린 학습 입력의 SHA-256은 네 실행에서 모두 같았다. 같은 seed에서는 같은 행을 같은 순서로 뽑았고 내용 손실에 쓰인 토큰 수도 같았다(seed 7: 10,477, seed 17: 10,635).

최대 추가 학습은 600스텝이며, 배치 크기 2, 학습률 0.0003, 기울기 노름 상한 1을 사용하고 50스텝마다 검증했다. 손실은 기존과 같은 **마지막 미래 구간의 모든 대화 내용에 대한 다음 토큰 교차엔트로피(CE)**다.

저장 중요도·저장 여부·과거 사실의 전달 위치·도구 문법을 알려 주는 라벨은 쓰지 않았다. 사실과 답의 위치 표시를 바꿔도 손실이 같은지, 쓰기 파라미터까지 기울기가 생기는지도 검사했다.

최선 가중치는 별도의 32값 검증 NLL로 골랐으며 초기 체크포인트도 후보에 포함했다. 선택 스텝은 8값 seed 7/17에서 50/150, 다양한 값 seed 7/17에서 550/500이었다.

따라서 이 비교는 **최대 예산과 선택 규칙을 맞춘 대조**다. 선택된 모든 가중치가 600번 갱신됐다는 뜻은 아니다. 선택 결과와 구분할 수 있도록 600스텝의 마지막 가중치도 `-last.pt`에 따로 보존했다.

## 주 시험: 별도 64개 값

각 모델은 동일한 64개 값 × 새 잡담 2배치 = 128사례를 평가했다. 주 지표는 후보 제한 없이 LM 전체 어휘에서 고른 단일 토큰의 정확도다.

| seed | 조건 | 8지선다 | 전체 어휘 | 정답 NLL |
| --- | --- | ---: | ---: | ---: |
| 7 | 8값 대조 | 14.06% | 0% | 18.1799 |
| 7 | 다양한 값 | 81.25% | 54.69% (70/128) | 4.4670 |
| 17 | 8값 대조 | 14.06% | 0% | 18.7604 |
| 17 | 다양한 값 | 80.47% | 50.00% (64/128) | 4.5141 |

다양한 값을 학습한 두 모델도 기억을 비우거나 교환하면 전체 어휘 정확도가 0%였다. 빈 기억의 8지선다는 12.50%였고, 기억 교환 시 원래 답의 8지선다는 2.34%/3.13%로 떨어졌다. 반대로 기억을 제공한 대화의 답을 고른 8지선다 비율은 자기 상태를 사용했을 때의 81.25%/80.47%와 같았다. 답이 기억의 내용에 따라 달라지므로, 기억을 사용하지 않고 새 답을 맞힌 결과로 해석할 수 없다.

같은 8값 그룹을 반복한 두 잡담 배치는 함께 묶고, **8개의 답 그룹** 단위로 부트스트랩했다. 이렇게 구한 정확도 개선의 95% 탐색적 구간은 seed 7에서 +41.41~+68.75%p, seed 17에서 +37.50~+62.50%p였다. 128행을 서로 독립인 표본으로 세지 않았다. 이 구간은 작은 인공 표본에 한정하며 다중 비교 보정은 하지 않았다.

오답은 대소문자만 다른 것이 아니었다. 사후 대소문자 무시 진단도 각각 54.69%/50.00%로 같았고, 틀린 단어 출력은 각각 58건/64건(각 128사례)이었다. 이 진단으로 주 지표를 바꾸지 않았다.

## 새 잡담·긴 거리 시험

같은 미학습 64개 값에 별도 잡담 seed 6009를 사용했다. 각 칸은 128사례의 전체 어휘 정확도다.

| 모델 | 새 잡담 8·16턴 | 새 잡담 32·64턴 |
| --- | ---: | ---: |
| 8값 seed 7 | 0% | 0% |
| 다양한 값 seed 7 | 59.38% | 61.72% (79/128) |
| 8값 seed 17 | 0% | 0% |
| 다양한 값 seed 17 | 56.25% | 65.63% (84/128) |

다양한 값을 학습한 모델은 두 거리 조건 모두 빈 기억이나 교환 기억을 쓰면 전체 어휘 정확도가 0%였다. 긴 조건에서 다양한 값 모델과 8값 대조의 차이를 답 그룹 단위로 부트스트랩한 구간은 seed 7이 +52.34~+70.31%p, seed 17이 +52.34~+76.56%p였다.

다만 짧은 조건과 긴 조건은 뽑힌 잡담과 사실 위치도 다르다. 따라서 긴 조건의 점수가 높다고 **거리가 길어질수록 좋아진다는 인과 주장**을 하지는 않는다. 이 시험 결과로 체크포인트를 다시 선택하지도 않았다.

## 재검사에서 드러난 남은 실패

이전 [[메모리-연구/neural-memory/neural-memory/STREAM_MEMORY_TRANSFER_REPORT|전이 검사]]의 원문/seed 4009를 그대로 다시 사용했다. 아래는 다양한 모델의 전체 어휘 정확도이며, 각 조건은 64사례다.

| 어휘 | 시나리오 | seed 7 | seed 17 |
| --- | --- | ---: | ---: |
| 원래 8개 | 중립 | 100% | 100% |
| 원래 8개 | 후보 단어 언급 잡담 | 96.88% | 96.88% |
| 원래 8개 | 다른 화자의 후보 사실 | 82.81% | 95.31% |
| 원래 8개 | 본인 정정 | 62.50% | 23.44% |
| 이전 미학습 8개 | 중립 | 62.50% | 78.13% |
| 이전 미학습 8개 | 후보 단어 언급 잡담 | 59.38% | 70.31% |
| 이전 미학습 8개 | 다른 화자의 후보 사실 | 45.31% | 60.94% |
| 이전 미학습 8개 | 본인 정정 | 7.81% | 3.13% |

새 값의 중립 검사에서는 이전의 0%가 개선됐지만, 본인 정정에서는 다른 양상이 나타났다. 원래 8값의 정정은 이전 공동학습 seed 7/17의 100%/54.69%보다 나빠졌다.

`My secret word is clock` 이후 `Actually, my secret word is cat`처럼 값을 바꾸는 이전 미학습 8값 시험에서, seed 7은 54/64번, seed 17은 62/64번 **옛값 clock을 출력**했다. 새 사실을 반영하지 못한 직접적인 실패다. 다만 이 검사로 게이트 하나를 원인으로 확정한 것은 아니다.

다른 화자가 clock을 반복하는 별도 대조에서도 새 8값 정확도는 26.56%/1.56%에 그쳤다. 따라서 간섭 내성이 해결됐다고 말할 수 없다. 후보를 제한하면 상당한 정보를 구분하더라도 전체 어휘 출력은 clock일 수 있으므로, 8지선다만으로 성공 여부를 판단하지 않는다.

다른 헤더/잡담 배치의 `original_values` 시험은 두 방법 모두 75%였고, 위의 동일한 기존 중립 재검사는 100%였다. 서로 다른 입력 배치를 합치거나 기존 값 유지가 모든 형식에서 완벽하다고 주장하지 않는다.

## 검증·보존·재현

4건의 GPU 학습, 4건의 새 거리 평가, 2건의 기존 간섭/정정 재검사를 완료했다. 같은 시작 가중치·행 배치·손실 토큰 예산·선택 규칙을 검사하고, 실제 학습 입력을 다시 만들어 기록된 digest와 정확히 일치하는지 확인했다.

저장된 설정의 일부 표기에는 주의가 필요하다. seed 17 설정의 일부 noise/block 필드는 시작 체크포인트의 옛 메타데이터를 물려받았다. **실제 학습은 위에 적은 96블록, 2·4·8턴 조건**이며, 두 seed 모두 `training_audits`에서 입력을 재생성해 확인했다. seed 7의 저장부터는 메타데이터에도 실제 조건을 명시했다. 이 기록 오류는 모델 계산에 영향을 주지 않았고 원본 결과 파일을 소급 수정하지 않았다.

검사에는 단어와 토큰의 분리·역변환, 균형 잡힌 반복 주기, 동일 입력, 그룹별 후보, 위치 표시와 손실의 독립성, 쓰기 파라미터의 기울기를 포함했다. 예산이나 시작 모델이 다르면 비교를 거부하는지, 답 그룹을 함께 묶는지, 스트레스 평가의 잘못된 비교를 거부하는지도 확인했다.

전체 **542개가 통과했고 기존 requires-grad scalar 경고 1개**가 남았다. codecanvas에서 새 함수를 찾지 못해 정적 그래프로 변경 영향을 입증하지는 못했고, 회귀 검사와 실제 CPU/GPU 실행으로 확인했다.

원래 체크포인트와 사용자가 변경한 파일은 보존했다. 산출물은 `local-data/stream-rmt-open-vocab-*`에 있으며 값 분할 목록, 학습 JSON, 선택·마지막 가중치, 거리 시험, 이전 검사와 비교 요약을 포함한다. 저장 중요도 라벨이나 외부 검색 메모리는 추가하지 않았다. 실제 사람 대화의 일반적인 기억 능력과 기억 텍스트 반환/침묵은 아직 검증되지 않았다.

`neural-memory/`에서 수행한 명령 예시다. 기존 학습 artifact는 덮어쓰기를 거부하므로 재실행할 때 새 출력 파일명을 사용한다.

```sh
HF_HUB_OFFLINE=1 TRANSFORMERS_OFFLINE=1 .venv/bin/python run_stream_memory_open_vocab.py --manifest local-data/stream-rmt-open-vocab-manifest.json --prepare-manifest
HF_HUB_OFFLINE=1 TRANSFORMERS_OFFLINE=1 .venv/bin/python run_stream_memory_open_vocab.py --manifest local-data/stream-rmt-open-vocab-manifest.json --warm-start local-data/stream-rmt-control-acquire-joint-seed17.pt --seed 17 --steps 600 --mode diverse --output local-data/stream-rmt-open-vocab-diverse-seed17.json
HF_HUB_OFFLINE=1 TRANSFORMERS_OFFLINE=1 .venv/bin/python run_stream_memory_open_vocab.py --manifest local-data/stream-rmt-open-vocab-manifest.json --warm-start local-data/stream-rmt-control-acquire-joint-seed17.pt --seed 17 --steps 600 --mode eight --output local-data/stream-rmt-open-vocab-eight-seed17.json
HF_HUB_OFFLINE=1 TRANSFORMERS_OFFLINE=1 .venv/bin/python eval_stream_memory_open_stress.py --checkpoint local-data/stream-rmt-open-vocab-diverse-seed17.pt --manifest local-data/stream-rmt-open-vocab-manifest.json --output local-data/stream-rmt-open-vocab-stress-diverse-seed17.json
HF_HUB_OFFLINE=1 TRANSFORMERS_OFFLINE=1 .venv/bin/python eval_stream_memory_transfer.py --checkpoint local-data/stream-rmt-open-vocab-diverse-seed17.pt --compare local-data/stream-rmt-transfer-joint-seed17.json --output local-data/stream-rmt-open-vocab-transfer-seed17.json
```

seed 7은 입력·출력 파일명과 seed를 같이 바꾼다. `analyze_stream_memory_open_vocab.py`의 `--eight/--diverse`에 두 seed의 학습 JSON을, `--stress-eight/--stress-diverse`에 대응하는 거리 평가 JSON을 주면 `stream-rmt-open-vocab-comparison.json`과 같은 입력 감사·비교를 재현할 수 있다.
