이 공간은 직접 수행한 메모리 연구의 지식베이스다. 논문 조사, 구현 설계, 실험 기록과 정정을 함께 관리한다. 2026-10-16 로컬 연구 문서를 정리해 가져왔다. 이번 정리는 실험 재실행이나 논문의 독립 검증이 아니다.

## 어디부터 읽을까

- [[메모리-연구/keymem-연상기억|keymem을 시작한 이유]]: 친구와 드라이브하다 떠올린 연상기억 구조와 구현 과정.
- [[메모리-연구/절차-그래프-읽기|절차 그래프와 Grounded Memory]]: 절차를 조언하는 그래프와 환경 증거로 갱신하는 의미 기억의 결합.
- [[메모리-연구/신경-메모리-읽기|신경 메모리]]: 저장 판단, fast weights, 연속 토큰 기억, 실제 사람 대화로의 전이.
- [[메모리-연구/커넥톰-읽기|초파리 커넥톰]]: 실제 회로의 연결을 사용한 기억과 대조 실험.
- [[메모리-연구/neural-memory/board/004-harness-hazards|측정 하네스의 함정]]: 도구 상속, 결과 유실, 예산 종료와 측정 오류.

## 세 연구가 다루는 대상

| 연구 | 기억의 형태 | 무엇으로 평가하나 | 해석 경계 |
|---|---|---|---|
| 절차 그래프 재현 | 의미 레코드 + 절차 그래프의 조언 | CLBench, MultiChallenge의 과제 정답·비용 | 모델·러너·표본·run이 다른 수치를 합치지 않는다 |
| 신경 메모리 | 학습된 쓰기와 변화하는 내부 상태 | 합성 회상, 실제 대화의 개입 대조, 에이전트 행동 | 다음 토큰 예측과 실제 과제 해결을 구분한다 |
| 커넥톰 | 실제 mushroom body 연결과 가소성 | 용량·간섭·재배선 대조 | 해부학적 구조가 LLM 유용성을 자동 보장하지 않는다 |

## 기록을 읽는 규칙

1. 문서 위의 수집일은 실험일이나 최신 사실 검증일이 아니다.
2. 각 문서의 정정·철회와 후속 phase를 먼저 확인한다. 오래된 양성 결과를 최종 결론으로 인용하지 않는다.
3. 미커밋 사본은 명시했다. 원격 GitHub에 같은 파일이나 실행 코드가 있다고 가정하지 않는다.
4. 연구 문서 42개를 보존했다. 원시 대화, API 설정, 실행 로그, 데이터셋과 가중치는 게시하지 않았다.
5. 원본 프로젝트는 수정하지 않았다. 이후 지식 정리는 이 저장소의 `content`에서 한다.
